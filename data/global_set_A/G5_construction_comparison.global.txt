# G5 — Cross-Language Construction Comparison

## 1. Main Recurring Constructional Functions

Based on F4 tables across all eight languages, the following constructional functions recur with varying realization strategies:

### Function 1: Basic Truth-Value Predication
Assigning truth-value to propositions or entities (X is true/false/correct/wrong).

### Function 2: Truth-Value Negation
Denying truth-value or asserting falsity.

### Function 3: Adnominal Truth-Marking
Modifying nouns with truth-domain predicates (true story, false testimony, correct answer).

### Function 4: Epistemic Status Change
Expressing that something becomes true, is revealed as false, or changes truth-value.

### Function 5: Truth-Status Causation
Expressing that an agent causes something to be verified, falsified, or established as true/false.

### Function 6: Truth Revelation
Expressing that hidden truth emerges, comes to light, or is uncovered.

### Function 7: Truth Concealment
Expressing that truth is hidden, covered up, or kept secret.

### Function 8: Verification and Confirmation
Expressing formal or evidential establishment of truth through proof or authentication.

### Function 9: Abstract Quality Nominalization
Creating abstract nouns denoting truth-related qualities or states (truthfulness, honesty, accuracy).

### Function 10: Agent Nominalization
Creating nouns denoting persons characterized by truth-related behavior (liar, truth-teller).

### Function 11: Manner Adverbialization
Creating adverbs indicating how actions are performed regarding truth (truly, honestly, accurately).

## 3. Narrative Analysis

### Recurring Cross-Language Constructional Patterns

**1. UNIVERSAL: Zero or minimal copula in present affirmative**

All eight languages show strong preference for zero copula or minimal copula in present tense affirmative truth-value attribution, documented in F4 tables:

- **Zero copula**: Georgian (სიმართლეა contracts copula), Yoruba (ó tọ́ "it is true"), Turkish (bu doğru "this is true"), Korean (진실이다 with -이다 often dropped), Indonesian (ini benar colloquially), Basque (egia da with minimal *da*)
- **Obligatory copula**: Finnish (se on totta requires *olla*) — only exception
- **Formal copula**: Tamil (உண்மையாக இருக்கிறது in formal contexts; zero copula colloquially)

**Evidence**: All F4 tables explicitly document copula patterns. Finnish F4 states "Copula *olla* required in all tenses." Other F4 tables note zero copula as unmarked pattern.

**Pattern**: Zero or minimal copula is the unmarked strategy across typologically diverse languages. Only Finnish consistently requires explicit copula.

**2. UNIVERSAL: Light verb constructions for truth-telling**

All eight languages use light verb constructions combining truth-domain nouns with verbs of speaking, documented in F4 tables:

- Georgian: სიმართლე თქმა (simart'le t'qma) "truth saying" [F4: CORE]
- Yoruba: sọ òtítọ́ "speak truth" [F4: CORE]
- Finnish: puhua totuutta "speak truth" [F4: CORE]
- Basque: egia esan "truth say" [F4: CORE]
- Tamil: உண்மை சொல் (uṇmai col) "truth say" [F4: CORE]
- Indonesian: mengatakan kebenaran "say truth" [F4: CORE]
- Turkish: doğru söylemek "true speak" [F4: CORE]
- Korean: 진실을 말하다 (jinsireul malhada) "truth-ACC say" [F4: CORE]

**Evidence**: All F4 tables document these constructions with [CORE] status and note high frequency.

**Pattern**: Truth-telling is universally expressed through light verb constructions (truth-term + "say") rather than dedicated simple verbs. No language has a single verb meaning "to truth."

**3. NEAR-UNIVERSAL: Revelation verbs preferred over simple inchoatives**

Seven of eight languages show systematic preference for revelation/discovery verbs over simple "become true" constructions, documented in F4 and F6 tables:

**Revelation verbs preferred** (F6 evidence):
- Georgian: გამოვლინდა "was revealed" [CORE] vs. სიმართლე გახდა "became truth" [MARGINAL]
- Finnish: paljastua "be revealed" [CORE] vs. *tulla totuudeksi [restricted to predictions]
- Korean: 드러나다 "come to light" [CORE] vs. 진실이 되다 [MARGINAL] "semantically odd"
- Tamil: வெளிப்படு "come out" [CORE] vs. ஆகு "become" [requires context]
- Basque: egia atera "truth came out" [CORE] vs. egia bihurtu [MARGINAL] "marked"

**Inchoatives natural**:
- Indonesian: menjadi benar "become true" [CORE] — fully natural
- Turkish: gerçekleşmek "become real" [CORE] — lexicalized and productive

**Evidence**: F6 naturalness tables explicitly rate these constructions. F4 tables document revelation verbs as primary strategy.

**Pattern**: Most languages conceptualize truth-discovery as revelation/emergence from hiddenness rather than simple state change. Represents **systematic constructional substitution**: revelation constructions replace inchoatives in truth-domain.

**Interpretation**: Languages avoid constructions implying truth "comes into being"; prefer constructions implying truth "comes into view." Reflects conceptualization of truth as pre-existing and discovered.

**4. UNIVERSAL: Productive abstract nominalization**

All eight languages show highly productive affixation for creating abstract quality nouns, documented in F4 tables:

- Georgian: -ობა suffix [F4: CORE]
- Yoruba: ì-/ò- prefixes [F4: CORE]
- Finnish: -uus/-yys suffix [F4: CORE]
- Basque: -tasun suffix [F4: CORE]
- Tamil: -தன்மை suffix [F4: CORE]
- Indonesian: ke-...-an circumfix [F4: CORE]
- Turkish: -lık/-lik suffix [F4: CORE]
- Korean: -성 suffix [F4: CORE]

**Evidence**: All F4 tables document abstract nominalization as productive construction type with multiple examples.

**Pattern**: Abstract nominalization is universally productive in truth-domain, regardless of whether language generally prefers prefixing, suffixing, or circumfixing.

**5. UNIVERSAL: Agentive nominalization asymmetry**

All eight languages show productive agentive nominalization with striking asymmetry, documented in F4 and F2a tables:

**"Liar" lexicalized** (all F4 tables document):
- Georgian: ტყუარა [F4: CORE]
- Yoruba: apurọ́ [F4: CORE]
- Finnish: valehtelija [F4: CORE]
- Basque: gezurtia [F4: CORE]
- Tamil: பொய்யன் [F4: CORE]
- Indonesian: pembohong [F4: CORE]
- Turkish: yalancı [F4: CORE]
- Korean: 거짓말쟁이 [F4: CORE]

**"Truth-teller" absent** (all F4 tables note):
- All languages use periphrastic constructions: "person who tells truth," "honest person"
- Only Tamil உண்மைவாதி exists, marked as less common in F2a
- F4 tables explicitly note this gap for all languages

**Evidence**: F4 tables document agentive nominalization as construction type. All tables note asymmetry.

**Pattern**: Represents **universal constructional asymmetry**: agentive nominalization productive for negative agents, blocked or avoided for positive agents.

**6. UNIVERSAL: Verification vocabulary with productive derivation**

All eight languages show dedicated verification/authentication vocabulary with productive derivational support, documented in F4 and F2a tables:

- Georgian: დადასტურება + derivatives [F4: CORE]
- Yoruba: ìfẹ̀sẹ̀múlẹ̀, ẹ̀rí, jẹ́rìí + derivatives [F4: CORE]
- Finnish: todistaa, todentaa, todiste + extensive family [F4: CORE]
- Basque: egiazkotu, egiaztagiri, egiaztatze + derivatives [F4: CORE]
- Tamil: மெய்ப்பு, உண்மைப்படுத்து + derivatives [F4: CORE]
- Indonesian: membenarkan, validasi + derivatives [F4: CORE]
- Turkish: doğrulamak, tasdik + derivatives [F4: CORE]
- Korean: 확인하다, 증명하다 + derivatives [F4: CORE]

**Evidence**: All F4 tables document verification as distinct construction type. All F2a tables show productive derivational families.

**Pattern**: Verification is universally lexicalized as distinct function with productive morphological support.

### Important Asymmetries, Substitutions, and Restrictions

**ASYMMETRY 1: Inchoative Blocking → Revelation Substitution**

**Restriction**: Simple inchoatives blocked with abstract truth terms in 6/8 languages (documented in F6):

- Korean: 진실이 되다 [MARGINAL] "semantically odd"
- Georgian: სიმართლე გახდა [MARGINAL] "requires specific contexts"
- Basque: egia bihurtu [MARGINAL] "marked construction"
- Finnish: käydä toteen [CORE] but "restricted to predictions"
- Tamil: உண்மையாகு [CORE] but "requires context"

**Substitution**: Revelation verbs systematically substituted (all rated [CORE] in F6):

- Korean: 드러나다 "come to light" replaces 되다 "become"
- Finnish: paljastua "be revealed" replaces *tulla totuudeksi
- Tamil: வெளிப்படு "come out" preferred over ஆகு "become"
- Georgian: გამოვლინდა "was revealed" preferred over გახდა "became"
- Basque: atera "came out" preferred over bihurtu "became"

**Evidence**: F6 naturalness tables explicitly rate both constructions. F4 tables document substitution patterns.

**Interpretation**: Languages avoid constructions implying truth "comes into being"; prefer constructions implying truth "comes into view." Reflects conceptualization of truth as pre-existing and discovered rather than created.

**ASYMMETRY 2: Agentive Nominalization Blocking**

**Restriction**: Agentive nominalization blocked for "truth-teller" in all 8 languages (documented in F4 and F2a):

- All F4 tables document productive agentive patterns
- All F4 tables document "liar" lexicalization
- All F4 tables note "truth-teller" absence or marginality

**Substitution**: Periphrastic constructions universally substituted:
- "Person who tells truth"
- "Honest person"
- "Truth-advocate"

**Evidence**: F4 tables explicitly note this gap. F2a tables document periphrastic alternatives.

**Interpretation**: Negative agent roles (liar, deceiver) are marked and require lexicalization; positive agent roles (truth-teller) are unmarked/expected and don't require special naming. Reflects pragmatic asymmetry in what behaviors need lexical encoding.

**ASYMMETRY 3: Causative Semantic Restriction**

**Restriction**: Causative "make true" blocked in creation sense across most languages (documented in F4):

- Korean F4: "implies manipulation or philosophical impossibility"
- Tamil F4: similar restrictions noted
- Georgian F4: "requires specific contexts"
- Basque F4: semantic markedness noted

**Allowed sense**: Verification/authentication causatives universally productive (all F2a tables document):
- Georgian: გამართლება "justification"
- Finnish: todistaa "prove"
- Basque: egiazkotu "verify"
- Tamil: உண்மைப்படுத்து "verify"
- Indonesian: membenarkan "confirm"
- Turkish: doğrulamak "verify"
- Korean: 확인하다 "verify"

**Evidence**: F4 construction tables note semantic split. F2a tables document productive verification verbs.

**Interpretation**: Languages distinguish verification (establishing pre-existing truth) from creation (bringing truth into existence). Creation sense blocked because truth is discovered, not manufactured.

**ASYMMETRY 4: Passive Voice Stratification**

**Observation**: Languages differ systematically in passive voice preferences for revelation, documented in F4 tables:

**Passive strongly preferred**:
- Finnish F4: "Passive voice dominant in formal registers"
- Korean F4: "Passive revelation verbs (밝혀지다) strongly preferred over active forms"
- Indonesian F4: "di- passive preferred in formal contexts"

**Active/intransitive preferred**:
- Yoruba F4: "Passive less grammaticalized; active voice dominant"
- Basque F4: "Intransitive emergence verbs preferred"
- Tamil F4: "Intransitive emergence verbs preferred"

**Both common**:
- Georgian, Turkish F4 tables note both voices used freely

**Evidence**: F4 tables explicitly document voice preferences.

**Interpretation**: Truth-domain constructions follow general typological patterns for passive productivity. Languages with highly developed passive systems extend them to truth-domain; languages with less grammaticalized passives use active or intransitive alternatives. Not truth-domain-specific.

### Cases Where One Strategy Replaces Another

**SUBSTITUTION 1: Revelation for Inchoative**

As documented above, six languages systematically substitute revelation/discovery constructions for simple inchoatives when expressing truth-discovery:

- **Blocked**: Simple "become true" constructions (F6: [MARGINAL])
- **Substituted**: "Come to light," "be revealed," "emerge" constructions (F6: [CORE])

**Evidence**: F6 naturalness tables rate both. F4 tables document substitution as primary strategy.

**SUBSTITUTION 2: Periphrasis for Agentive "Truth-Teller"**

All languages substitute periphrastic constructions for blocked agentive "truth-teller":

- **Blocked**: Dedicated agentive noun (F4 tables note absence)
- **Substituted**: "Person who tells truth," "honest person" (F4 tables document)

**Evidence**: F4 tables explicitly note periphrastic alternatives.

**SUBSTITUTION 3: Serial Verbs for Affixal Causatives (Yoruba)**

Yoruba substitutes serial verb constructions for affixal causatives found in other languages:

- **Other languages**: Affixal causatives (Turkish -tir, Korean -게 하다, Indonesian -kan, Tamil -படுத்து) documented in F2a
- **Yoruba**: Serial verb constructions (mú kí "cause that") documented in F4

**Evidence**: Yoruba F4 table documents serial verb strategy. Other F4 tables document affixal causatives.

**Interpretation**: Typological substitution — Yoruba's isolating morphology uses syntactic serialization where agglutinative languages use affixation.

**SUBSTITUTION 4: Prepositional Phrases for Case Marking (Indonesian)**

Indonesian substitutes prepositional phrases for case-marked adverbials found in case-rich languages:

- **Case-marking languages**: Finnish -lla/-llä, Turkish -le/-la, Basque -z, Tamil -ஆக, Korean -으로 (all documented in F2a)
- **Indonesian**: dengan + adjective (dengan jujur "with honesty") documented in F2a and F4

**Evidence**: F2a and F4 tables document both strategies.

**Interpretation**: Typological substitution — analytic structure uses prepositions where synthetic structure uses case affixes.

### Weakly Expressed, Constructionally Indirect, or Absent Functions

**1. WEAKLY EXPRESSED: Philosophical Truth Predication**

Most languages lack dedicated constructions for philosophical/ultimate truth distinct from everyday factual truth:

- **Dedicated constructions**: Tamil (மெய் உணர் "realize truth" implies enlightenment, F4 documents), Korean (진리를 깨닫다 "realize philosophical truth", F4 documents)
- **No dedicated constructions**: Georgian, Yoruba, Finnish, Basque, Indonesian, Turkish (F4 tables show same constructions for all truth types)

**Evidence**: F4 tables document construction inventories. Only Tamil and Korean show specialized philosophical truth constructions.

**2. CONSTRUCTIONALLY INDIRECT: Appearance vs. Reality**

Most languages express appearance/reality contrast constructionally rather than through dedicated adjectives:

- **Dedicated adjectives**: Basque (itxurazko "apparent" vs. egiazkoa "real", F1 documents), Turkish (görünüşte "in appearance" vs. gerçekte "in reality", F1 documents)
- **Constructional only**: Georgian, Yoruba, Finnish, Tamil, Indonesian, Korean use "seem" verbs (F4 tables document: Finnish *vaikuttaa*, Korean -것 같다, Indonesian *tampak*, Tamil போல்)

**Evidence**: F1 tables document lexical items. F4 tables document constructional alternatives.

**3. ABSENT: Dispositional Causation**

No language shows productive constructions for causing someone to become a truth-teller or liar as character transformation:

- **Absent**: Constructions like "make someone into a liar" or "cause someone to become honest" as character change
- **Available**: Constructions for causing specific truth-telling or lying acts (all F4 tables document)

**Evidence**: F4 tables document causative constructions but none show dispositional character-change causatives.

**Interpretation**: Universal constructional gap — languages can express causing specific acts but not causing dispositional character change in truth-domain.

**4. RESTRICTED: Degree Modification of Truth Nominals**

Most languages show restrictions on degree modification of core truth nouns, documented in F6:

- **Blocked**: Korean (*매우 진실 "very truth" ungrammatical, F6 notes), Finnish (totuus resists degree modification, F6 notes)
- **Restricted**: Georgian (requires specific constructions, F6 notes), Tamil (similar restrictions, F6 notes)
- **Allowed with adjectival forms**: Korean (매우 정확하다 "very accurate" [CORE]), Indonesian (sangat benar "very true" [CORE])

**Evidence**: F6 tables explicitly note these restrictions.

**Pattern**: Core truth nominals resist degree modification; only adjectival derivatives accept degree adverbs freely.

**5. LANGUAGE-SPECIFIC: Partitive Case Requirement (Finnish)**

Finnish uniquely requires partitive case for general truth statements:

- Finnish F4: "Partitive *totta* obligatory in general statements (*se on totta*)"
- Other case-marking languages: Use nominative or accusative (Tamil, Basque, Korean F4 tables document standard object marking)

**Evidence**: Finnish F4 table explicitly documents partitive requirement. Other F4 tables show no parallel.

**Pattern**: Language-specific constructional requirement without cross-linguistic parallel.

## 4. Summary

### Universal Constructional Patterns (8/8 languages, F4 documented)

1. Zero or minimal copula in present affirmative attribution
2. Light verb constructions for truth-telling (truth-term + "say")
3. Productive abstract quality nominalization
4. Productive agentive nominalization (with universal asymmetry: liar yes, truth-teller no)
5. Revelation/discovery constructions for truth emergence
6. Verification/authentication constructions
7. Truth-term + noun compounding
8. Manner adverbialization (diverse morphological strategies)

### Strong Tendencies (6-7/8 languages, F4/F6 documented)

1. Revelation verbs preferred over simple inchoatives (7/8)
2. Privative/negative affixation for oppositions (7/8)
3. Denominative verb formation for verification (7/8)
4. Concealment constructions (8/8 but less elaborated than revelation)

### Moderate Patterns (3-5/8 languages, F4/F6 documented)

1. Reduplication for intensification (5/8)
2. Passive voice preference in formal revelation contexts (3/8)
3. Inchoative affixation (productive in 2/8; periphrastic in others)
4. Register-based parallel construction systems (4/8)

### Weak or Single-Language Patterns (1-2/8 languages, F4 documented)

1. Partitive case for general truth (Finnish only)
2. Error-type specification compounding (Indonesian exceptional)
3. Inchoative + causative stacking (Turkish productive)
4. Color metaphors for lie types (Korean only)
5. Softened negation for politeness (Indonesian, Korean only)
6. Postpositional grammaticalization (Turkish only)
7. Ideophonic modification (Yoruba only)

### Universal Constructional Gaps (F4 documented)

1. **No dedicated "truth-teller" agentive constructions** — Periphrastic substitution universal
2. **No dispositional causation constructions** — Cannot express causing character change
3. **Degree modification blocked for core truth nominals** — Only adjectival derivatives accept degree adverbs

### Systematic Constructional Substitutions (F4/F6 documented)

1. **Revelation verbs substitute for inchoatives** — When expressing truth-discovery
2. **Periphrasis substitutes for agentive nominalization** — For positive agent roles
3. **Verification causatives substitute for creation causatives** — Establishing vs. creating truth

These patterns represent **systematic constructional constraints** operating across typologically diverse languages, suggesting universal cognitive or pragmatic principles governing truth-domain morphosyntax.
