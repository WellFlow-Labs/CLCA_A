# G6 — Cross-Language Opposition and Asymmetry Comparison

---

## 1. Per-Language Extraction of Attested Oppositional Structures

### 1.1 Chinese (zh)

**Lexical oppositions:**
- 真 / 假 (genuine/true vs. fake/false) — foundational binary; generates 真假 compound and 是真是假 construction
- 真实 / 虚假 (truthful/authentic vs. false/fraudulent) — formal register pair for statements and representations
- 真实 / 失实 (accurate vs. inaccurate in reporting) — journalistic/legal pair; 失实 does not imply intent
- 真实 / 失真 (faithful vs. distorted) — technical/aesthetic pair; 失真 marks departure from an original
- 正确 / 错误 (correct vs. wrong/erroneous) — standard correctness pair
- 客观 / 主观 (objective vs. subjective) — epistemic stance pair
- 合法 / 违法 (lawful vs. unlawful) — legal pair
- 真相 / 假象 (true state of affairs vs. false appearance) — morphologically parallel (真/假 + 象)
- 真话 / 假话 (true words vs. false words) — speech-act pair
- 实话 / 假话 (honest words vs. false words) — speech-act pair, slight register difference from 真话/假话

**Morphological oppositions:**
- 正确 / 不正确 — 不- prefixal negation
- 准确 / 不准确 — 不- prefixal negation
- 可靠 / 不可靠 — 不- prefixal negation
- 诚实 / 不诚实 — 不- prefixal negation
- 真实 / 不真实 — 不- prefixal negation
- 相符 / 不相符 — 不- prefixal negation
- 合法 / 违法 — lexical (违 "violate" vs. 合 "conform"), not simple prefixal negation
- 合法性 / 违法性 — nominalized pair
- 正确性 / 错误性 — nominalized pair; asymmetric: 正确性 [CORE], 错误性 [MARGINAL]
- 真实性 / 虚假性 — nominalized pair; asymmetric: 真实性 more frequent and broadly distributed
- 名副其实 / 名不副实 — internal negation of fixed four-character expression (不 inserted)
- 表里如一 / 表里不一 — internal negation of fixed four-character expression (不 replaces 如)

**Constructional oppositions:**
- 揭露真相 / 掩盖真相 — same object (真相), opposing verbs (reveal vs. conceal)
- 尊重事实 / 歪曲事实 — same object (事实), opposing verbs (respect vs. distort)
- 尊重事实 / 捏造事实 — same object (事实), opposing verbs (respect vs. fabricate)
- 明辨是非 / 颠倒是非 — same object (是非), opposing verbs (distinguish correctly vs. invert)
- 明辨是非 / 混淆是非 — same object (是非), opposing verbs (distinguish vs. confuse)
- 这是真的 / 这是假的 — parallel copular predications
- 这是真的 / 这不是真的 — affirmative vs. negated copular predication
- 辨别真伪 (resolvable) / 真伪莫辨 (irresolvable) — constructional contrast on epistemic outcome
- 去伪存真 / 以假乱真 — opposing processes (purify vs. confuse)
- 合法化 / (no attested *违法化) — asymmetric: process of becoming lawful is lexicalized; process of becoming unlawful is not

**F6 naturalness observations (zh):**
- Inchoative constructions with 失实 and 失真 are [CORE]; with 真实 they are [MARGINAL]; with 正确 they are [MARGINAL]
- 他变得诚实了 is [CORE]; 他的判断变得正确了 is [MARGINAL]
- 真的东西被做成假的了 is [CORE] (passive causative for counterfeiting)
- 合法化 is [CORE]; 真实化 and 现实化 are [MARGINAL]

### 1.2 Hebrew (he)

**Lexical oppositions:**
- אֱמֶת / שֶׁקֶר (*ʾemet* / *sheqer*) — foundational truth/falsehood binary
- עֵד אֱמֶת / עֵד שֶׁקֶר (*ʿed ʾemet* / *ʿed sheqer*) — fixed legal pair (truthful vs. false witness)
- דּוֹבֵר אֱמֶת / דּוֹבֵר שֶׁקֶר (*dover ʾemet* / *dover sheqer*) — parallel participial constructions
- כָּשֵׁר / פָּסוּל (*kasher* / *pasul*) — lexical pair (fit/valid vs. disqualified/invalid); unrelated roots
- תָּקֵף / בָּטֵל (*taqef* / *batel*) — lexical pair (valid/in force vs. null/void); unrelated roots
- מְקוֹרִי / מְזוּיָּף (*meqori* / *mezuyaf*) — original vs. forged
- אוֹתֶנְטִי / מְזוּיָּף (*ʾotenti* / *mezuyaf*) — authentic vs. forged
- צַדִּיק / רָשָׁע (*tsaddiq* / *rashaʿ*) — righteous vs. wicked (moral binary)
- אֱמֶת אוֹבְּיֶקְטִיבִית / אֱמֶת סוּבְּיֶקְטִיבִית — objective vs. subjective truth (collocational pair)
- אֱמוּנָה עִוֶּרֶת / אֱמוּנָה אֲמִתִּית — blind faith vs. genuine faith
- מְדֻיָּק / מְעֻרְפָּל (*meduyaq* / *meʿurpal*) — precise vs. vague
- מְדֻיָּק / מְשֻׁעָר (*meduyaq* / *meshuʿar*) — precise vs. approximate

**Morphological oppositions:**
- נָכוֹן / לֹא נָכוֹן (*nakhon* / *lo nakhon*) — syntactic negation
- זֶה אֱמֶת / זֶה לֹא אֱמֶת — copular affirmation vs. syntactic negation
- אָמִין / לֹא אָמִין (*ʾamin* / *lo ʾamin*) — syntactic negation
- מְהֵימָן / לֹא מְהֵימָן (*mehiman* / *lo mehiman*) — syntactic negation; no single-word antonym
- נֶאֱמָן / לֹא נֶאֱמָן (*neʾeman* / *lo neʾeman*) — syntactic negation
- אוֹתֶנְטִי / לֹא אוֹתֶנְטִי (*ʾotenti* / *lo ʾotenti*) — syntactic negation (loanword, no prefix available)
- מְקוֹרִי / לֹא מְקוֹרִי (*meqori* / *lo meqori*) — syntactic negation (distinct from *mezuyaf*)
- מוּצְדָּק / לֹא מוּצְדָּק (*mutsdddaq* / *lo mutsdddaq*) — syntactic negation
- חוּקִי / בִּלְתִּי חוּקִי (*ḥuqi* / *bilti ḥuqi*) — *bilti* negation (formal register)
- חוּקִי / אִי-חוּקִיּוּת (*ḥuqi* / *ʾi-ḥuqiyyut*) — asymmetric: adjective vs. negated nominalization
- לֶגִיטִימִי / בִּלְתִּי לֶגִיטִימִי (*legitimi* / *bilti legitimi*) — *bilti* negation
- לֶגִיטִימִיּוּת / אִי-לֶגִיטִימִיּוּת — *ʾi-* prefix on nominalization
- תָּקֵף / לֹא תָּקֵף (*taqef* / *lo taqef*) — syntactic negation
- תְּקִינוּת / אִי-תְּקִינוּת (*teqinut* / *ʾi-teqinut*) — *ʾi-* prefix on nominalization
- סָבִיר / בִּלְתִּי סָבִיר (*savir* / *bilti savir*) — *bilti* negation
- סְבִירוּת / אִי-סְבִירוּת (*sevirut* / *ʾi-sevirut*) — *ʾi-* prefix on nominalization; institutionally salient in Israeli administrative law
- דִּיּוּק / אִי-דִּיּוּק (*diyyuq* / *ʾi-diyyuq*) — *ʾi-* prefix on nominalization
- מְדוּיָּק / לֹא מְדוּיָּק (*meduyaq* / *lo meduyaq*) — syntactic negation on adjective
- אֲמִינוּת / אִי-אֲמִינוּת (*ʾaminut* / *ʾi-ʾaminut*) — *ʾi-* prefix on nominalization
- חֲצִי אֱמֶת / אֱמֶת — partial truth vs. full truth (constructional)

**Constructional oppositions:**
- זֶה נָכוֹן / זֶה לֹא נָכוֹן — standard correctness affirmation/denial pair
- זֶה אֱמֶת / זֶה שֶׁקֶר — truth vs. lie (stronger than *ze lo ʾemet*)
- נִמְצָא מְהֵימָן / נִמְצָא לֹא מְהֵימָן — institutionally fixed legal judgment pair
- לְדַבֵּר אֱמֶת / לְשַׁקֵּר — to tell the truth vs. to lie (verbal pair)
- לְגַלּוֹת אֶת הָאֱמֶת / לְהַסְתִּיר אֶת הָאֱמֶת — to reveal vs. to conceal the truth
- לְעַוֵּת אֶת הָאֱמֶת / לְדַבֵּר אֱמֶת — to distort vs. to speak the truth
- כָּל הָאֱמֶת וְרַק הָאֱמֶת / לֹא כָּל הָאֱמֶת — whole truth vs. not the whole truth

**F6 naturalness observations (he):**
- *hafakh le-ʾamin*, *hitgalaʾh ke-ʾotenti*, *ha-ḥoze nikhnas le-toqef* are [CORE]
- *ha-ḥoze hafakh le-batel*, *ha-ḥoze naʿasah batel* are [CORE]
- *ha-mismakh hafakh le-mezuyaf be-yadav* is [UNCERTAIN] — inchoative is not natural for forgery; causative strongly preferred
- *ha-shmuʿah naʿasetat ʾamitit* is [CORE]
- Trust-erosion constructions (*hitʿarer*, *qaras*, *hitmotet*) are [CORE]

### 1.3 Sanskrit (sa)

**Lexical oppositions:**
- सत्य / असत्य (*satya* / *asatya*) — truth vs. untruth (morphological: *a-* prefix)
- ऋत / अनृत (*ṛta* / *anṛta*) — cosmic order vs. disorder/falsehood (morphological: *an-* prefix)
- सत् / असत् (*sat* / *asat*) — being vs. non-being (morphological: *a-* prefix)
- प्रमा / अप्रमा (*pramā* / *apramā*) — valid cognition vs. non-valid cognition (morphological: *a-* prefix)
- प्रमाण / अप्रमाण (*pramāṇa* / *apramāṇa*) — valid means vs. invalid means (morphological: *a-* prefix)
- प्रमाण / प्रमाणाभास (*pramāṇa* / *pramāṇābhāsa*) — genuine vs. pseudo-valid means (*ābhāsa* suffix)
- हेतु / हेत्वाभास (*hetu* / *hetvābhāsa*) — genuine reason vs. fallacious reason (*ābhāsa* suffix)
- प्रामाण्य / अप्रामाण्य (*prāmāṇya* / *aprāmāṇya*) — validity vs. invalidity (morphological: *a-* prefix)
- प्रामाणिक / अप्रामाणिक (*prāmāṇika* / *aprāmāṇika*) — authoritative vs. inauthentic (morphological: *a-* prefix)
- धर्म / अधर्म (*dharma* / *adharma*) — right conduct vs. wrong conduct (morphological: *a-* prefix)
- साधु / असाधु (*sādhu* / *asādhu*) — correct/good vs. incorrect/bad (morphological: *a-* prefix)
- साधु / अपशब्द (*sādhu* / *apaśabda*) — correct word vs. solecism (lexical)
- मुख्य / गौण (*mukhya* / *gauṇa*) — primary/literal vs. secondary/figurative (lexical)
- मुख्य / औपचारिक (*mukhya* / *aupacārika*) — primary vs. conventional/figurative (lexical)
- वस्तु / आभास (*vastu* / *ābhāsa*) — real thing vs. mere semblance (lexical)
- वस्तु / प्रतिभास (*vastu* / *pratibhāsa*) — real thing vs. mere appearance (lexical)
- सत् / मिथ्या (*sat* / *mithyā*) — absolute reality vs. indeterminate/illusory (lexical; *mithyā* is not simply the negation of *sat*)
- सत्य / मिथ्या (*satya* / *mithyā*) — truth vs. false/illusory (lexical)
- यथार्थ / मिथ्या (*yathārtha* / *mithyā*) — accurate vs. false/illusory (lexical)
- यथार्थ / अयथार्थ (*yathārtha* / *ayathārtha*) — accurate vs. inaccurate (morphological: *a-* prefix; [MARGINAL])
- तथ्य / अतथ्य (*tathya* / *atathya*) — factual vs. not factual (morphological: *a-* prefix)
- वास्तव / अवास्तव (*vāstava* / *avāstava*) — real vs. unreal (morphological: *a-* prefix; [MARGINAL])
- युक्त / अयुक्त (*yukta* / *ayukta*) — appropriate vs. inappropriate (morphological: *a-* prefix)
- उचित / अनुचित (*ucita* / *anucita*) — fitting vs. unfitting (morphological: *an-* prefix)
- औचित्य / अनौचित्य (*aucitya* / *anaucitya*) — propriety vs. impropriety (morphological: *an-* prefix)
- गुण / दोष (*guṇa* / *doṣa*) — merit vs. fault (lexical)
- शुद्ध / अशुद्ध (*śuddha* / *aśuddha*) — pure/correct vs. impure/incorrect (morphological: *a-* prefix)
- सत्कार्यवाद / असत्कार्यवाद — opposing philosophical doctrines on causation (morphological: *a-* prefix on compound)
- स्वतःप्रामाण्य / परतःप्रामाण्य — intrinsic vs. extrinsic validity (lexical: opposing adverbial prefixes within same compound frame)
- सत्यवादिन् / असत्यवादिन् — truth-speaker vs. false-speaker (morphological: *a-* prefix on compound)
- परमार्थ / व्यावहारिक (*paramārtha* / *vyāvahārika*) — ultimate vs. conventional truth (lexical)

**F6 naturalness observations (sa):**
- *pramā jāyate*, *pramā utpadyate*, *bhramaḥ jāyate*, *bhrāntiḥ nivartate*, *bādhena bhrāntiḥ nivartate* are [CORE]
- *bādhitam* (past passive participle of sublation) is [CORE]
- *viparyyayaḥ jāyate* is [MARGINAL] — confined to Sāṃkhya-Yoga discourse

- *anṛtena parivṛttaḥ* is [MARGINAL] — attested for *anṛta* only; no parallel with *asatya*, *mithyā*, or *adharma*

### 1.5 English (en)

**Lexical oppositions:**
- *true* / *false* — foundational binary
- *truth* / *falsehood* — nominalized pair; *falsehood* implies intent more than *false*
- *truth* / *untruth* — morphological (*un-* prefix); softer than *falsehood*
- *genuine* / *fake* — genuineness vs. inauthenticity (lexical)
- *authentic* / *fake* — authenticity vs. inauthenticity (lexical)
- *genuine* / *spurious* — genuine vs. spurious (lexical; *spurious* more formal)
- *genuine* / *counterfeit* — genuine vs. counterfeit (lexical; *counterfeit* more domain-specific)
- *valid* / *sound* — valid (form) vs. sound (form + true premises) in formal logic (constructional distinction)
- *accurate* / *exact* — tolerates margin vs. no deviation (lexical distinction within correctness)
- *accurate* / *correct* — degree of correspondence vs. conformity to norm (lexical distinction)
- *plausible* / *specious* — appears reasonable vs. deceptively appears reasonable (lexical; evaluative direction differs)
- *sincere* / *disingenuous* — sincere vs. strategically insincere (lexical; *disingenuous* via *ingenuous*)
- *truthful* / *untruthful* — morphological (*un-* prefix)
- *reliable narrator* / *unreliable narrator* — constructional pair in literary criticism

**Morphological oppositions:**
- *accurate* / *inaccurate* — *in-* prefix
- *accuracy* / *inaccuracy* — *in-* prefix on nominalization
- *correct* / *incorrect* — *in-* prefix
- *valid* / *invalid* — *in-* prefix (homophony with *invalid* = disabled person noted)
- *validity* / *invalidity* — *in-* prefix on nominalization
- *legitimate* / *illegitimate* — *il-* prefix (variant of *in-*)
- *authentic* / *inauthentic* — *in-* prefix
- *authenticity* / *inauthenticity* — *in-* prefix on nominalization
- *credible* / *incredible* — *in-* prefix; *incredible* has undergone semantic shift toward "extraordinary" in informal use
- *plausible* / *implausible* — *im-* prefix
- *sincere* / *insincere* — *in-* prefix
- *honest* / *dishonest* — *dis-* prefix
- *trustworthy* / *untrustworthy* — *un-* prefix
- *true* / *untrue* — *un-* prefix
- *truthful* / *untruthful* — *un-* prefix
- *legitimate* / *delegitimize* — *de-* reversal of causative (not simple negation)
- *validate* / *invalidate* — *in-* prefix on causative verb
- *exactness* / *inexactitude* — competing nominalizations with register differentiation

**Constructional oppositions:**
- *proved true* / *proved false* — same verb, opposing predicates
- *ring true* / *ring false* — fixed verbal idiom pair
- *come true* / (no parallel *come false*) — asymmetric: lexicalized only for positive pole
- *hold true* / (no parallel *hold false*) — asymmetric: lexicalized only for positive pole
- *tell the truth* / *tell lies* — parallel verbal constructions
- *reliable narrator* / *unreliable narrator* — constructional pair; *unreliable narrator* more frequently used as a term of art
- *it is true that… but* — concessive frame (no parallel negative concessive)
- *the truth hurts* / *the truth will out* — opposing proverbial orientations (painful vs. inevitable)

**F6 naturalness observations (en):**
- *proved true*, *proved false*, *proved correct*, *proved genuine*, *proved authentic* are [CORE]
- *turned out to be false/genuine/bogus/counterfeit/apocryphal* are [CORE]
- *became true* is [MARGINAL] — *prove true* and *turn out to be true* strongly preferred
- *come true* is [CORE] but restricted to wishes, dreams, predictions, fears as subject
- *ring true/false* are [CORE] but restricted to informal and journalistic registers
- *became invalid* is [CORE]; *became valid* is [CORE] but less natural than *became invalid* because validity is typically conferred by an act
- *became insincere* is [CORE]; *became sincere* is [CORE] but sincerity is typically a baseline state that can be lost rather than acquired
- *became apocryphal* is [MARGINAL] — apocryphal status is typically assigned retrospectively, not acquired gradually
