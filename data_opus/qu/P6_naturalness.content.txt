# CLCA P6 — CHANGE, CAUSATION, AND STABILITY
## Language: Quechua (qu)

Scope note: All lexical material is drawn from CONTEXT (P1–P5). Function words added as permitted: copula/verbalizer *kay* "to be," the inchoative/verbalizing potential of causative *-cha-* with reflexive *-ku-*, evidential *-mi*, and aspect via *kay*. Where CONTEXT attests no construction, this is stated explicitly. Each root is treated separately, since CONTEXT documents asymmetric behavior across *chiqa-*, *allin*, and *llulla*.

---

## 1. BECOMING TRUE / GENUINE ("X becomes true/correct")

### Pattern
CONTEXT attests **no dedicated intransitive inchoative** ("become X") construction for these roots. P4a/P4b (#4 BECOME/INCHOATIVE) states explicitly: *"No dedicated inchoative ('become true/good/false') construction is documented in P1–P3."* Change-of-state is documented **transitively only**, via causative *-cha-*.

The nearest attested approximation to a "become true" sense uses the reflexive/middle on the verified-state verb:
- **chiqaqchakuy** (chiqaq + -cha- + -ku- + -y) — "to verify oneself, to make sure, to ascertain" (P1b, P2a [MARGINAL])

### Examples
- chiqaqchakuy → chiqaqchakuy → "to make sure (for oneself), to come to be verified" *(MARGINAL — documented as a reflexive verification verb, not a true inchoative)*

### Notes
This is a **middle/reflexive verification** sense ("ascertain for oneself"), not a clean "X becomes true." A genuine inchoative is **NOT ATTESTED**. The data structurally favors transitive causation (rectification) over spontaneous becoming.

---

## 2. BECOMING FALSE / MISTAKEN ("X becomes false / X turns out wrong")

### Pattern
No dedicated inchoative for *llulla* is attested. However, CONTEXT attests an **error/mistakenness** axis distinct from lying (Opposition 6: *llulla* intentional vs. *pantay* unintentional). The verb *pantay* "to err" itself encodes a **dynamic event of going wrong**, and its participle *pantasqa* encodes the **resulting state**.

### Examples
- pantay → pantay → "to err, to come to be wrong" *(CORE — verb encoding the event of erring)*
- pantasqa → pantasqa → "mistaken, having become erroneous" *(CORE — participial resultant state, -sqa)*
- llulla kay → llulla kay → "falseness, the state of being a lie" *(MARGINAL — abstract nominal state, not a becoming)*

### Notes
- For **unintentional** falling-into-error, *pantay* → *pantasqa* is the natural dynamic→resultant pair documented in CONTEXT (P2a, P3 Group 11).
- For **intentional** falsehood, no "X becomes a lie" inchoative is attested; *llulla* and *llulla kay* name the state/quality, not a transition into it.
- A periphrastic "X becomes false" using *llulla* + *kay* (e.g. *llulla kanqa* "it will be false") is grammatically possible with the copula but is **NOT documented as a fixed expression** in CONTEXT.

---

## 3. CAUSING TO BE TRUE / CORRECT / GOOD ("Y causes X to be [truth-related state]")

### Pattern
This is the **most strongly attested** dynamic in the domain. The causative **-cha-** verbalizes evaluative roots into "make/render X." P4a/P4b (#5) marks this as the dominant, broadly productive pattern.

### Examples
- chiqachay → chiqachay → "to correct, set right, verify (cause to be true/straight)" *(CORE)*
- chiqanchay → chiqanchay → "to straighten, align, rectify (cause to be right/just)" *(CORE)*
- allinchay → allinchay → "to make good, improve, repair, make right" *(CORE)*
- sut'inchay → sut'inchay → "to clarify, make evident (cause to be clear)" *(CORE)*

### Notes
- These are transitive: an agent Y acts on X to bring it into the true/right/good/clear state. This is the documented expression of caused change-of-state across the domain (P3 Group 2, "making something clear or setting it right").
- *chiqachay* uniquely spans **factual** ("verify") and **physical/moral** ("set straight") causation per P1.
- Embedding in a Y-causes-X frame (e.g. *Juan chiqachan willakuyta* "Juan corrects/verifies the report") uses the bare causative verb; no further dedicated construction is required or attested.

---

## 4. CAUSING TO BELIEVE A FALSEHOOD ("Y causes X to be deceived")

### Pattern
A **distinct second causative -chi-** on *llulla* directs the change at a **third party's belief state**, not at the truth-value of a proposition. P4a/P4b (#5) and P5 (Opposition 7) document this contrast: *-cha-* (rectify) vs. *-chi-* (deceive).

### Examples
- llullachiy → llullachiy → "to deceive (someone), to cause to be fooled, to trick" *(MARGINAL)*
- llullakuy → llullakuy → "to lie, to deceive (telling untruth)" *(CORE — reflexive/middle, agent-oriented)*

### Notes
- **Polarity contrast (P5 Opposition 7):** *chiqachay/allinchay* (-cha-) cause a GOOD/TRUE state; *llullachiy* (-chi-) causes a third party into a DECEIVED state.
- **Argument-structure contrast:** *llullakuy* (-ku- reflexive/middle) centers the **act of the liar**; *llullachiy* (-chi- causative) centers **causation onto another's belief**.
- This is the only attested "cause to be in a non-true state" construction; it targets a **person's belief**, not a proposition's truth-value.

---

## 5. CAUSING TO BELIEVE / ACCEPT AS TRUE ("Y causes X to believe")

### Pattern
CONTEXT attests the belief verb *iñiy* "to believe" and agentive *iñiq* "believer" (P1 #24, P2a), but **no causative form** (*iñichiy* or similar) is attested in CONTEXT.

### Examples
- iñiy → iñiy → "to believe, to accept as true" *(CORE — non-causative)*
- *(causative "to make believe" — NO COMMON EXPRESSION ATTESTED in CONTEXT)*

### Notes
A causative of *iñiy* is morphologically plausible (-chi-) but is **NOT documented**. The only documented "cause-to-believe-something-false" verb is *llullachiy* (§4), which lexicalizes deception rather than compositional causation on *iñiy*.

---

## 6. RESULTANT / STABLE STATES (states reached and held)

### Pattern
CONTEXT attests **resultant-state** marking via the participle **-sqa** (P2a), and **abstract stable states** via the [X + kay] nominalizing frame (P4a #6). These encode the *outcome* of change rather than the change itself.

### Examples
- pantasqa → pantasqa → "mistaken, erroneous (resultant state of having erred)" *(CORE — -sqa participle)*
- allin ruwasqa → allin ruwasqa → "well made, well done (resultant good state)" *(MARGINAL — -sqa, with allin)*
- chiqap kay → chiqap kay → "truth, reality (stable abstract state)" *(CORE)*
- allin kay → allin kay → "goodness, well-being (stable state)" *(MARGINAL)*
- llulla kay → llulla kay → "falseness, mendacity (stable state)" *(MARGINAL)*

### Notes
- The **-sqa** participle is the documented device for "having become / having been made X" (resultant). It is attested on *panta-* (pantasqa) and on *ruwa-* under *allin* (allin ruwasqa), but **NOT** attested directly on *chiqa-* or *llulla* in CONTEXT.
- The **[X + kay]** frame names the stable abstraction at each pole (truth / goodness / falseness) — the most cross-cutting template (P4a #6), but it is **stative**, not dynamic.

---

## 7. STABILITY / CERTAINTY-AS-PERSISTENCE ("X is firmly/definitely true")

### Pattern
CONTEXT does not attest a verb of *maintaining* a truth-state, but it attests **certainty intensification** via the enclitic **-puni** and affirmation via **-mi**, which mark the assertion's firmness/stability rather than a change.

### Examples
- chiqaqpuni → chiqaqpuni → "definitely true, surely true (firmly so)" *(CORE)*
- chiqaqmi → chiqaqmi → "it's true (I affirm)" *(CORE)*

### Notes
- *-puni* (P1 #30, [UNCERTAIN] as lexical; P4 borderline grammatical) marks **persisting certainty** — the closest documented analog to "stably/unchangingly true."
- This encodes **epistemic stability of the assertion**, not stability of the world-state. No verb "to remain true" is attested.

---

## SUMMARY OF DYNAMIC ENCODING (supported by CONTEXT)

| Dynamic type | Attested device | Example | Status |
|---|---|---|---|
| Become true (inchoative) | **NONE** — not attested | — | absent |
| Reflexive verification (nearest) | -cha- + -ku- | chiqaqchakuy | MARGINAL |
| Become mistaken (unintentional) | verb *panta-* → -sqa | pantay → pantasqa | CORE |
| Become false (intentional) | **NONE** — not attested | — | absent |
| Cause to be true/right/good/clear | causative **-cha-** | chiqachay, allinchay, sut'inchay | CORE |
| Cause to be deceived | causative **-chi-** | llullachiy | MARGINAL |
| Cause to believe (true) | **NONE** — *iñiy* has no attested causative | — | absent |
| Resultant state | participle **-sqa** | pantasqa, allin ruwasqa | CORE/MARGINAL |
| Stable abstract state | [X + kay] | chiqap kay, llulla kay | CORE/MARGINAL |
| Epistemic stability/certainty | enclitic **-puni / -mi** | chiqaqpuni, chiqaqmi | CORE |

### Key asymmetries (data-supported)
1. **Causation is richly encoded; spontaneous becoming is not.** The domain has robust transitive *-cha-* causatives (rectification) but **no intransitive inchoative** for truth/falsity (confirmed in P4a #4).
2. **Two causatives diverge by target and polarity (P5 Opp. 7):** *-cha-* → good/true *state of a thing*; *-chi-* → deceived *belief of a person*.
3. **Only the error axis (*panta-*) supplies a clean dynamic→resultant pair** (*pantay* → *pantasqa*); the intentional-falsehood axis (*llulla*) supplies only stative forms (*llulla*, *llulla kay*), no attested becoming.
4. **Belief (*iñiy*) is stative/non-causative in CONTEXT**; the only lexicalized causation onto belief is deceptive (*llullachiy*).
5. **Stability is expressed epistemically** (via *-puni/-mi* certainty marking) rather than via any verb of persisting in a truth-state.
