## 1. ATTRIBUTION
### Pattern
**X + copular predication**: **X உண்மை / நிஜம் / சரி / தவறு**; also quoted-clause + **உண்மை / சரி**
### Examples
- இது உண்மை. → *itu uṇmai.* → “This is true.”
- அது சரி. → *atu cari.* → “That is correct / okay.”
### Notes
Tamil commonly uses bare nominal/adjectival predication without an overt present-tense copula. Truth/correctness predicates can stand directly after the subject or quoted proposition.

## 2. NEGATIVE ATTRIBUTION
### Pattern
**X + predicate + இல்லை / அல்ல**; also **உண்மையில்லை, சரியில்லை, மெய்யல்ல**
### Examples
- இது உண்மையில்லை. → *itu uṇmaiyillai.* → “This is not true.”
- அது சரியல்ல. → *atu cariyalla.* → “That is not correct / proper.”
### Notes
Negation is commonly formed with **இல்லை** or **அல்ல** after the truth/correctness predicate. **இல்லை** is especially common in everyday usage; **அல்ல** is somewhat more categorical/formal.

## 3. ADNOMINAL MODIFICATION
### Pattern
**Noun + adjectival form in -ஆன**: **உண்மையான N, பொய்யான N, சரியான N, தவறான N, நிஜமான N**
### Examples
- உண்மையான தகவல் → *uṇmaiyāṉa takaval* → “true / factual information”
- பொய்யான குற்றச்சாட்டு → *poyyāṉa kuṟṟaccāṭṭu* → “false accusation”
### Notes
A very productive pattern is adjectival derivation with **-ஆன** from truth/falsity/correctness nouns. These forms directly modify nouns in attributive position.

## 4. BECOME / INCHOATIVE
### Pattern
**Predicate + ஆகு / ஆகி போ**: **சரி ஆகு, பொய்யாகி போ**
### Examples
- எல்லாம் சரி ஆகும். → *ellām cari ākum.* → “Everything will become okay / right.”
- அந்தக் கூற்று பொய்யாகி போனது. → *antak kūṟṟu poyyāki pōnatu.* → “That claim turned out to be false.”
### Notes
Tamil uses **ஆகு** ‘become’ and resultative **ஆகி போ** for change into a truth-status or correctness-status. This is natural with **சரி** and **பொய்**; less so with some other items.

## 5. CAUSATIVE
### Pattern
**Truth/correctness base + light verb**: **சரிசெய், உறுதிப்படுத்து**  
### Examples
- பிழையை சரிசெய். → *piḻaiyai caricey.* → “Correct the error.”
- தகவலை உறுதிப்படுத்து. → *takavalai uṟuti paṭuttu.* → “Confirm the information.”
### Notes
Rather than a single productive morphological causative for “make true/correct,” Tamil commonly uses lexical/light-verb constructions. **சரிசெய்** means ‘make right/correct,’ and **உறுதிப்படுத்து** means ‘make certain/confirm.’

## 6. ABSTRACT NOMINALIZATION
### Pattern
**Base + -மை / -தன்மை**: **உண்மை, மெய்மை, உண்மைத்தன்மை, நம்பகத்தன்மை, சரித்தன்மை**
### Examples
- உண்மைத்தன்மை முக்கியம். → *uṇmaittaṉmai mukkiyam.* → “Truthfulness / veracity is important.”
- நம்பகத்தன்மை குறைந்தது. → *nampakattaṉmai kuṟaintatu.* → “Reliability decreased.”
### Notes
Abstract truth-domain nouns are commonly formed with **-மை** and **-தன்மை**. **-தன்மை** is especially common in formal evaluative language for qualities like veracity and reliability.

## 8. ADVERBIAL / DISCOURSE MARKING
### Pattern
**Base + case/adverbial morphology**: **உண்மையில், உண்மையாக, சரியாக, நிஜமாகவே**
### Examples
- உண்மையில் இது கடினம். → *uṇmaiyil itu kaṭiṉam.* → “In fact, this is difficult.”
- அவன் சரியாக பதில் சொன்னான். → *avaṉ cariyāka patil coṉṉāṉ.* → “He answered correctly.”
### Notes
Truth and correctness terms frequently appear in adverbial/discourse functions. **-இல்** gives “in fact / actually,” while **-ஆக** gives manner or stance adverbs like “truly, correctly.”

## 9. VERBAL TRUTH/FALSITY EXPRESSIONS
### Pattern
**Object/base + speech verb**: **உண்மையைச் சொல், உண்மை பேசு, பொய் சொல், பொய் பேசு**
### Examples
- உண்மையைச் சொல். → *uṇmaiyaic col.* → “Tell the truth.”
- பொய் பேசாதே. → *poy pēcātē.* → “Don’t lie.”
### Notes
Tamil often expresses truth/falsity through noun + speech verb constructions rather than simple lexical verbs meaning “truth” or “lie” alone. These are core everyday patterns.

## 10. VERIFICATION / CONFIRMATION
### Pattern
**Correctness/certainty base + checking verb**: **சரிபார், உறுதி செய், உறுதிப்படுத்து**
### Examples
- ஆவணத்தை சரிபார். → *āvaṇattai caripār.* → “Check the document.”
- செய்தியை உறுதி செய். → *ceytiyai uṟuti cey.* → “Verify / confirm the news.”
### Notes
A major truth-domain construction in Tamil is procedural verification. These forms are especially common in administrative, journalistic, and technical contexts.
