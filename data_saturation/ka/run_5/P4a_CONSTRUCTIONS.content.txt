# CLCA Protocol v3.4 — P4a CONSTRUCTIONS
# Language: Georgian (ka)

---

## 1. ATTRIBUTION

### Pattern
[Subject NP] + [truth-domain adjective] + copula (-a / -ia / არის)

### Examples
- ეს მართალია → es martalia → "This is true / This is right"
- ეს ყალბია → es q̇albia → "This is fake / This is false"

### Notes
Georgian predicative attribution uses a copular suffix (-a, -ia) attached directly to the adjective or a free copula (არის aris). The adjective agrees in number with the subject but does not inflect for case in predicative position. Both martali and q̇albi participate freely in this pattern.

---

## 2. NEGATIVE ATTRIBUTION

### Pattern
[Subject NP] + [truth-domain adjective] + არ არის (ar aris) / ara- prefix on adjective

### Examples
- ეს სწორი არ არის → es sc̣ori ar aris → "This is not correct"
- ეს არასწორია → es arasc̣oria → "This is incorrect"

### Notes
Georgian has two strategies: (a) negation of the copula with ar aris, leaving the adjective unchanged; (b) lexical negation via the prefix ara- incorporated into the adjective itself (arasc̣ori, aralegitimuri, araobieqt̕uri). Both are productive. The ara- strategy produces a single lexical item; the ar aris strategy is syntactically compositional.

---

## 3. ADNOMINAL MODIFICATION

### Pattern
[truth-domain adjective] + [head noun] (adjective precedes noun; no agreement inflection for attributive position)

### Examples
- ჭეშმარიტი ამბავი → č̣ešmariti ambavi → "a true story / a true account"
- ყალბი დოკუმენტი → q̇albi dokument̕i → "a forged document"

### Notes
Georgian adjectives precede the head noun and do not inflect for gender (Georgian has none) or case in attributive position; case is marked on the head noun. Truth-domain adjectives (č̣ešmariti, q̇albi, namdvili, sc̣ori, zusti, martali, etc.) all follow this pattern without exception.

---

## 4. BECOME / INCHOATIVE

### Pattern
[NP] + [truth-domain adverbial (-ad form)] + გამოვიდა (gamovida) / აღმოჩნდა (aɣmočnda)

### Examples
- ყალბად გამოვიდა → q̇albad gamovida → "turned out to be false / came out as fake"
- ნამდვილი აღმოჩნდა → namdvili aɣmočnda → "turned out to be genuine / proved to be authentic"

### Notes
Georgian lacks a dedicated inchoative copula equivalent to "become." The inchoative/resultative meaning is expressed periphrastically: either with the adverbial form of the adjective (q̇albad) + gamovida ("came out"), or with the adjective in nominative + aɣmočnda ("turned out to be"). The aɣmočnda construction is slightly more formal; gamovida is more colloquial. Both are attested across truth-domain adjectives.

---

## 5. CAUSATIVE

### Pattern
ga- (preverb) + [truth-domain root] + -eba (verbal noun) / inflected verb

### Examples
- გაყალბება → gaq̇albeba → "falsification, the act of making false / forging"
- გასწორება → gasc̣oreba → "correction, the act of making correct / rectifying"

### Notes
Georgian does not use a dedicated causative morpheme equivalent to "make X true/false." Instead, the preverb ga- combines with the root to form a completive/resultative verbal stem expressing the act of bringing about the truth-domain state (making false, making correct, making precise: gaq̇albeba, gasc̣oreba, gazusteba). This is a derivational rather than a productive syntactic causative. No periphrastic "cause to be true/false" construction is identified in the data.

## 6. ABSTRACT NOMINALIZATION

### Pattern
si- + [root] + -e (nominal circumfix) OR [adjectival base] + -eba / -oba (suffix)

### Examples
- სიმართლე → simartle → "truth, correctness, rightness" (si- + martal- + -e)
- ჭეშმარიტება → č̣ešmariteba → "truth, truthfulness, veracity" (č̣ešmariti + -eba)

### Notes
Two productive nominalization strategies are attested for truth-domain items. The si-...-e circumfix applies to adjectival roots to yield abstract quality nouns (simartle, siq̇albe, sizuste, sisc̣ore, sicrue). The suffix -eba attaches to adjectival or participial bases (č̣ešmariteba, namdviloba via -oba, legitimuroba, obieqt̕uroba). The -oba suffix is used for borrowed adjectival bases ending in -uri (legitimuri → legitimuroba) and for native bases where -eba is blocked. Both strategies are fully productive across the truth-evaluation domain.

---

## 7. AGENTIVE NOMINALIZATION

### Pattern
[preverb] + [root] + -ebeli (agentive/potential suffix) + -i

### Examples
- გამყალბებელი → gamq̇albebeli → "forger, falsifier, counterfeiter"
- მიმბაძველი → mimbadzvelilit → "imitator, mimic, copyist"

### Notes
The suffix -ebeli (with preverb) is the primary agentive nominalizer for truth-domain actors in Georgian. It derives agent nouns from verbal roots: ga- + q̇alb- + -ebeli yields the forger; mi- + badz- + -veli (variant) yields the imitator. No common agentive noun for "truth-teller" (a positive agent) is identified in the data; the pattern is productive primarily on the falsification/deception side. The item tvaltmaqci (deceiver) uses a different adjectival/nominal suffix -i directly on the compound stem.

## 8. DISCOURSE-FRAMING CONSTRUCTIONS (candor markers)

### Pattern
[truth-domain NP in nominative or adverbial] + rom + [1sg subjunctive of tqva]

### Examples
- სიმართლე რომ ვთქვა → simartle rom vtqva → "to tell the truth / truth be told"
- გულწრფელად რომ ვთქვა → gulc̣rpelaad rom vtqva → "frankly speaking / to be sincere"

### Notes
This construction functions as a pragmatic frame introducing a candid or frank statement. The structure is: [truth-domain element] + subordinator rom + 1sg subjunctive vtqva ("that I say / were I to say"). It is not a subordinate clause in context but a fixed discourse marker. Two variants are attested: one using a nominal (simartle) in nominative, one using an adverbial (gulc̣rpelaad). Both are high-frequency in spoken Georgian.

## 9. POSTPOSITIONAL CONFORMITY/MISMATCH CONSTRUCTION

### Pattern
[NP] + -თან (-tan postposition) + შეუსაბამოა / შესაბამისია (predicative adjective + copula)

### Examples
- კანონთან შეუსაბამოა → kanontан šeusabamoа → "is inconsistent with the law / is non-compliant with the law"
- სინამდვილესთან შეუსაბამოა → sinamdvilestан šeusabamoа → "is inconsistent with reality / does not accord with the facts"

### Notes
This construction expresses a truth-domain mismatch between a claim, action, or document and a standard or reality. The postposition -tan (comitative/relational) marks the standard against which conformity is evaluated. The predicative adjective šeusabamoа (is inconsistent) or šesabamisia (is consistent) carries the evaluative force. This pattern is characteristic of legal and administrative registers and is not replicated by any other construction type in the data.
