## 1. Per-language extraction of main attested oppositional / contrastive structures

### ka (Georgian)
Main attested contrasts from F5/F6:

- **Lexical oppositions**
  - **ნამდვილი / ყალბი** “genuine / fake” — strong core authenticity contrast
  - **ნამდვილობა / სიყალბე** “authenticity / falseness”
  - **უტყუარი / სარწმუნო / დამაჯერებელი** — scalar contrast: conclusive/reliable vs credible vs merely convincing
  - **სწორი პასუხი / ზუსტი პასუხი** — correctness vs precision
  - **სისწორე / სიზუსტე** — correctness vs accuracy/precision
  - **ჭეშმარიტების ძიება / სიმართლის ძიება**
  - **ჭეშმარიტების დადგენა / სიმართლის დადგენა**
  - **ჭეშმარიტების თქმა / სიმართლის თქმა**
    - these are register/scope contrasts, not polarity oppositions
  - **მართალი პასუხი / სწორი პასუხი** — usage contrast
  - **ჭეშმარიტი სიყვარული / ნამდვილი სიყვარული** — stylistic contrast

- **Morphological / negational oppositions**
  - **სწორი / სწორი არ არის**
  - **მართებული / მართებული არ არის**

- **Constructional oppositions**
  - **სიმართლეს შეესაბამება / სიმართლეს არ შეესაბამება**
  - **ეს მართალია / ეს სწორი არ არის**
  - **გამართლება აქვს / გამართლება არ აქვს**
  - paired noun phrases:
    - **ნამდვილი დოკუმენტი / ყალბი დოკუმენტი**
    - **ნამდვილი ხელმოწერა / ყალბი ხელმოწერა**

- **F6-supported dynamic asymmetry**
  - strong for:
    - **სიმართლე გაირკვა**
    - **სიმართლე დადგინდა**
    - **სიმართლის დადგენა**
    - **ნამდვილობის დადგენა**
    - **სისწორის/სიზუსტის შემოწმება**
  - weak/absent for:
    - general “remain true”
    - change-of-state for **ყალბი / სიყალბე**

### yo (Yoruba)
Main attested contrasts:

- **Lexical oppositions**
  - **òtítọ́ / irọ́** “truth / lie”
  - **òtítọ́ / èké** “truth / falsehood-deceit”
  - **òtọ́ / èké** “genuine/truth / fake/deceit”
  - **ojúlówó / èké** “genuine / fake”
  - **péye / àṣìṣe** “exact/accurate / error”
  - **ìwà rere / ìwà búburú** “good conduct / bad conduct”
  - **òdodo / ìwà búburú** — moral contrast
  - **òtítọ́ / òdodo** — truth vs justice/righteousness domain contrast
  - **ẹlẹ́rìí ojú / ẹlẹ́rìí àròsọ** — eyewitness vs hearsay witness, but uncertain

- **Morphological / negational oppositions**
  - **jẹ́ òtítọ́ / kì í ṣe òtítọ́**
  - **tọ́ / kò tọ́**

- **Constructional oppositions**
  - **òtítọ́ ni / irọ́ ni**
  - **ní ẹ̀rí / kò sí ẹ̀rí**
  - **fi ẹ̀rí hàn / kò sí ẹ̀rí**
  - looser semantic contrast:
    - **sọ òtítọ́ / irọ́ ni**

- **F6-supported dynamic asymmetry**
  - strong for:
    - predicative truth/falsity
    - **fi òtítọ́ hàn**
    - **fi ẹ̀rí hàn**
    - **rí i dájú**
  - absent/unsupported for:
    - dedicated “become true”
    - dedicated “become false”
    - dedicated “become right”
    - dedicated “become authentic”
    - dedicated “become righteous”

### fi (Finnish)
Main attested contrasts:

- **Lexical oppositions**
  - **totta/tosi / epätosi**
  - **aito / epäaito**
  - **oikea / väärä**
  - **todellinen / apparent-fictional-supposed**
  - **todellisuus / illusion-appearance-representation**
  - **aito / väärennös-jäljitelmä**
  - **alkuperäinen / jäljitelmä**
  - **luotettava / uskottava**
  - **laillinen / lainmukainen** — scope/register contrast
  - **väärä / virheellinen** — breadth/register contrast

- **Constructional oppositions**
  - **Se on totta / Se ei ole tosi / Väite ei pidä paikkaansa**
  - general positive vs negative attribution:
    - **X on ... / X ei ole ...**
  - **tulla todeksi / osoittautua epätodeksi**
  - **pitää jokin totena / pitää jotakuta luotettavana**
  - **On totta, että ... / Pitää paikkansa, että ...**
  - authenticity/result:
    - **paljastua väärennökseksi**

- **F6-supported dynamic asymmetry**
  - strong for:
    - **tulla todeksi**
    - **osoittautua epätodeksi**
    - **paljastua väärennökseksi**
    - **todistaa jokin**
    - **tehdä jokin uskottavaksi**
  - absent/unsupported as general productive patterns for:
    - many other adjectives like **laillinen, luotettava, aito, autenttinen, oikea**

### eu (Basque)
Main attested contrasts:

- **Lexical oppositions**
  - **egia / gezur**
  - **egiazko / gezurrezko**
  - **egiazko / itxurazko**
  - **benetako / itxurazko**
  - **zuzen / oker**
  - **zuzena / okerra**
  - **egia osoa / egia erdi**
  - **antzeko / identiko**
  - **antzeko / berdin**
  - **fidagarri / sinesgarri** — reliability vs believability

- **Constructional oppositions**
  - **egia da / ez da egia**
  - **X da egia / X ez da egia**
  - **X zuzena da / X ez da zuzena**
  - **X benetakoa da / X ez da benetakoa**
  - **egia esan / gezurra esan**
  - **egia hutsa / gezur hutsa**
  - **egia borobila / gezur borobila**
  - **egia erdi / gezur erdi**

- **F6-supported dynamic asymmetry**

    - **X egia dela egiaztatu da**
    - **egia agerian jarri**
    - **egia azaleratu**
    - **X zuzendu da / Y-k X zuzendu du**
    - **Y-k X egiaztatu du**
  - unsupported for:
    - dedicated “become false”
    - general “become true” as simple inchoative
    - dedicated “become genuine/real” pattern

### ta (Tamil)
Main attested contrasts:

- **Lexical oppositions**
  - **உண்மை / பொய்**
  - **உண்மையான / பொய்யான**
  - **மெய் / பொய்**
  - **மெய்யான / பொய்யான** — more register-sensitive
  - **சரி / தவறு**
  - **சரியான / தவறான**
  - **அசல் / போலி**
  - **நிஜமான / போலி**
  - **அசல் நகல்** — original vs copy internal contrast
  - **மெய் / மெய்நிகர்** — marginal technical contrast

- **Morphological oppositions**
  - **உண்மை / உண்மையில்லை**
  - **மெய் / மெய்யல்ல**
  - **சரி / சரியில்லை**
  - **சரி / சரியல்ல**
  - **உண்மை / உண்மையற்ற**

- **Constructional oppositions**
  - **இது உண்மை / இது உண்மையில்லை**
  - **அது சரி / அது சரியல்ல**
  - **உண்மையைச் சொல் / பொய் சொல்**
  - **உண்மை பேசு / பொய் பேசு**
  - **உண்மை வெளிவரு / உண்மையை மறை**
  - **உண்மையை ஒப்பு கொள் / உண்மையை ஏற்று கொள் / உண்மையை மறை**
  - **உண்மைக்கு புறம்பாக / உண்மையின் அடிப்படையில்**
  - **உண்மைக்கு மாறாக / உண்மையை அடிப்படையாகக் கொண்டு**
  - **ஒற்றுமை காணப்படுகிறது / ஒற்றுமை இல்லை**
  - **நம்பகமான / நம்பகத்தன்மையை இழக்கு** — asymmetrical reliability contrast

- **F6-supported dynamic asymmetry**
  - strong for:
    - **உண்மை தெரியவருகிறது**
    - **உண்மை வெளிவந்தது**
    - **சரி ஆகும்**
    - **பொய்யாகி போனது**
    - **சரிசெய்**
    - **உறுதி செய் / உறுதிப்படுத்து**
  - weak/absent for:
    - exact “make X true”
    - clear dynamic “become wrong” with **தவறு**
    - positive causative “make reliable”

### id (Indonesian)
Main attested contrasts:

- **Morphological / scalar oppositions**

  - **benar / kurang benar**
  - **tepat / tidak tepat**
  - **tepat / kurang tepat**
  - **tepat sasaran / tidak tepat sasaran**
  - **tepat sasaran / kurang tepat sasaran**
  - **tepat sasaran / belum tepat sasaran**
  - **sesuai / kurang sesuai**
  - **cocok / kurang cocok**
  - **sah / tidak sah**
  - **absah / tidak absah**
  - **valid / tidak valid**
  - **valid / belum valid**
  - **akurat / tidak akurat**
  - **akurat / kurang akurat**
  - **andal / tidak andal**
  - **andal / kurang andal**
  - **mirip / tidak mirip**
  - **patut / tidak patut**
  - **patut / kurang patut**

- **Lexical oppositions**
  - **asli / palsu**
  - **sah menurut hukum / sah menurut agama** — contrast of normative frame, not polarity

- **Constructional oppositions**
  - **benar bahwa ... / tidak benar bahwa ...**
  - **sesuai dengan ... / tidak sesuai dengan ...**
  - **cocok dengan ... / tidak cocok dengan ...**
  - **asli atau palsu / palsu atau asli**
  - **dipastikan asli / diduga palsu**

  - **sah secara hukum / tidak sah secara hukum**
  - **dianggap valid / tidak valid**
  - **diduga palsu / terbukti palsu**

- **F6-supported dynamic asymmetry**
  - strong for:
    - **ternyata benar / terbukti benar**
    - **terbukti tidak benar**
    - **menjadi valid / tidak valid**
    - **menjadi tepat / akurat / sesuai**

    - **membetulkan**
    - **menyesuaikan**
    - **mencocokkan**
    - **mengesahkan / mengabsahkan / memvalidasi**
    - **memalsukan**
  - weak/absent for:
    - common “make accurate” from **akurat**
    - common “become genuine” from **asli**
    - common “make reliable” from **andal**

### tr (Turkish)
Main attested contrasts:

  - **gerçek / gerçekçi** — real vs realistic
  - **gerçek kişi / tüzel kişi**
  - **hakikat sonrası / factual accuracy** — asymmetrical conceptual contrast
  - **gerçek hayat / fiction-theory-online representation**
  - **gerçek dünya / idealized-simulated settings**
  - **gerçek ad / pseudonym-false identity**

- **Morphological oppositions**

  - **geçerli / geçersiz**
  - **meşru / gayrimeşru**
  - **isabetli / isabetsiz**
  - **asıl / asılsız**

  - **hakikati söylemek / hakikati gizlemek**
  - **hakikati söylemek / hakikati çarpıtmak**
  - **gerçeğe uygun / hakikatten uzak**
  - **X doğru/gerçek/geçerli değil / X sahte/asılsız/geçersiz**

    - **sahteleşmek / sahteleştirmek**
    - **özgünleşmek / özgünleştirmek**
    - **dürüstleşmek / dürüstleştirmek**
  - absent:
    - clear common causative “make X güvenilir/geçerli/haklı/meşru/sahici”

### ko (Korean)
Main attested contrasts:

- **Lexical oppositions**
  - **진짜 / 가짜**
  - **진실 / 거짓**
  - **참 / 거짓**
  - **허위 / 사실**
  - **유효하다 / 무효**
  - **정당하다 / 타당하다** — legitimacy vs soundness
  - **올바르다 / 옳다** — usage/domain contrast
  - **진품/진본/정품 / 위작/가짜**
  - **본질 / appearance** — asymmetrical
  - **실체 / appearance-rumor-formal surface** — asymmetrical
  - **실질 / 형식적 surface** — asymmetrical

- **Morphological oppositions**
  - **사실이다 / 사실이 아니다**
  - **진짜가 아니다 / 가짜가 아니다**

- **Constructional oppositions**
  - **사실이 아니다 / 사실과 다르다**
  - **진실을 밝히다 / 진실을 숨기다**
  - **사실을 확인하다 / 사실을 밝히다**
  - **진짜 같다 / 가짜처럼 보이다**
  - **진짜처럼 보이다 / 실체가 드러나다**
  - **보이다/같다 / 드러나다**
  - **신뢰할 수 있다 / 신뢰성에 문제가 있다**
  - **믿을 만하다 / 믿을 만하지 않다**
  - **유효한 표 / 무효표**
  - **유효하다 / 무효가 되다**
  - internal oppositional compounds:
    - **진위**
    - **정오**
    - **옳고 그름**

- **F6-supported dynamic asymmetry**
  - strong for:
    - **진실/사실/실체 + 드러나다**
    - **진실/사실/실체 + 밝히다**
    - **사실/정품 여부를 확인하다**
    - **거짓/허위로 드러나다**
    - **무효가 되다**
    - **무효로 하다**
    - **신뢰를 얻다 / 신뢰성을 확보하다**
    - sincerity dynamics via **느껴지다 / 의심하다 / 인정하다**
  - weak/absent for:
    - direct common “become true”
    - direct common “make true”
    - clear inchoative for **진짜**
    - strong ordinary “become false” outside revelation framing

## 3. F6-based naturalness patterns

### A. Combinations strongly natural across multiple languages

#### 1. Truth as revelation, emergence, or exposure
**Strong recurrent pattern**

Strongly supported in:
- **ka**: სიმართლე გაირკვა / დადგინდა
- **fi**: totuus tulee ilmi
- **eu**: egia agerian jarri / azaleratu
- **ta**: உண்மை தெரியவரு / வெளிவரு
- **tr**: gerçek ortaya çıkmak; gerçeği/hakikati + reveal-type verbs
- **ko**: 진실/실체가 드러나다
- **id**: terbukti benar / tidak benar / palsu; dipastikan asli
- **yo**: fi òtítọ́ hàn, fi ẹ̀rí hàn

This is one of the clearest cross-language natural clusters.

#### 2. Verification/checking instead of direct truth-change
**Strong recurrent pattern**

Strongly supported in:
- **ka**: სიმართლის დადგენა, ნამდვილობის დადგენა, სისწორის/სიზუსტის შემოწმება
- **yo**: rí i dájú, fi ẹ̀rí hàn
- **eu**: egiaztatu
- **ta**: சரிபார், உறுதி செய், உறுதிப்படுத்து
- **id**: memvalidasi, memeriksa keaslian, membenarkan, evaluative passives
- **tr**: doğrulamak, doğruluğunu kontrol etmek
- **ko**: 사실을 확인하다, 정품 여부를 확인하다

#### 3. Dynamic invalidation / formal status change
**Strong recurrent pattern**, especially in formal domains

Strongly supported in:
- **fi**: osoittautua epätodeksi; paljastua väärennökseksi
- **id**: menjadi tidak valid; mengesahkan / mengabsahkan / memvalidasi
- **tr**: geçerli olmak / geçersiz olmak / geçerlilik kazanmak
- **ko**: 무효가 되다 / 무효로 하다
- **ta**: procedural confirmation/correction rather than exact equivalent, but strong in adjacent domain
- **ka**: establishment/checking rather than direct invalidation pattern

#### 4. Correction/fixing rather than “making true”
**Strong recurrent pattern**

Strongly supported in:
- **eu**: zuzendu
- **ta**: சரிசெய்
- **id**: membetulkan
- **tr**: doğrulamak partly, but more “verify”; correction less central in same root
- **ka**: checking/establishing correctness
- **ko**: 정정-related family in broader data, though F6 emphasizes 확인/드러나다 more

#### 5. Scalar or evidentially graded negative outcomes
**Moderate to strong recurrent pattern**

Strongly visible in:
- **id**: diduga palsu / terbukti palsu / dipastikan asli; kurang / belum
- **fi**: osoittautua epätodeksi vs stable epätosi
- **ko**: 드러나다, 판명되다, 의심하다, 인정하다
- **ka**: supported vs less directly supported distinctions
- **tr**: kazanmak/yitirmek, çıkmak, doğrulanmak

---

### B. Combinations consistently weak, awkward, marked, or absent

#### 1. A general common expression meaning “make X true”
**Strong recurrent absence**

Explicitly weak/absent in:
- **ka**
- **yo**
- **eu**
- **ta**
- **ko**

Also restricted in:
- **id** (uses confirm/validate/correct/falsify instead)
- **tr** (uses doğrulamak, olmak, çıkmak, etc., not a general “make true”)
- **fi** (uses prove/show/come true, not a broad general causative “make true”)

This is one of the clearest cross-language blocking patterns.

#### 2. A general common expression meaning “become true” for ordinary propositions
**Moderate to strong recurrent restriction**

Weak/absent or replaced by other strategies in:
- **ka**
- **yo**
- **eu**
- **ko**

More available in:
- **fi**: strong
- **id**: possible with menjadi, but often less natural than ternyata/terbukti
- **ta**: structurally possible, but revelation patterns are stronger
- **tr**: possible with olmak, but often other patterns are more idiomatic depending on root

#### 3. Productive positive agentive “truth-teller” parallel to “liar”
**Strong recurrent asymmetry**

Weak/absent or descriptive only in:
- **ka**
- **yo**
- **fi**
- **ta**
- **id**
- **tr**
- **ko**

Only negative or specialized roles are strongly lexicalized in many languages:
- **eu** gezurti
- **ko** 거짓말쟁이
- **yo** ẹlẹ́rìí is witness, not truth-teller
- **fi** todistaja is witness, not truth-teller

#### 4. Productive “become authentic/genuine” pattern
**Moderate recurrent restriction**

Weak/absent in:
- **yo**
- **eu**
- **id** (explicitly absent for **asli**)
- **ko** (explicitly absent for **진짜**)
- **ka** (authenticity mainly checked/established)
- **ta** (authenticity mainly evaluated or checked)
- **tr** (possible with olmak in some contexts, but not highlighted as a strong dedicated pattern)
- **fi** (not generally productive across authenticity adjectives)

#### 5. Productive “make accurate” pattern
**Single-domain recurrent gap**
- explicitly weak/uncertain in **id** for **akurat**
- not highlighted as strong in several others, which instead use “correct,” “verify,” “improve accuracy,” etc.

---

### C. Recurrent patterns of restriction, substitution, or blocking

#### Pattern 1: Revelation replaces inchoative truth
**Strong recurrent pattern**
- ka, yo, eu, ta, tr, ko, and partly fi/id

#### Pattern 2: Verification replaces causative truth
**Strong recurrent pattern**
- ka, yo, eu, ta, id, tr, ko

#### Pattern 3: Institutional status change is easier than truth-state change
**Strong recurrent pattern**
- especially **id, tr, ko, fi**
- “become invalid / be declared valid / be considered valid” is often more natural than “become true”

#### Pattern 4: Negative side often more richly lexicalized than positive side
**Moderate recurrent pattern**
- fake/forged/false often has strong dedicated lexemes
- positive side may be analytic, domain-split, or checked procedurally

#### Pattern 5: Positive dynamic causation is often blocked where negative causation is lexicalized
**Moderate recurrent pattern**
- e.g. **memalsukan** is strong in Indonesian, but “make genuine” is weak
- **무효로 하다** is strong in Korean, but “make true” is weak
- Tamil has strong **சரிசெய்**, but not a parallel broad “make true”
- Finnish has **tehdä uskottavaksi**, but not a broad “make true” across the field

## 4. Cross-language asymmetry summary

### A. One side richly lexicalized, the other analytic or weak

#### 1. Fake/false often stronger than positive “genuine” dynamics
- **id**: strong **palsu, memalsukan, pemalsuan**, but no common “become asli”
- **ko**: strong **가짜, 위작, 무효**, but weak direct “become true/genuine”
- **ta**: strong **பொய், பொய்யாகி போ**, but no equally strong general “make true”
- **fi**: strong **epätosi**, **väärennös**, **paljastua väärennökseksi**, but no equally broad dynamic for all positive authenticity adjectives

#### 2. Liar often lexicalized, truth-teller often descriptive
- **eu**: **gezurti** vs no equally central positive counterpart
- **ko**: **거짓말쟁이** vs descriptive **정직한 사람**
- **ta**: **பொய் சொல்பவன்** / **உண்மை பேசுபவர்** both descriptive, but no compact positive lexicalized counterpart
- **ka**, **fi**, **yo**, **id** show similar asymmetry in the supplied data

---

### B. Productive derivation on one side, weak derivation on the other

#### 1. Validity systems are often morphologically productive
Strong in:
- **id**: sah/absah/valid families
- **tr**: geçerli/geçersiz, meşru/gayrimeşru
- **ko**: 유효/무효, 정당성, 타당성
- **fi**: multiple validity/legality families

But equivalent productivity for plain truth-state change is often weaker.

#### 2. Correction/verification verbs are productive where truth-causatives are not
Strong in:
- **eu**: egiaztatu, zuzendu
- **ta**: சரிபார், சரிசெய், உறுதிப்படுத்து
- **id**: membetulkan, menyesuaikan, mencocokkan, memvalidasi
- **tr**: doğrulamak
- **ko**: 확인하다, 밝히다, 무효로 하다

---

### C. Domains resisting construction types natural elsewhere

#### 1. Truth resists simple “become” in several languages
- **ka, yo, eu, ko** especially
- these languages prefer revelation/checking/confirmation

#### 2. Authenticity resists productive inchoative/causative patterns
- **id** explicitly for **asli**
- **ko** for **진짜**
- **eu** and **yo** also weak here
- **ka** and **ta** prefer checking/establishing authenticity

#### 3. Reliability often resists direct causative derivation
- **id** explicitly lacks common “make reliable” from **andal**
- **tr** lacks clear common causative “make güvenilir”
- **ko** uses gaining trust / securing reliability rather than direct causative
- **ta** has clearer negative dynamic loss than positive causation

#### 4. Positive truth-state change is less natural than negative institutional change
- “become invalid” is often easy:
  - **ko** 무효가 되다
  - **id** menjadi tidak valid
  - **tr** geçersiz olmak
  - **fi** osoittautua epätodeksi / invalidity-like resultatives
- but “become true” is often weaker or replaced

---

## Final cross-language conclusion

From F5 and F6 alone, the clearest cross-language result is:

### Strong recurrent patterns
- lexical contrasts for **truth vs falsehood**
- lexical contrasts for **genuine vs fake**
- morphological or analytic contrasts for **correct vs incorrect**, **valid vs invalid**
- constructional contrasts for **reveal vs hide truth**
- strong preference for **verification, revelation, confirmation, and institutional recognition**
- strong use of **scalar/evidentially graded negatives** in some languages, especially Indonesian

### Moderate patterns
- reliability vs credibility contrasts
- resemblance vs identity contrasts
- partial-truth constructions
- dynamic “become X” patterns, but only in some domains/languages

### Recurrent absences / blockings
- no broadly shared common construction for **“make X true”**
- no broadly shared strong everyday construction for **“become true”** in several languages
- no broadly shared symmetrical lexical pair **liar / truth-teller**
- authenticity and reliability often resist the same dynamic constructions that validity supports

So the major asymmetry is not just lexical but structural:
many languages are much better at expressing that truth is **revealed, checked, confirmed, denied, concealed, or institutionally recognized** than at expressing that something simply **becomes true** or is **made true**.
