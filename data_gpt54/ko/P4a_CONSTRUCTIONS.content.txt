## 1. ATTRIBUTION
### Pattern
**N(이/가) 사실이다 / 진실이다 / 정확하다 / 옳다 / 유효하다**
### Examples
- 그것은 사실이다. → *geugeoseun sasirida* → “That is a fact / That is true.”
- 네 말이 옳다. → *ne mari olta* → “What you said is right.”
### Notes
Korean commonly predicates truth/factuality with a noun + copula (**사실이다, 진실이다**) or with descriptive predicates (**옳다, 정확하다, 유효하다**). Choice depends on domain: factual truth, correctness, legitimacy, or formal validity.

## 2. NEGATIVE ATTRIBUTION
### Pattern
**N(이/가) 아니다 / A-지 않다 / 사실과 다르다 / 허위이다**
### Examples
- 그 말은 사실이 아니다. → *geu mareun sasiri anida* → “That statement is not true / not a fact.”
- 그 보도는 사실과 다르다. → *geu bodoneun sasilgwa dareuda* → “That report differs from the facts / is untrue.”
### Notes
Negation is usually formed analytically with **아니다** or **-지 않다**. Korean also uses contrastive mismatch constructions like **사실과 다르다** and formal falsity labels such as **허위이다**.

## 3. ADNOMINAL MODIFICATION
### Pattern
**A-(으)ㄴ N / N인 N / 관형형: 진정한, 진실한, 정확한, 정당한, 타당한, 유효한**
### Examples
- 진정한 사랑 → *jinjeonghan sarang* → “true/genuine love”
- 정확한 정보 → *jeonghwakan jeongbo* → “accurate information”
### Notes
Truth-domain meanings are very often expressed attributively before nouns. Descriptive predicates take adnominal **-(으)ㄴ**, while copular nouns may appear as **N인 N** in broader syntax.

## 4. BECOME / INCHOATIVE
### Pattern
**N(이/가) 되다 / A-게 되다 / N으로 드러나다**
### Examples
- 계약이 무효가 되었다. → *gyeyagi muhyoga doeeotda* → “The contract became invalid.”
- 그 주장은 거짓으로 드러났다. → *geu jujangeun geojiseuro deureonatda* → “That claim turned out to be false.”
### Notes
Change-of-state is commonly expressed with **되다** for status shifts and **드러나다** for emergence of truth/falsity. Lexical inchoatives like English “falsify/become true” are limited; Korean prefers periphrastic constructions.

## 5. CAUSATIVE (OR ABSENCE)
### Pattern
**N을/를 밝히다 / 확인하다 / 무효로 하다 / 정정하다**
### Examples
- 사실을 확인하다. → *sasireul hwaginhada* → “Confirm the facts.”
- 결정을 무효로 했다. → *gyeoljeongeul muhyoro haetda* → “They invalidated the decision.”
### Notes
There is no single productive causative morphology dedicated to “make true/false/valid” across this domain. Korean instead uses lexical verbs plus complements: **밝히다** ‘reveal’, **확인하다** ‘verify’, **무효로 하다** ‘invalidate’, **정정하다** ‘correct’.

## 6. ABSTRACT NOMINALIZATION
### Pattern
**A-ㅁ/음 / N+성 / N+도**
### Examples
- 정확성이 중요하다. → *jeonghwakseongi jungyohada* → “Accuracy is important.”
- 그의 진실성이 느껴진다. → *geuui jinsilseongi neukkyeojinda* → “His sincerity/authenticity is felt.”
### Notes
Abstract qualities are commonly nominalized with Sino-Korean **-성** (**정확성, 진실성, 정당성, 타당성, 신뢰성**) and sometimes **-도** for measurable degree (**정확도, 신뢰도**). Native-style **-ㅁ/음** exists but is more limited and often formal/literary (**옳음, 참됨**).

## 7. AGENTIVE NOMINALIZATION (LIAR, TRUTH-TELLER)
### Pattern
**(no common expression identified)**
### Examples
- 거짓말쟁이 → *geojinmaljaengi* → “liar”
- 정직한 사람 → *jeongjikhan saram* → “honest person”
### Notes
Korean has a common lexicalized agent noun for “liar” (**거짓말쟁이**), but no equally standard productive truth-domain counterpart meaning “truth-teller.” Positive roles are usually expressed descriptively, e.g. **정직한 사람**, **진실한 사람**.

## 8. EVIDENTIAL / ASSERTIVE CLAUSAL FRAME
### Pattern
**-는 것은 사실이다 / 부인할 수 없는 사실이다 / 사실상 ~이다**
### Examples
- 그가 떠난 것은 사실이다. → *geuga tteonan geoseun sasirida* → “It is true that he left.”
- 이는 부인할 수 없는 사실이다. → *ineun buinhal su eomneun sasirida* → “This is an undeniable fact.”
### Notes
Korean frequently packages truth assertion in clausal nominalization plus **사실이다**. This construction is especially common in formal argumentation, concession, and public statement style.

## 9. VERIFICATION / REVELATION CONSTRUCTION
### Pattern
**N을/를 밝히다 / 확인하다 / 규명하다 / N 여부를 확인하다**
### Examples
- 진실을 밝히다. → *jinsireul balkhida* → “Reveal the truth.”
- 정품 여부를 확인하다. → *jeongpum yeobureul hwaginhada* → “Check whether an item is genuine.”
### Notes
A major Korean truth-domain pattern is procedural: truth is established through acts of revealing, checking, and clarifying. This is especially productive in journalism, law, administration, and authenticity disputes.

## 10. APPEARANCE VS REALITY
### Pattern
**진짜/가짜 같다 / ~처럼 보이다 / 실체가 드러나다**
### Examples
- 진짜처럼 보인다. → *jinjjacheoreom boinda* → “It looks real.”
- 그 조직의 실체가 드러났다. → *geu jojigui silchega deureonatda* → “The true nature of that organization was revealed.”
### Notes
Korean often distinguishes seeming from being through appearance predicates (**같다, 보이다**) and reality nouns like **실체**. This constructional contrast is central for authenticity, deception, and hidden-truth discourse.
