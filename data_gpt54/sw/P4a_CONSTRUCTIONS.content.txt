## 1. ATTRIBUTION
### Pattern
**NP + ni + kweli / uongo / sahihi / batili / halali / haramu / dhahiri**
### Examples
- **Ni kweli.** → *Ni kweli.* → “It is true.”
- **Hii ni sahihi.** → *Hii ni sahihi.* → “This is correct.”
### Notes
The basic predicative pattern uses **ni** plus a truth-domain predicate. It is common for truth, falsity, correctness, validity, lawfulness, and evidentness.

## 2. NEGATIVE ATTRIBUTION
### Pattern
**NP + si + kweli / sahihi**; also **NP + ni + uongo / batili**
### Examples
- **Si kweli.** → *Si kweli.* → “It is not true.”
- **Jibu hili si sahihi.** → *Jibu hili si sahihi.* → “This answer is not correct.”
### Notes
Negation is commonly expressed with **si + predicate**. For stronger rejection, Swahili often uses positive predication with a negative-value noun/adjective, e.g. **ni uongo**, **ni batili**.

## 3. ADNOMINAL MODIFICATION
### Pattern
**Noun + adjective/descriptive form**; especially **N + -kweli / -ongo / sahihi / halisi / bandia / feki / ya asili / -enye haki**
### Examples
- **taarifa sahihi** → *taarifa sahihi* → “accurate information”
- **dawa bandia** → *dawa bandia* → “counterfeit medicine”
### Notes
Truth-domain meanings commonly modify nouns directly. With **-kweli** and related agreeing stems, class agreement may appear; other items like **sahihi, halisi, bandia, feki** are widely used as postnominal modifiers.

## 4. BECOME / INCHOATIVE
### Pattern
**ku- + root + -ika** for “be/become credible”; otherwise **(no common expression identified)**
### Examples
- **Taarifa hii inaaminika.** → *Taarifa hii inaaminika.* → “This report is credible.”
- **Chanzo hicho hakiaminiki.** → *Chanzo hicho hakiaminiki.* → “That source is not credible.”
### Notes
A clear inchoative/stative pattern is attested with **-amini- → -aminika** ‘be credible, be trustworthy’. No equally common inchoative verb is identified for **kweli**, **uongo**, or **sahihi** in the supplied data.

## 5. CAUSATIVE (OR ABSENCE)
### Pattern
**(no common expression identified)**; periphrastic **kutia imani** for causing confidence
### Examples
- **Hotuba yake ilitia imani.** → *Hotuba yake ilitia imani.* → “His speech inspired confidence.”
- **Kiongozi huyo anatia imani.** → *Kiongozi huyo anatia imani.* → “That leader inspires confidence.”
### Notes
No productive causative dedicated to “make true/correct” is established in the data. The nearest common causative-like construction is periphrastic **kutia imani** ‘instill confidence’.

## 6. ABSTRACT NOMINALIZATION
### Pattern
**u- + stem** → **ukweli, usahihi, uaminifu, uhalisia**
### Examples
- **ukweli** → *ukweli* → “truth”
- **usahihi wa taarifa** → *usahihi wa taarifa* → “accuracy of information”
### Notes
Abstract truth-domain nouns are commonly formed with **u-**. These nouns denote qualities or states such as truth, correctness, trustworthiness, and reality/authenticity.

## 7. AGENTIVE NOMINALIZATION (LIAR, TRUTH-TELLER)
### Pattern
**m-/mw- + stem** → **mkweli, mwongo, mwaminifu**
### Examples
- **mwongo** → *mwongo* → “liar”
- **mkweli** → *mkweli* → “truthful/honest person”
### Notes
Person-denoting nouns are formed with **m-/mw-**. These encode stable character roles such as liar, truthful person, or trustworthy/faithful person.

## 8. PROPOSITIONAL COMPLEMENT WITH “THAT”
### Pattern
**kuamini / ni dhahiri / ukweli ni kwamba + kwamba + clause**
### Examples
- **Ninaamini kwamba atasema ukweli.** → *Ninaamini kwamba atasema ukweli.* → “I believe that he will tell the truth.”
- **Ni dhahiri kwamba ni uongo.** → *Ni dhahiri kwamba ni uongo.* → “It is evident that it is a lie.”
### Notes
Truth-related predicates commonly take clausal complements with **kwamba**. This is a major structure for belief, evidential assessment, and explicit truth-framing.

## 9. TRUTH / FALSEHOOD AS LIGHT-VERB OBJECT
### Pattern
**kusema / sema + ukweli / uongo**
### Examples
- **Sema ukweli.** → *Sema ukweli.* → “Tell the truth.”
- **Alisema uongo.** → *Alisema uongo.* → “He/she told a lie.”
### Notes
Swahili often expresses truth-telling and lying with a light verb plus noun: **sema/kusema + ukweli/uongo**. This is the ordinary verbal strategy rather than a simple lexical verb pair.

## 10. GENITIVE QUALITY CONSTRUCTION
### Pattern
**N + wa/ya/za + ukweli / uongo / asili**
### Examples
- **habari za uongo** → *habari za uongo* → “false news”
- **bidhaa ya asili** → *bidhaa ya asili* → “natural/authentic product”
### Notes
A productive genitive construction links a noun to truth-domain qualities or source/status nouns. It is especially common for falsity (**za uongo**) and authenticity/origin (**ya asili**).
