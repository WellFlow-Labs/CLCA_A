## 1. ATTRIBUTION
### Pattern
**X (is) ADJ / N + enclitic** for predicative evaluation: e.g. **chiqaq** ‘true/real’, **allin(mi)** ‘right/correct’, **pantasqa** ‘mistaken’, **huchayuq** ‘guilty’.

### Examples
- **allinmi** → *allinmi* → ‘it is right / correct’
- **pantasqa** → *pantasqa* → ‘it is mistaken / wrong’

### Notes
Quechua commonly uses adjectival or participial forms predicatively without a separate copula in simple evaluative statements. The assertive/evidential enclitic **-mi** can strengthen the predication, as in **allinmi**.

## 2. NEGATIVE ATTRIBUTION
### Pattern
**mana + ADJ** for negative predicative evaluation.

### Examples
- **mana allin** → *mana allin* → ‘not right; wrong; improper’
- **mana chiqaq** → *mana chiqaq* → ‘not true; not real’ *(pattern-level extension from core adjective)*

### Notes
The basic negative attributive pattern is formed with preverbal/preadjectival **mana**. In the provided data, **mana allin** is the clearly established common expression; extension to other evaluative adjectives is structurally natural but less directly supported.

## 3. ADNOMINAL MODIFICATION
### Pattern
**ADJ/N + N**: truth/falsity or character term modifies a following noun.

### Examples
- **llulla runa** → *llulla runa* → ‘liar; deceitful person’
- **llulla simi** → *llulla simi* → ‘false speech; lie’

### Notes
A truth-domain modifier commonly precedes the noun it qualifies. This pattern is used both for propositional content (**… simi**) and person characterization (**… runa**).

## 5. CAUSATIVE
### Pattern
**Root + causative derivation** or **N-man + churay** ‘put into X’ for causing error.

### Examples
- **pantachiy** → *pantachiy* → ‘to mislead; cause to err’
- **pantayman churay** → *pantayman churay* → ‘to lead into error; misdirect’

### Notes
Causation is clearly attested in the error domain, especially from **pantay** ‘error’. Both a derived causative verb and a periphrastic directional construction are represented.

## 6. ABSTRACT NOMINALIZATION
### Pattern
**ADJ + kay** for abstract ‘truth/reality’ type nominalization.

### Examples
- **chiqaq kay** → *chiqaq kay* → ‘truth; reality; true nature’
- **hucha** → *hucha* → ‘fault; guilt; sin’ *(lexical abstract noun rather than productive nominalization)*

### Notes
The clearest abstract construction in the dataset is **chiqaq kay**, literally ‘true being’. Other abstract meanings such as **hucha** are lexical nouns, not transparently derived by the same productive pattern in the provided material.

## 7. AGENTIVE NOMINALIZATION (LIAR, TRUTH-TELLER)
### Pattern
**Root + -q** or **modifier + runa** for person characterized by lying/deception.

### Examples
- **llullaq** → *llullaq* → ‘liar; one who lies’
- **llulla runa** → *llulla runa* → ‘liar; deceitful person’

### Notes
Agentive/person-characterizing formation is well supported for the falsehood domain. No equally secure truth-teller counterpart is provided in the source material, so only the lying/deception side is included.

## 8. ADVERBIAL TRUTH-ASSERTION
### Pattern
**Adverbial form of truth adjective** used to reinforce assertion.

### Examples
- **chiqap** → *chiqap* → ‘truly; really; in truth’
- **chiqaqta** → *chiqaqta* → ‘truly; really’ 

### Notes
Quechua uses adverbialized truth forms to modify the whole proposition rather than a noun. In the supplied material, **chiqap** is core and **chiqaqta** is a less certain but structurally similar variant.

## 9. SPEECH-SPECIFIC TRUTH/FALSEHOOD NOUN PHRASES
### Pattern
**truth/falsity modifier + simi** ‘word, speech’.

### Examples
- **chiqaq simi** → *chiqaq simi* → ‘true word; truthful speech’
- **llulla simi** → *llulla simi* → ‘false speech; lie’

### Notes
This construction specializes truth-domain evaluation to speech content. It is especially suited to moral, rhetorical, or elevated discourse about truthful versus deceptive utterance.
