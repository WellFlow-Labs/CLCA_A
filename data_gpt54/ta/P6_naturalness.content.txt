## 1. BECOME: TRUTH / REALITY BECOMES ESTABLISHED OR APPARENT
### Pattern
**X + உண்மை ஆகு / நிஜம் ஆகு**; more naturally in the provided data: **உண்மை வெளிவரு, உண்மை தெரியவரு**

### Examples
- அது உண்மை ஆகிறது. → *atu uṇmai ākiṟatu.* → “That becomes true / turns out to be true.”
- பிறகு உண்மை தெரியவருகிறது. → *piṟaku uṇmai teriyavarukiṟatu.* → “Later the truth becomes known.”
- இறுதியில் உண்மை வெளிவந்தது. → *iṟutiyil uṇmai veḷivantatu.* → “In the end the truth came out.”

### Notes
From the context, the most clearly established dynamic expressions are not primarily “become true” in a strict morphological sense, but rather **truth emerging or becoming known**:
- **உண்மை வெளிவரு**
- **உண்மை தெரியவரு**

A form like **அது உண்மை ஆகிறது** is structurally possible using allowed vocabulary plus **ஆகு**, but the context more strongly supports the emergence-type constructions above.

## 2. BECOME: CORRECT / ACCEPTABLE STATE
### Pattern
**X + சரி ஆகு**

### Examples
- எல்லாம் சரி ஆகும். → *ellām cari ākum.* → “Everything will become okay / right.”
- இது பிறகு சரி ஆகும். → *itu piṟaku cari ākum.* → “This will become okay later.”

### Notes
This is one of the clearest and most natural dynamic patterns in the dataset. With **சரி**, Tamil readily encodes movement into a good, acceptable, corrected, or functioning state by using **ஆகு**.

This pattern is broader than factual truth alone: it often means “become okay,” “be fixed,” or “come right.”

## 3. BECOME: FALSE / NON-TRUE STATE
### Pattern
**X + பொய்யாகி போ**

### Examples
- அந்தக் கூற்று பொய்யாகி போனது. → *antak kūṟṟu poyyāki pōnatu.* → “That claim turned out to be false.”
- அது பொய்யாகி போயிற்று. → *atu poyyāki pōyiṟṟu.* → “It ended up being false.”

### Notes
This is the strongest attested “become non-truth” pattern in the context. It expresses retrospective falsification or failure of a claim, expectation, or report.

The construction is more specific than simple negation:
- not just “is not true”
- but “turned out false”

## 4. BECOME: NOT CORRECT / NOT ADEQUATE
### Pattern
**X + சரி வரவில்லை**; also static-negative result states **சரியில்லை / சரியல்ல**

### Examples
- இது சரி வரவில்லை. → *itu cari varavillai.* → “This did not come out right.”
- அது சரியில்லை. → *atu cariyillai.* → “That is not right / not correct.”

### Notes
For **சரி**, Tamil often uses dynamic failure expressions rather than a neat opposite “become wrong” form:
- **சரி வரவில்லை** = “did not come out right”
- **சரியில்லை / சரியல்ல** = resulting non-correct state

A direct common expression from the context equivalent to “X becomes தவறு” is **not clearly identified**.

## 5. CAUSE: MAKE SOMETHING CORRECT / SET IT RIGHT
### Pattern
**X + சரிசெய்**; nominalized **சரிசெய்தல்**

### Examples
- பிழையை சரிசெய். → *piḻaiyai caricey.* → “Correct the error.”
- அதை சரி செய்து கொள். → *atai cari ceytu koḷ.* → “Fix it / set it right.”

### Notes
This is the clearest causative-style pattern in the correctness domain. Tamil uses a light-verb construction rather than a single dedicated verb meaning “make correct.”

This is strongly attested and highly natural.

---

## 6. CAUSE: CONFIRM / ESTABLISH AS CERTAIN
### Pattern
**X + உறுதி செய் / உறுதி படுத்து**

### Examples
- செய்தியை உறுதி செய். → *ceytiyai uṟuti cey.* → “Verify / confirm the news.”
- தகவலை உறுதிப்படுத்து. → *takavalai uṟuti paṭuttu.* → “Confirm the information.”
- அவர்கள் தகவலை உறுதி செய்தார்கள். → *avarkaḷ takavalai uṟuti ceytārkaḷ.* → “They confirmed the information.”

### Notes
These constructions do not literally mean “make true.” Rather, they mean:
- confirm
- establish firmly
- verify as certain

So the causation here is epistemic/procedural, not ontological.

## 8. CAUSE: HIDE OR BLOCK TRUTH
### Pattern
**உண்மையை மறை**

### Examples
- அவர்கள் உண்மையை மறைத்தார்கள். → *avarkaḷ uṇmaiyai maṟaittārkaḷ.* → “They hid the truth.”
- உண்மையை மறைக்காதே. → *uṇmaiyai maṟaikkātē.* → “Do not hide the truth.”

### Notes
This is a dynamic expression involving truth vocabulary, but in the opposite direction from revelation. It encodes active concealment of truth.

It contrasts with:
- **உண்மை வெளிவரு**
- **உண்மை தெரியவரு**
- **உண்மையை ஒப்பு கொள்**
- **உண்மையை ஏற்று கொள்**

## 9. CHANGE IN SPEAKER STANCE TOWARD TRUTH
### Pattern
**உண்மையை ஒப்பு கொள் / உண்மையை ஏற்று கொள் / உண்மை தெரிந்து கொள்**

### Examples
- அவன் உண்மையை ஒப்பு கொண்டான். → *avaṉ uṇmaiyai oppu koṇṭāṉ.* → “He admitted the truth.”
- அவள் உண்மையை ஏற்று கொண்டாள். → *avaḷ uṇmaiyai ēṟṟu koṇṭāḷ.* → “She accepted the truth.”
- அவர்கள் உண்மை தெரிந்து கொண்டார்கள். → *avarkaḷ uṇmai terintu koṇṭārkaḷ.* → “They came to know the truth.”

### Notes
These do not mean that truth itself changes. Instead, they encode a change in:
- acknowledgment
- acceptance
- knowledge state

So Tamil often handles “truth dynamics” through changes in access to truth, not only changes in truth-status itself.

## 10. CHANGE IN CREDIBILITY / RELIABILITY
### Pattern
**நம்பகத்தன்மையை இழக்கு**; also evaluative establishment with **நம்பகமான**, **நம்பகத்தன்மை கொண்ட**

### Examples
- அது நம்பகத்தன்மையை இழந்தது. → *atu nampakattaṉmaiyai iḻantatu.* → “It lost credibility.”
- நம்பகமான ஆதாரம் வேண்டும். → *nampakamāṉa ātāram vēṇṭum.* → “A reliable source is needed.”

### Notes
The clearest dynamic expression here is loss:
- **நம்பகத்தன்மையை இழக்கு** = “lose credibility”

A direct common expression in the context for “cause X to become reliable” is **not clearly identified**.

So:
- dynamic negative change is clearly attested
- dynamic positive causation is not equally clear in the provided material

## 11. CHANGE IN AGREEMENT / CORRESPONDENCE
### Pattern
**ஒத்துப் போ / ஒத்துவரு**; negative state **ஒற்றுமை இல்லை**

### Examples
- அது மூலத்துடன் ஒத்துப் போகிறது. → *atu mūlattuṭaṉ ottup pōkiṟatu.* → “It matches the original.”
- இது அதுடன் ஒத்துவரவில்லை. → *itu atuṭaṉ ottuvaravillai.* → “This does not correspond with that.”
- இவற்றுக்கு ஒற்றுமை இல்லை. → *ivaṟṟukku oṟṟumai illai.* → “There is no agreement / consistency between these.”

### Notes
These expressions encode dynamic or relational fit rather than truth in a narrow sense. Still, they are important in the truth-related domain because they describe:
- matching
- correspondence
- consistency with a source or account

## 12. MENTAL / SPIRITUAL ATTAINMENT OF TRUE REALIZATION
### Pattern
**மெய்யுணர்வு அடை / மெய்ஞ்ஞானம் பெறு / மெய்ப்பொருள் காண்**

### Examples
- அவன் மெய்யுணர்வு அடைந்தான். → *avaṉ meyyuṇarvu aṭaintāṉ.* → “He attained true realization.”
- அவர்கள் மெய்ஞ்ஞானம் பெற்றார்கள். → *avarkaḷ meyññāṉam peṟṟārkaḷ.* → “They attained true knowledge.”
- மெய்ப்பொருள் காண வேண்டும். → *meypporuḷ kāṇa vēṇṭum.* → “One must grasp the true meaning / essential reality.”

### Notes
With **மெய்**-based vocabulary, Tamil often encodes truth dynamics as:
- attainment
- realization
- insight
- grasping essential meaning

This is distinct from everyday factual truth expressions built on **உண்மை**.

## 15. SUMMARY OF MAIN DYNAMIC PATTERNS
### Most clearly attested
- **சரி ஆகு** — become okay / right
- **பொய்யாகி போ** — turn out false
- **சரிசெய்** — make right / correct
- **உறுதி செய் / உறுதிப்படுத்து** — confirm / establish firmly
- **உண்மை வெளிவரு / உண்மை தெரியவரு** — truth comes out / becomes known
- **உண்மையை மறை** — hide the truth
- **உண்மையை ஒப்பு கொள் / ஏற்று கொள்** — admit / accept the truth
- **நம்பகத்தன்மையை இழக்கு** — lose credibility
- **ஒத்துப் போ / ஒத்துவரு** — match / correspond
- **மெய்யுணர்வு அடை / மெய்ஞ்ஞானம் பெறு** — attain true realization / true knowledge

### Important asymmetry
Tamil, in the provided material, does **not** treat all truth-related terms alike:
- **சரி** strongly supports change-of-state and causative repair
- **பொய்** strongly supports “turn out false”
- **உண்மை** strongly supports emergence, discovery, admission, concealment
- **உறுதி** supports confirmation rather than “making true”
- **மெய்** supports realization/attainment in philosophical-religious usage
- **தவறு** is less clearly dynamic in the provided evidence
