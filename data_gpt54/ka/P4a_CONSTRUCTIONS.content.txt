## 1. ATTRIBUTION
### Pattern
**N/Clause + copula + truth/correctness adjective**: **მართალი / სწორი / ნამდვილი / ჭეშმარიტი / სარწმუნო / ზუსტი**
### Examples
- ეს მართალია. → *es martalia* → “This is true / right.”
- ეს სწორი არ არის. → *es sts’ori ar aris* → “This is not correct / right.”
### Notes
Georgian commonly predicates truth/correctness with an adjective plus copular structure. Different adjectives specialize by domain: **მართალი** ‘right/true’, **სწორი** ‘correct’, **ნამდვილი** ‘real/genuine’, **ზუსტი** ‘accurate’, etc.

## 2. NEGATIVE ATTRIBUTION
### Pattern
**N/Clause + ar ‘not’ + copula + adjective**; also positive predicate with negative adjective such as **ყალბი**
### Examples
- ეს სიმართლეს არ შეესაბამება. → *es simartles ar sheesabameba* → “This does not correspond to the truth.”
- ეს დოკუმენტი ყალბია. → *es dokument’i q’albia* → “This document is fake.”
### Notes
Negation is often formed analytically with **არ** in the predicate. For authenticity/falsity, Georgian also uses direct negative-value adjectives like **ყალბი** rather than only negating a positive adjective.

## 3. ADNOMINAL MODIFICATION
### Pattern
**Adjective + noun** with truth/authenticity/correctness adjective modifying a noun
### Examples
- სწორი პასუხი → *sts’ori pasuxi* → “correct answer”
- ნამდვილი დოკუმენტი → *namdvili dokument’i* → “authentic document”
### Notes
This is a very productive pattern. The adjective directly modifies entities such as answers, documents, reasons, sources, evidence, love, friend, etc.

## 5. CAUSATIVE (OR ABSENCE)
### Pattern
**Cause/establish/justify + truth noun or derived verb/noun**; especially **დადგენა**, **გამართლება**
### Examples
- სიმართლის დადგენა → *simartlis dadgena* → “establishing the truth”
- გაამართლა მოლოდინი. → *gaamartla molodini* → “It justified / lived up to expectations.”
### Notes
A dedicated causative “make true” pattern is not prominent in the data. Instead, Georgian uses lexical verbs for ‘establish truth’ and derivations from **მართ-** such as **გამართლება / გაამართლა** for ‘justify, vindicate, prove right’.

## 6. ABSTRACT NOMINALIZATION
### Pattern
**Adjective/root + abstract nominal suffixes**: **-ება, -ობა, si-...-e**
### Examples
- მართალი → სიმართლე → *martali → simartle* → “right/true” → “truth”
- ნამდვილი → ნამდვილობა → *namdvili → namdviloba* → “genuine” → “genuineness/authenticity”
### Notes
Abstract truth-domain nouns are very common and structurally central in Georgian. Several formations are attested: inherited abstract nouns (**სიმართლე**), and productive-looking suffixal nouns such as **-ება** and **-ობა**.

## 8. TRUTH-TELLING LIGHT-VERB CONSTRUCTION
### Pattern
**Truth noun in genitive + თქმა ‘saying/telling’**
### Examples
- სიმართლის თქმა → *simartlis tkma* → “telling the truth”
- ჭეშმარიტების თქმა → *č’eshmarit’ebis tkma* → “speaking the truth”
### Notes
This is a core verbal-nominal construction for truth-telling. **სიმართლის თქმა** is the neutral/common form; **ჭეშმარიტების თქმა** is more elevated.

## 9. FRANKNESS / DISCOURSE-MARKER CONSTRUCTION
### Pattern
**Truth/right adjective or noun + ‘tell you / say’ formula**
### Examples
- სიმართლე გითხრათ. → *simartle gitxrat* → “To tell you the truth.”
- მართალი რომ ვთქვა. → *martali rom vtkva* → “Honestly / to tell the truth.”
### Notes
These are fixed discourse-organizing constructions used to introduce candid opinion or admission. They are structurally clause-like but function pragmatically as stance markers.

## 10. CORRESPONDENCE-TO-TRUTH CONSTRUCTION
### Pattern
**X + სიმართლეს + შეესაბამება / არ შეესაბამება**
### Examples
- ეს სიმართლეს შეესაბამება. → *es simartles sheesabameba* → “This corresponds to the truth.”
- ეს სიმართლეს არ შეესაბამება. → *es simartles ar sheesabameba* → “This does not correspond to the truth.”
### Notes
This is a formal evaluative construction for factual correspondence. It is especially suited to official, journalistic, legal, and argumentative contexts.

## 11. VERIFICATION / ESTABLISHMENT CONSTRUCTION
### Pattern
**Abstract truth/authenticity noun + დადგენა / შემოწმება**
### Examples
- ნამდვილობის დადგენა → *namdvilobis dadgena* → “establishing authenticity”
- სიზუსტის შემოწმება → *sizust’is shemots’meba* → “checking accuracy”
### Notes
Georgian frequently packages truth-domain meanings in procedural nominal constructions. These are common in legal, investigative, technical, and administrative registers.
