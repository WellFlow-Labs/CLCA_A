## 1. BECOMING TRUE / VALID / CORRECT

### Pattern
**X + सत्यतां गच्छति**  
“X becomes true / proves true.”

### Examples
- **सत्यतां गच्छति** → *satyatāṃ gacchati* → “It proves true / comes to be true.”
- **प्रमा जायते** → *pramā jāyate* → “Valid cognition arises.”
- **प्रमा भवति** → *pramā bhavati* → “It is / becomes valid cognition.”

### Notes
Within the provided material, the clearest dynamic expression for “becoming true” is **सत्यतां गच्छति**. This is marked in the context as more formal or scholastic and not the dominant everyday pattern.

For epistemic correctness of cognition, the **प्रमा** family gives dynamic expressions such as **प्रमा जायते** “valid cognition arises.” This is natural in philosophical discourse, but it is specific to cognition, not a general “become true” verb for all truth terms.

No equally clear common “becomes true” construction is explicitly provided for **सत्य**, **तथ्य**, **भूतार्थ**, or **तत्त्व** beyond ordinary predication.

## 2. BECOMING FACTUALLY ACCURATE / REAL

### Pattern
**X + यथार्थं / यथार्थतः** with verbs of knowing or describing, rather than a dedicated “become” verb

### Examples
- **यथार्थं जानाति** → *yathārthaṃ jānāti* → “He/she knows correctly / knows the real state of affairs.”
- **यथार्थं वर्णयति** → *yathārthaṃ varṇayati* → “He/she describes accurately.”
- **भूतार्थं निरूपयति** → *bhūtārthaṃ nirūpayati* → “He/she determines the actual state of affairs.”

### Notes
For **यथार्थ** and **भूतार्थ**, the context mainly shows dynamic expressions of **arriving at**, **grasping**, or **stating** reality, not a common inchoative pattern meaning “becomes accurate/real.”

So Sanskrit here encodes the dynamics less as “X becomes yathārtha” and more as:
- someone **knows** correctly,
- **describes** accurately,
- or **determines** the actual facts.

No common expression is explicitly identified in the context for:
- **यथार्थतां गच्छति**
- **भूतार्थतां गच्छति**

So these should not be assumed.

## 3. BECOMING FALSE / INVALID / NON-VERIDICAL

### Pattern
**No common inchoative expression explicitly identified** for most negative terms.

### Examples
- **अयथार्थज्ञान** → *ayathārthajñāna* → “false knowledge; erroneous cognition”
- **मिथ्या ज्ञानम्** → *mithyā jñānam* → “false knowledge; erroneous cognition”
- **असत्यं वदति** → *asatyaṃ vadati* → “He/she speaks falsehood.”
- **अनृतं वदति** → *anṛtaṃ vadati* → “He/she speaks falsehood.”

### Notes
The provided material gives strong vocabulary for **being false** or **speaking falsely**, but not a clear common dynamic construction meaning:
- “X becomes false,”
- “X turns into falsehood,”
- “cognition becomes erroneous.”

Instead, Sanskrit in this dataset tends to encode the opposed state lexically:
- **असत्य**
- **अनृत**
- **अयथार्थ**
- **मिथ्या**
- **मृषा**
- **अप्रामाण्य**
- **अप्रमाण**

Thus, for “becoming false/invalid,” **no common expression is explicitly identified** in the context.

## 4. CAUSING SOMETHING TO BECOME TRUE / VALID

### Pattern
**No single common productive causative pattern identified**

### Examples
- **प्रमाणीकृतम्** → *pramāṇīkṛtam* → “authenticated / validated”
- **प्रमाणीकरणम्** → *pramāṇīkaraṇam* → “authentication / validation”

### Notes
The context explicitly states that there is **no single common productive causative pattern** meaning “make true” or “make valid” across this lexical field.

Where causation-like meaning does appear, it is mainly in the **प्रमाण** family:
- **प्रमाणीकृतम्** for “made authoritative / validated”
- **प्रमाणीकरणम्** for “the act of validating / authenticating”

These are technical and lexicalized, especially in administrative, textual, or procedural contexts. They do **not** justify assuming parallel causatives for all truth terms.

No common expression is explicitly identified in the context for:
- “make something satya”
- “make something yathārtha”
- “make something tattva”

## 5. CAUSING OR ESTABLISHING VALIDITY BY PROOF

### Pattern
**प्रमाणेन + सिद्धम्**  
“established by valid proof”

### Examples
- **प्रमाणेन सिद्धम्** → *pramāṇena siddham* → “Established by valid proof.”
- **प्रमाणैरवगम्यते** → *pramāṇair avagamyate* → “It is known through valid means of knowledge.”
- **प्रमाणसिद्ध** → *pramāṇasiddha* → “established by valid proof”
- **प्रमाणसिद्धि** → *pramāṇasiddhi* → “establishment by proof”

### Notes
This is one of the clearest dynamic zones in the dataset. Sanskrit often encodes not “making true” but **establishing**, **showing**, or **grounding** something as valid through **प्रमाण**.

So the dynamic is epistemic rather than transformational:
- a claim is **established by proof**,
- an object is **known through pramāṇas**,
- a conclusion is **pramāṇasiddha**.

This is especially natural in philosophical and scholastic prose.

## 6. DYNAMIC EXPRESSIONS OF TRUTHFUL OR FALSE SPEECH

### Pattern
**truth/falsity term + वद् / ब्रू / भाष्**

### Examples
- **सत्यं वद** → *satyaṃ vada* → “Speak the truth.”
- **सत्यं ब्रूते / सत्यं ब्रवीति** → *satyaṃ brūte / satyaṃ bravīti* → “He/she speaks the truth.”
- **मिथ्या वदति** → *mithyā vadati* → “He/she speaks falsely.”
- **मृषा वदति** → *mṛṣā vadati* → “He/she speaks falsely.”
- **मृषा भाषते** → *mṛṣā bhāṣate* → “He/she speaks untruly.”
- **असत्यं वदति** → *asatyaṃ vadati* → “He/she speaks falsehood.”
- **अनृतं वदति** → *anṛtaṃ vadati* → “He/she speaks falsehood.”

### Notes
This is a strongly dynamic part of the system. Sanskrit often encodes truth not as a changing state of propositions, but as an **action of speaking truth or falsehood**.

This domain is lexically differentiated:
- **सत्यं वद** = positive ethical injunction
- **मिथ्या / मृषा / असत्यं / अनृतं वदति** = false speaking, with different stylistic or semantic shades

So one important dynamic encoding is not “become true,” but **“utter truth / utter falsehood.”**

## 7. STABILITY IN TRUTH AS A MAINTAINED STATE

### Pattern
**truth-related noun in locative + स्थितः / प्रतिष्ठितः**  
or ethical commitment nouns

### Examples
- **सत्ये स्थितः / सत्ये प्रतिष्ठितः** → *satye sthitaḥ / satye pratiṣṭhitaḥ* → “established in truth; standing in truth”
- **सत्यवचने स्थितः** → *satyavacane sthitaḥ* → “steadfast in truthful speech”
- **सत्यपालन** → *satyapālana* → “observance of truth; keeping truth”
- **सत्यनिष्ठ** → *satyaniṣṭha* → “steadfast in truth”
- **सत्यपरायण** → *satyaparāyaṇa* → “devoted to truth”

### Notes
The dataset shows a clear way of encoding **stability** rather than change:
- being **established in truth**
- being **steadfast in truthful speech**
- **maintaining** truth
- being **devoted** to truth

This is especially important for ethical and characterological usage. Sanskrit here often prefers a stable moral posture over a dynamic “becoming truthful” expression.

No common explicit inchoative expression like “becomes truthful” is identified in the context for these forms; instead, the language emphasizes:
- standing in truth,
- keeping truth,
- being devoted to truth.

## 8. DEVIATION FROM TRUTH / FAILURE TO REMAIN IN IT

### Pattern
**X-ablative + na pramaditavyam**

### Examples
- **सत्यात् न प्रमदितव्यम्** → *satyāt na pramaditavyam* → “One must not deviate from truth.”

### Notes
This is a dynamic negative-stability expression: not becoming false exactly, but **not lapsing from truth**.

It is important because it shows Sanskrit can encode truth dynamically as a norm of **continued adherence**, not only as a property of statements.

This construction is specifically attested for **सत्य**, and the context does not provide parallel common expressions for other truth terms.

## 9. TRUTH AS ESSENTIAL OR FACTUAL STANCE RATHER THAN CHANGE

### Pattern
**adverbial forms in -तः / instrumental adverbials**

### Examples
- **यथार्थतः** → *yathārthataḥ* → “in reality; as a matter of fact”
- **तत्त्वतः** → *tattvataḥ* → “truly; in reality; in principle”
- **स्वरूपतः** → *svarūpataḥ* → “essentially; by its very nature”
- **भूतार्थेन** → *bhūtārthena* → “in accordance with the actual facts”
- **तत्त्वेन** → *tattvena* → “truly; in accordance with reality”

### Notes
These are dynamic only in a weak sense: they do not mean “become true,” but they mark a shift in discourse to the standpoint of reality, essence, or fact.

So another Sanskrit strategy is not transformation but **reframing**:
- “in reality,”
- “essentially,”
- “according to the facts.”

This is especially common in philosophical and analytical prose.

## 10. SUMMARY OF WHAT IS AND IS NOT COMMONLY ENCODED

### Clearly supported dynamic patterns
- **becoming true**: **सत्यतां गच्छति**
- **arising of valid cognition**: **प्रमा जायते**
- **establishment by proof**: **प्रमाणेन सिद्धम्**, **प्रमाणसिद्ध**
- **speaking truth / falsehood**: **सत्यं वद**, **मिथ्या वदति**, **अनृतं वदति**, etc.
- **remaining grounded in truth**: **सत्ये स्थितः**, **सत्यपालन**, **सत्यनिष्ठ**
- **not deviating from truth**: **सत्यात् न प्रमदितव्यम्**

### No common expression explicitly identified
- a general productive pattern for **“X becomes false”**
- a general productive pattern for **“Y makes X true”**
- parallel causatives across all truth-related stems
- a clearly attested common inchoative for **यथार्थ**, **भूतार्थ**, **तत्त्व**, **स्वरूप** comparable to **सत्यतां गच्छति**

Overall, the provided Sanskrit material encodes truth dynamics mainly through:
1. **speech acts**,
2. **epistemic establishment by proof**,
3. **arising of valid cognition**,
4. **stable adherence to truth**,

rather than through a broad, uniform system of “become true / make true” verbs across all truth-related vocabulary.
