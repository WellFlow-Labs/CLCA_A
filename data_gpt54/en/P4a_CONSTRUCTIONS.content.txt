## 1. ATTRIBUTION
### Pattern
**NP + be + true / correct / right / accurate / valid / genuine / authentic / real / reliable / credible**
### Examples
- *The statement is true.* → N/A → “The statement is true.”
- *That explanation is credible.* → N/A → “That explanation is credible.”
### Notes
English commonly uses a copular predicate with evaluative adjectives for truth, correctness, validity, authenticity, and credibility. The adjective chosen depends on domain: *true* for propositions, *accurate* for descriptions, *valid* for arguments/documents, *genuine/authentic/real* for genuineness.

## 2. NEGATIVE ATTRIBUTION
### Pattern
**NP + be + not true / untrue / false / incorrect / inaccurate / invalid / fake / counterfeit / inauthentic / unreliable / untrustworthy**
### Examples
- *The claim is untrue.* → N/A → “The claim is untrue.”
- *The document is fake.* → N/A → “The document is fake.”
### Notes
Negative attribution is formed either analytically with *not* or lexically with negative adjectives such as *untrue, incorrect, invalid, fake*. Different negatives align with different semantic subdomains: propositional falsity, procedural error, invalidity, or non-genuineness.

## 3. ADNOMINAL MODIFICATION
### Pattern
**truth-domain adjective + noun**  
(e.g. **true/correct/accurate/valid/genuine/authentic/real/reliable/credible/faithful/exact/precise + N**)
### Examples
- *a true story* → N/A → “a true story”
- *an authentic document* → N/A → “an authentic document”
### Notes
English freely places these adjectives before nouns to classify statements, objects, documents, accounts, or representations. This is highly productive, though some pairings are conventionalized (*valid argument, reliable source, exact copy*).

## 4. BECOME / INCHOATIVE
### Pattern
**NP + become / prove / turn out + true / real / valid**; also **come true**
### Examples
- *The rumor proved true.* → N/A → “The rumor proved true.”
- *Her prediction came true.* → N/A → “Her prediction came true.”
### Notes
English has several inchoative/resultative patterns for later confirmation or realization. *Come true* is especially fixed for wishes, fears, and predictions; *prove/turn out true* is common for claims and suspicions.

## 5. CAUSATIVE (OR ABSENCE)
### Pattern
**V + NP + true/right/valid**; also lexical causatives such as **authenticate, validate, verify, correct**
### Examples
- *The new evidence proved the claim true.* → N/A → “The new evidence proved the claim true.”
- *Experts authenticated the painting.* → N/A → “Experts authenticated the painting.”
### Notes
English has limited adjective-based causatives (*prove X true*, *set/put X right*) and also uses dedicated verbs for making or establishing truth-related status. There is no single productive causative verb meaning “make true/genuine/correct” across all subdomains.

## 6. ABSTRACT NOMINALIZATION
### Pattern
**Adjective/root + nominal suffix**: **truth, accuracy, correctness, validity, authenticity, reliability, credibility, faithfulness, exactness, precision**
### Examples
- *the accuracy of the report* → N/A → “the accuracy of the report”
- *the authenticity of the signature* → N/A → “the authenticity of the signature”
### Notes
English commonly forms abstract nouns with suffixes such as *-ness, -ity, -cy, -ion*. These nouns denote qualities or standards and often occur in *the X of NP* constructions.

## 7. AGENTIVE NOMINALIZATION (LIAR, TRUTH-TELLER)
### Pattern
**agent noun / compound for speaker or source**: **truth-teller, liar, forger**; less commonly **truthful person, reliable source, credible witness**
### Examples
- *She is a truth-teller.* → N/A → “She is a truth-teller.”
- *He is a liar.* → N/A → “He is a liar.”
### Notes
English has some lexical agent nouns in this domain, but they are unevenly distributed. *Liar* and *forger* are common; positive truth-agent forms are often periphrastic (*truthful person, trustworthy source*) rather than fully productive nominalizations.

## 8. TRUTH-TELLING PREDICATE
### Pattern
**tell / speak + the truth**; also **truth be told**
### Examples
- *Please tell the truth.* → N/A → “Please tell the truth.”
- *Truth be told, I was unsure.* → N/A → “Truth be told, I was unsure.”
### Notes
English strongly favors verbal constructions with the noun *truth* for honesty in speech. These are central for interpersonal and legal contexts and are more idiomatic than a simple verb “truth.”

## 9. APPEARANCE-OF-TRUTH / PLAUSIBILITY
### Pattern
**NP + ring true / have a ring of truth / seem credible / seem genuine**
### Examples
- *His story rings true.* → N/A → “His story rings true.”
- *The excuse seems credible.* → N/A → “The excuse seems credible.”
### Notes
These constructions mark intuitive plausibility or felt authenticity rather than established truth. They are common when speakers evaluate accounts indirectly, without full verification.

## 10. FIDELITY-TO-SOURCE CONSTRUCTION
### Pattern
**be faithful to / true to + source/original/reality**
### Examples
- *The translation is faithful to the original.* → N/A → “The translation is faithful to the original.”
- *The portrait is true to life.* → N/A → “The portrait is true to life.”
### Notes
English has a distinct construction for representational fidelity rather than simple factual truth. It is especially common with translations, depictions, adaptations, and portraits.
