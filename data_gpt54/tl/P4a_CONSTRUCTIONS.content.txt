## 1. ATTRIBUTION
### Pattern
**[Predicate adjective/noun] + ang/si NP** or **[Predicate] + pronoun/clitic** for ‘be true/correct/certain/fake/reliable’.
### Examples
- **Totoo iyan.** → *Totoo iyan.* → “That is true.”
- **Tumpak ang sinabi mo.** → *Tumpak ang sinabi mo.* → “What you said is accurate.”
### Notes
Tagalog commonly expresses truth-domain attribution with a predicate-initial adjective-like form: *totoo, tama, wasto, tumpak, tiyak, sigurado, peke*. No copula is required in ordinary nonpast predication.

## 2. NEGATIVE ATTRIBUTION
### Pattern
**Hindi + predicate + ang/si NP**; also fixed unsupported-claim pattern **walang saligan + ang NP**.
### Examples
- **Hindi pa tiyak ang resulta.** → *Hindi pa tiyak ang resulta.* → “The result is not certain yet.”
- **Walang saligan ang paratang.** → *Walang saligan ang paratang.* → “The accusation is baseless.”
### Notes
Simple negation uses *hindi* before the predicate. For lack of evidential basis, Tagalog often uses the separate predicative expression *walang saligan* rather than negating a positive adjective.

## 3. ADNOMINAL MODIFICATION
### Pattern
**Modifier + linker (-ng / na) + noun** for ‘true/real/correct/fake/reliable/etc. N’.
### Examples
- **totoong balita** → *totoong balita* → “true/real news”
- **pekeng dokumento** → *pekeng dokumento* → “fake document”
### Notes
Truth-domain modifiers regularly appear before nouns with the linker: *totoong, wastong, tunay na, tumpak na, tiyak na, mapagkakatiwalaang, walang saligang*. This is the main attributive strategy.

## 4. BECOME / INCHOATIVE
### Pattern
**magka-/nagka- + totoo** → ‘become true / turn out true’.
### Examples
- **Sana magkatotoo ang hiling mo.** → *Sana magkatotoo ang hiling mo.* → “I hope your wish comes true.”
- **Nagkatotoo ang kanyang hinala.** → *Nagkatotoo ang kanyang hinala.* → “His suspicion turned out to be true.”
### Notes
A clear inchoative/resultative construction is attested with the *totoo* root: *magkatotoo / nagkatotoo*. It is used especially for wishes, predictions, fears, and suspicions.

## 6. ABSTRACT NOMINALIZATION
### Pattern
**ka- + root + -han** or lexical noun for abstract truth/correctness/basis meanings.
### Examples
- **katotohanan** → *katotohanan* → “truth; reality”
- **saligan** → *saligan* → “basis; foundation; grounds”
### Notes
Abstract nominalization is clearly attested with *katotohanan* from *totoo* and *saligan* from *salig*. These nouns function as standard abstract terms in formal and everyday discourse.

## 8. DISCOURSE-MARKING TRUTH FRAME
### Pattern
**sa + truth noun/adjective + particle** as clause-initial frame.
### Examples
- **Sa totoo lang, pagod na ako.** → *Sa totoo lang, pagod na ako.* → “To tell the truth, I’m already tired.”
- **Sa katotohanan, wala pang pinal na pasya.** → *Sa katotohanan, wala pang pinal na pasya.* → “In fact, there is no final decision yet.”
### Notes
Tagalog has fixed preposed discourse markers built from the truth lexicon. *Sa totoo lang* is colloquial-candid; *sa katotohanan* is more formal and corrective.

## 9. INTERROGATIVE EVALUATION
### Pattern
**Predicate + ba + NP/deictic** for ‘is it true/correct/sure?’
### Examples
- **Totoo ba iyan?** → *Totoo ba iyan?* → “Is that true?”
- **Sigurado ka ba?** → *Sigurado ka ba?* → “Are you sure?”
### Notes
Truth and certainty are commonly queried with predicate-initial yes/no questions using *ba*. This pattern is highly productive with *totoo, tama, wasto, sigurado*.

## 10. BASIS / SUPPORT CONSTRUCTION
### Pattern
**salig sa / nakasalig sa + NP**; contrastive **may saligan / walang saligan**.
### Examples
- **Salig sa ebidensiya ang ulat.** → *Salig sa ebidensiya ang ulat.* → “The report is based on evidence.”
- **May saligan ang kanyang reklamo.** → *May saligan ang kanyang reklamo.* → “His complaint has basis / is well-founded.”
### Notes
This construction family expresses whether a claim rests on evidence or grounds. It is especially common in formal, legal, journalistic, and analytical registers.

## 11. VERIFICATION / AUTHENTICATION
### Pattern
**beripikahin + object**; **beripikadong + noun**
### Examples
- **Beripikahin ang impormasyon bago ito ibahagi.** → *Beripikahin ang impormasyon bago ito ibahagi.* → “Verify the information before sharing it.”
- **Beripikadong impormasyon lamang ang ilalathala.** → *Beripikadong impormasyon lamang ang ilalathala.* → “Only verified information will be published.”
### Notes
A modern borrowed construction family expresses procedural confirmation of truth or authenticity. It appears mainly in media, bureaucratic, digital, and security contexts.

## 12. SERIOUSNESS SHIFT FROM ‘TRUE’
### Pattern
**totohanin + object**; **totohanan / sa totohanan** for ‘seriously / for real’.
### Examples
- **Huwag mong totohanin ang biro.** → *Huwag mong totohanin ang biro.* → “Don’t take the joke seriously.”
- **Totohanan na ito.** → *Totohanan na ito.* → “This is serious now / This is for real now.”
### Notes
This is a peripheral extension of the *totoo* family from factual truth to seriousness/earnestness. It is colloquial and narrower than core truth-evaluating constructions.
