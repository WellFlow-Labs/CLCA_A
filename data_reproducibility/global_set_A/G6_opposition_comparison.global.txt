# G6 — Cross-Language Opposition and Asymmetry Comparison

---

## 1. Per-Language Extraction of Attested Oppositional Structures

### Georgian (ka)

**Lexical oppositions:**
- სიმართლე / ტყუილი (truth / lie) — primary lexical pair, appears in fixed binomial
- მართალი / მცდარი (correct / erroneous) — factual correctness vs. error
- სწორი / მცდარი (correct / erroneous) — procedural correctness vs. error
- ნამდვილი / ყალბი (genuine / fake/counterfeit) — authenticity domain
- ნამდვილი / ფიქტიური (real / fictitious) — reality vs. fiction
- ბუნებრივი / ხელოვნური (natural / artificial) — naturalness domain
- გულწრფელი / ლიცემერი (sincere / hypocritical) — sincerity domain
- სანდო / საეჭვო (reliable / doubtful) — reliability domain
- ობიექტური / სუბიექტური (objective / subjective) — epistemic stance
- რეალური / მოჩვენებითი (real / apparent) — reality vs. appearance
- არსებითი / ზედაპირული (essential / superficial) — depth vs. surface

**Morphological oppositions:**
- ზუსტი / უზუსტობა (precise / imprecision) — negative prefix უ-
- სამართლიანი / უსამართლობა (just / injustice) — negative prefix უ-
- ადეკვატური / არაადეკვატური (adequate / inadequate) — negative prefix არა-
- ტყუილი / უტყუარი (lie / infallible) — negative prefix უ- on lie root

**Constructional oppositions:**
- NP + არის + ADJ / NP + არ არის + ADJ (affirmative / negative attribution)
- არა X, არამედ Y (not X, but Y) — fixed corrective frame
- სიმართლეს ამბობს / ტყუილს ამბობს (tells truth / tells lies) — parallel dative constructions
- სანდო წყარო / საეჭვო წყარო (reliable source / dubious source) — same noun, contrasting modifiers
- ნამდვილი ისტორია / ფიქტიური ისტორია (true story / fictional story) — same noun, contrasting modifiers

**Asymmetries noted in F5:**
- ნაღდი ფული (cash money) has no single lexical opposite
- დამაჯერებელი მტკიცებულება (convincing evidence) has no fixed negative counterpart
- ნამდვილი სახე (true face) implies but does not lexicalize მოჩვენებითი სახე as a fixed phrase

### Yoruba (yo)

**Lexical oppositions:**
- òtítọ́ / irọ́ (truth / lie) — primary lexical pair
- tọ́ / purọ́ (to be correct / to lie) — primary verbal pair
- ìwà rere / ìwà búburú (good character / bad character) — moral character pair
- ṣe àṣìṣe / ṣe àtúnṣe (to make an error / to make a correction) — error/correction pair
- ọ̀rọ̀ tọ́ / ọ̀rọ̀ òfo (true word / empty word) — statement quality pair

**Morphological oppositions:**
- tọ́ / kò tọ́ (correct / not correct) — preverbal negator kò
- òtítọ́ / àìtọ́ (truth / incorrectness) — negative nominalizer àì-
- ìbámu / àìbámu (correspondence / non-correspondence) — negative nominalizer àì-
- ìmọ̀ / àìmọ̀ (knowledge / ignorance) — negative nominalizer àì-
- ìyẹ / àìyẹ (fittingness / unfittingness) — negative nominalizer àì-
- ìpé / àìpé (completeness / incompleteness) — negative nominalizer àì-
- dájú / kò dájú (certain / uncertain) — preverbal negator
- ṣe é ṣe / kò ṣe é ṣe (possible / impossible) — preverbal negator
- yẹ / kò yẹ (fitting / not fitting) — preverbal negator
- ṣe pàtàkì / kò ṣe pàtàkì (important / not important) — preverbal negator

**Constructional oppositions:**
- sọ òtítọ́ / pa irọ́ (tell truth / tell lie) — asymmetric verbs (sọ vs. pa)
- ọmọ òtítọ́ / apurọ́ (truthful person / liar) — compound vs. prefix agentive
- fi òtítọ́ hàn / pamọ́ òtítọ́ (reveal truth / hide truth) — contrasting verbs, same object
- ọkàn tọ́ / ọkàn méjì (straight heart / two hearts) — sincerity vs. duplicity
- ọkàn kan / ọkàn méjì (one heart / two hearts) — numerical metaphor pair
- tọ́ títí / kò tọ́ rárá (completely correct / not correct at all) — emphatic poles
- jọ ọ́ púpọ̀ / kò jọ ọ́ rárá (resembles greatly / doesn't resemble at all) — degree poles
- òtítọ́ ni / irọ́ ni (it is truth / it is a lie) — parallel focus constructions

**Asymmetries noted in F5:**
- gidi (genuine) has no specific lexical antonym; negation kì í ṣe gidi used instead
- òtítọ́ korò (truth is bitter) implies irọ́ dùn (lies are sweet) but the latter is not attested
- ọmọ òtítọ́ (truthful person) uses compound while apurọ́ (liar) uses agentive prefix — structural asymmetry

### Finnish (fi)

**Lexical oppositions:**
- tosi / väärä (true / wrong/false) — primary everyday pair
- totuus / valhe (truth / lie) — primary abstract noun pair
- oikea / väärä (correct / wrong) — correctness evaluation pair
- oikeellinen / virheellinen (correct / erroneous) — formal pair
- aito / väärennös (genuine / forgery) — authenticity pair
- rehellinen / petollinen (honest / deceptive) — character pair
- todistaa / väittää (prove / claim) — epistemic force pair
- tosiasia / väite (fact / claim) — established vs. asserted pair

**Morphological oppositions:**
- rehellinen / epärehellinen (honest / dishonest) — negative prefix epä-
- tosi / epätosi (true / untrue) — negative prefix epä-
- todennäköinen / epätodennäköinen (probable / improbable) — negative prefix epä-
- vilpitön / vilpillinen (sincere / deceitful) — privative -tön vs. positive -llinen on same root
- todistaa oikeaksi / todistaa vääräksi (prove correct / prove false) — translative case contrast
- olla oikeassa / olla väärässä (to be right / to be wrong) — fixed inessive constructions

**Constructional oppositions:**
- on totta / ei ole totta (is true / is not true) — affirmative vs. negative copular
- puhua totuutta / puhua valhetta (speak truth / tell a lie) — same verb, contrasting objects
- valehdella / puhua totuutta (to lie / speak truth) — dedicated verb vs. verb+object
- väärinkäsitys / oikea käsitys (misunderstanding / correct understanding) — lexicalized negative vs. compositional positive

**Asymmetries noted in F5 and F6:**
- No common expression for "becoming untrue" (F6 gap: [UNCERTAIN])
- No simple causative "make genuine" (*aitouttaa not attested)
- väärinkäsitys and väärinkäyttö lexicalized; positive counterparts are not
- valehdella (dedicated verb for lying) vs. puhua totuutta (verb+object for truth-telling)
- tosielämä (real life) contrasts with fiktio but fiktio is not in the P1 data

### Basque (eu)

**Lexical oppositions:**
- egia / gezurra (truth / lie) — primary lexical pair
- egiazkoa / gezurrezko (true / false) — adjectival pair from same roots
- zuzena / okerra (correct / wrong) — correctness/error pair
- zintzoa / faltsua (honest / false/deceitful) — moral character pair
- fidagarria / zalantzagarria (reliable / doubtful) — reliability pair
- benetakoa / itxurazko (genuine / apparent/seeming) — reality vs. appearance
- ageria / ezkutuan (evident / hidden) — visibility pair
- benetan / itxuraz (truly / apparently) — adverbial reality vs. appearance pair
- egiaren alde / egiaren kontra (on the side of truth / against truth) — postpositional pair
- gezur handia / gezur txikia (big lie / small/white lie) — scalar pair within falsehood domain

**Morphological oppositions:**
- egiaztatu / gezurtatu (to verify / to lie/falsify) — parallel verbalizations from contrasting roots
- zuzendu / okertu (to correct / to go wrong) — parallel verbalizations from contrasting roots
- zuzentasuna / okertasuna (correctness / wrongness) — parallel -tasun nominalizations
- zintzotasuna / faltsukeria (honesty / falseness) — asymmetric suffixes: neutral -tasun vs. pejorative -keria
- sinesgarria / sinesgaitza (believable / unbelievable) — -garri vs. -gaitz on same root [MARGINAL]
- frogagarria / frogaezina (provable / unprovable) — -garri vs. -ezin on same root [MARGINAL]

**Constructional oppositions:**
- egia esan / gezurra esan (tell truth / tell lie) — same verb, contrasting objects
- zuzen egin / oker egin (do right / do wrong) — same verb, contrasting modifiers
- zuzen ibili / oker ibili (walk straight/behave properly / walk crooked/behave wrongly) — same verb, contrasting modifiers
- agerian jarri / ezkutatu (expose / hide) — contrasting verbs, same domain
- agerian dago / ezkutuan dago (is exposed / is hidden) — parallel locative + copula
- zalantzan jarri / ziurtatu (call into question / make certain) — contrasting verbs
- X dirudi / X da (X seems / X is) — evidential vs. direct assertion
- egiazko balioa / itxurazko balioa (true value / apparent value) — same noun, contrasting modifiers

**Asymmetries noted in F5:**
- zintzotasuna uses neutral -tasun; faltsukeria uses pejorative -keria — formal asymmetry encoding moral asymmetry
- sinesgaitza and frogaezina are implied but not directly attested as productive forms [MARGINAL]
- ezkutuan dago (is hidden) is implied but not directly attested as a fixed construction [MARGINAL]

### Tamil (ta)

**Lexical oppositions:**
- uṇmai / poy (truth / lie) — primary lexical pair, all registers
- mey / poy (truth / lie) — literary/classical register pair
- cari / tappu (correct / wrong) — everyday correctness pair
- cari / tavaṟu (correct / mistake) — formal correctness pair
- acal / pōli (original / fake) — authenticity pair
- nampakam / cantēkam (reliability / doubt) — epistemic evaluation pair
- uṟuti / cantēkam (certainty / doubt) — certainty vs. doubt pair
- uṇmai mukam / poy mukam (true face / false face) — metaphorical character pair

**Morphological oppositions:**
- uṇmaiyāṉa / uṇmaiyaṟṟa (true / without truth) — positive -āṉa vs. privative -aṟṟa
- nērmaiyāṉa / nērmaiyaṟṟa (honest / dishonest) — positive -āṉa vs. privative -aṟṟa
- niyāyamāṉa / niyāyamaṟṟa (just / unjust) — positive -āṉa vs. privative -aṟṟa
- poruttamāṉa / poruttamaṟṟa (suitable / unsuitable) — positive -āṉa vs. privative -aṟṟa
- cantēkamāṉa / cantēkamaṟṟa (doubtful / without doubt) — positive -āṉa vs. privative -aṟṟa
- kuṟṟamāṉa / kuṟṟamaṟṟa (faulty / faultless) — positive -āṉa vs. privative -aṟṟa
- cāttiyamāṉa / cāttiyamaṟṟa (possible / impossible) — positive -āṉa vs. privative -aṟṟa
- uṇmai (truth) / uṇmaiyiṉmai (absence of truth) — base vs. -iṉmai nominalization

**Constructional oppositions:**
- uṇmaiyai col / poy col (tell truth / tell lies) — accusative marking on truth, no marking on lie
- uṇmaiyai maṟai / uṇmaiyai veḷippaṭuttu (hide truth / reveal truth) — contrasting verbs, same object
- uṇmai āku / poy ampalamāku (truth becomes / lie is exposed) — contrasting inchoatives
- uṇmaiyā poyyā (true or false?) — contrastive disjunction
- cariyā tappā (right or wrong?) — contrastive disjunction
- atu uṇmai / atu poy (that is true / that is false) — parallel copular constructions
- atu cari / atu tappu (that is correct / that is wrong) — parallel copular constructions
- muḻu uṇmai / pakuti uṇmai (whole truth / partial truth) — degree contrast within truth domain [MARGINAL]

**Asymmetries noted in F5 and F6:**
- uṇmaiyai col: accusative -ai on truth; poy col: no case marking on lie — morphological asymmetry
- poyyar (liars) lexicalized; no parallel *uṇmaiyar (truth-tellers)
- mey (literary truth) vs. uṇmai (general truth) vs. nijam (colloquial truth) — register stratification without parallel in falsehood domain
- Degree modification of truth predicates is marginal (F4: [MARGINAL] for muḻu uṇmai, pakuti uṇmai)
- Reciprocal, benefactive, and instrumental constructions with truth-domain terms are absent (F4: [UNCERTAIN])

### Indonesian (id)

**Lexical oppositions:**

- asli / palsu (genuine / fake/counterfeit) — authenticity pair
- jujur / bohong (honest / lie/to lie) — honesty vs. deception pair

- wajar / tidak wajar (reasonable / unreasonable) — morphological negation
- pantas / tidak pantas (appropriate / inappropriate) — morphological negation

**Morphological oppositions:**
- benar / tidak benar (true / not true) — analytic negation dengan tidak
- asli / tidak asli (genuine / not genuine) — analytic negation
- sah / tidak sah (valid / invalid) — analytic negation
- bohong / tidak bohong (lying / not lying) — analytic negation
- [ADJ] / tidak + [ADJ] — universal analytic negation strategy (no prefix negation)
- benar-benar / tidak...sama sekali (really / not at all) — emphatic affirmation vs. emphatic negation

**Constructional oppositions:**
- asli atau palsu (genuine or fake) — contrastive disjunction
- benar atau salah (true or false) — contrastive disjunction
- sah atau tidak (valid or not) — contrastive disjunction
- sebenarnya (actually) — discourse marker contrasting reality with assumption
- ternyata benar / ternyata palsu (it turns out true / it turns out fake) — parallel evidential constructions
- menjadi benar / menjadi palsu (become true / become fake) — parallel inchoatives
- membenarkan / menyalahkan (to confirm/justify / to blame/fault) — causative pair
- mengesahkan / membatalkan (to validate / to cancel/annul) — causative pair

**Asymmetries noted in F5:**

- hakikat (essence/true nature) has no clear lexical antonym

- nyata (real) contrasts with khayalan (imaginary) but khayalan is not in P1 data
- salah satu (one of) — grammaticalized from salah (wrong), no parallel from benar

**Constructional oppositions:**

- hakikat (fundamental truth) has no clear lexical antonym
- meşru / gayri meşru or meşru olmayan — Arabic prefix vs. Turkish negation [MARGINAL for gayri meşru]
- inandırıcı / inandırıcı olmayan or inanılmaz — constructional negation preferred over morphological antonym
- tatlı yalan (sweet lie) implied by acı gerçek (bitter truth) but not directly attested [MARGINAL]

### Korean (ko)

**Lexical oppositions:**
- 진실 / 거짓 (truth / falsehood) — primary Sino-Korean pair
- 사실 / 거짓 (fact / falsehood) — factual pair
- 진짜 / 가짜 (real/genuine / fake/counterfeit) — colloquial authenticity pair
- 진본 / 모조품 (authentic original / imitation product) — formal authenticity pair
- 맞다 / 틀리다 (correct / wrong) — native Korean correctness pair
- 옳다 / 그르다 (right / wrong) — native Korean moral pair [그르다 archaic]
- 새빨간 거짓말 / 하얀 거짓말 (blatant lie / white lie) — color metaphor pair within falsehood domain

**Morphological oppositions:**
- 정직 / 부정직 (honesty / dishonesty) — Sino-Korean negative prefix 부-
- 정확하다 / 부정확하다 (accurate / inaccurate) — Sino-Korean negative prefix 부-
- 정확성 / 부정확성 (accuracy / inaccuracy) — prefix 부- on nominalization
- 확실하다 / 불확실하다 (certain / uncertain) — Sino-Korean negative prefix 불-
- 확실성 / 불확실성 (certainty / uncertainty) — prefix 불- on nominalization
- 정당하다 / 부정당하다 (legitimate / illegitimate) — prefix 부- [부정당하다 MARGINAL]
- NP + 이다 / NP + 이/가 아니다 (is / is not) — copular affirmation vs. negation
- ADJ + -하다 / ADJ + -하지 않다 (is [quality] / is not [quality]) — adjectival affirmation vs. negation

**Constructional oppositions:**
- 진실을 밝히다 / 진실을 숨기다 (reveal truth / hide truth) — contrasting verbs, same object
- 진실을 말하다 / 거짓말하다 (tell truth / lie) — verb+object vs. compound verb
- 신빙성이 있다 / 신빙성이 없다 (credible / not credible) — existential pair
- 신빙성이 높아지다 / 신빙성이 떨어지다 (credibility rises / credibility falls) — directional pair
- 진짜인지 가짜인지 (whether real or fake) — embedded contrastive disjunction
- 맞는지 틀리는지 (whether right or wrong) — embedded contrastive disjunction
- 옳고 그름 (right and wrong) — fixed binomial [그르다 archaic outside this expression]
- 거짓말쟁이 / (진실을 말하는 사람) (liar / truth-teller) — agentive noun vs. periphrastic

**Asymmetries noted in F5:**
- 거짓말쟁이 (liar) lexicalized; no parallel agentive for truth-teller
- 그르다 (wrong) archaic; survives only in fixed expression 옳고 그름
- 진실이 드러나다 (truth comes to light) attested; no parallel intransitive for truth becoming concealed
- 명백하다 (obvious) has no clear lexical antonym in the data
- 그럴듯하다 (plausible) has no clear lexical antonym in the data
- 사실상 (in fact) has no parallel antonym
- Inchoative "becoming true/false" for propositions is marginal (F6: [MARGINAL])

### 3c. Recurrent Patterns of Restriction, Substitution, or Blocking

**Pattern 1: Discovery/revelation substitutes for inchoative in the truth domain.**
Across yo, ko, fi, and eu, the inchoative construction ("become true") is replaced by or reinterpreted as a discovery construction ("come to light," "be revealed," "be brought to light"). This substitution is most complete in yo and ko, partial in fi and eu. The substitution reflects a conceptual framing: truth does not change its value; it is uncovered. This pattern is absent in ka, id, and tr, where inchoative constructions for truth are natural.

**Pattern 2: Verification verbs substitute for causative "make true."**
In all eight languages, the preferred way to express causing something to be true is through verification verbs (prove, confirm, verify, reveal) rather than through direct causatives of truth adjectives. Even in languages with productive causative morphology (fi, eu, tr), the causative of a truth adjective is less natural than a verification verb. The substitution is most complete in yo and ko, where direct causatives of truth predicates are absent or marginal.

**Pattern 3: Analytic negation substitutes for morphological antonym in id.**
Indonesian uses the analytic negator tidak for all truth-domain negations rather than a prefix or suffix. This means Indonesian lacks the morphological antonym pairs found in tr (-lı/-sız), ta (-āṉa/-aṟṟa), fi (epä-), ko (부-/불-), and eu (-garri on contrasting bases). The result is that Indonesian's oppositions are consistently constructional rather than morphological in the truth domain.

**Pattern 4: Periphrastic construction substitutes for agentive "truth-teller."**
In all eight languages, the morphological pathway that creates "liar" agentives does not productively create "truth-teller" agentives. The substitution is a compound or relative clause construction in all languages. This blocking is not explained by morphological constraints and appears to reflect a cross-linguistic tendency.

**Pattern 5: Asymmetric verb selection for truth-telling vs. lying.**
In yo, fi, ta, id, and ko, the verb used for lying is morphologically more condensed (dedicated verb or compound verb) than the verb used for truth-telling (verb + object construction). In ka, eu, and tr, both use verb + object constructions with the same verb. The asymmetry is consistent with the general pattern of greater morphological elaboration on the negative pole.
