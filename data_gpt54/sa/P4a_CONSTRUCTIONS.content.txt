## 1. ATTRIBUTION
### Pattern
**X (nom.) + satyam / yathārtham / yuktam / ucitam / pramāṇam bhavati / asti**  
‘X is true / accurate / proper / valid.’

### Examples
- **सत्यम् एतत्** → *satyam etat* → “This is true.”
- **युक्तं भवति** → *yuktaṃ bhavati* → “It is proper / reasonable.”

### Notes
Predicative truth/correctness is commonly expressed with a neuter adjective or noun used predicatively, often with **asti/bhavati** understood or overt. Sanskrit also uses parallel predicates for factual truth (**satyam, yathārtham**) and justified propriety (**yuktam, ucitam**).

## 2. NEGATIVE ATTRIBUTION
### Pattern
**X (nom.) + na / nāsti + satyam / yuktam / ucitam / pramāṇam**; also **a- / an-** negative stems predicatively

### Examples
- **प्रमाणं नास्ति** → *pramāṇaṃ nāsti* → “There is no proof / valid evidence.”
- **न युक्तम्** → *na yuktam* → “It is not proper / not reasonable.”

### Notes
Negation is usually analytic with **na / nāsti**, though lexical negatives are also common (**asatya, ayathārtha, apramāṇika**). Sanskrit does not require a special copular pattern distinct from ordinary predication.

## 3. ADNOMINAL MODIFICATION
### Pattern
**truth/correctness adjective + noun**  
e.g. **satya-/tathya-/yathārtha-/pramāṇika-/dharmya- + N**

### Examples
- **तथ्यं वचनम्** → *tathyaṃ vacanam* → “a factual statement”
- **प्रमाणिकः ग्रन्थः** → *pramāṇikaḥ granthaḥ* → “an authoritative text”

### Notes
Adjectival stems directly modify nouns in gender/number/case agreement. This is a major strategy for expressing “true statement,” “accurate description,” “authoritative text,” and similar notions.

## 4. BECOME / INCHOATIVE
### Pattern
**abstract truth noun + gacchati**; or **X + bhavati / jāyate** with validity/cognition nouns

### Examples
- **सत्यतां गच्छति** → *satyatāṃ gacchati* → “It proves true / comes to be true.”
- **प्रमा जायते** → *pramā jāyate* → “Valid cognition arises.”

### Notes
Inchoative meaning is not tied to a single dedicated verb; Sanskrit commonly uses **gacchati**, **bhavati**, or **jāyate**. These patterns are especially natural in scholastic or philosophical prose.

## 5. CAUSATIVE (OR ABSENCE)
### Pattern
**(no common expression identified)**

### Examples
- **प्रमाणीकृतम्** → *pramāṇīkṛtam* → “authenticated / validated”
- **प्रमाणीकरणम्** → *pramāṇīkaraṇam* → “authentication / validation”

### Notes
No single common productive causative pattern meaning “make true” or “make valid” emerges from the data as a basic truth-domain construction. Instead, Sanskrit more often uses lexicalized formations in the **pramāṇa** family for “validate/authenticate.”

## 6. ABSTRACT NOMINALIZATION
### Pattern
**adjective/stem + -tā / -tva / abstract nominal family form**

### Examples
- **सत्यता** → *satyatā* → “truth / truthfulness”
- **यथार्थता** → *yathārthatā* → “accuracy / reality / truth”

### Notes
Abstract truth-related qualities are commonly formed with **-tā** and **-tva**, especially in scholastic registers. The **pramāṇa** family also has inherited abstracts such as **prāmāṇya** “validity.”

## 7. AGENTIVE NOMINALIZATION (LIAR, TRUTH-TELLER)
### Pattern
**truth/falsehood stem + -vādin / -vādī / -bhāṣin**  
‘truth-speaker, liar, truthful speaker’

### Examples
- **सत्यवादिन्** → *satyavādin* → “truth-speaker / truthful person”
- **असत्यवादिन्** → *asatyavādin* → “speaker of falsehood / liar”

### Notes
Agentive compounds are a regular way to encode habitual truthfulness or falsehood as a personal trait. These are especially common in ethical, narrative, and didactic characterization.

## 8. VERBAL COMPLEMENT WITH “SPEAK/SAY”
### Pattern
**truth/falsity noun or adverb + vad-/brū-/bhāṣ-**  
‘speak truth / speak falsely’

### Examples
- **सत्यं वद** → *satyaṃ vada* → “Speak the truth.”
- **मिथ्या वदति** → *mithyā vadati* → “He/she speaks falsely.”

### Notes
This is one of the most basic construction types in the domain. Sanskrit uses an object-like neuter form (**satyaṃ, asatyaṃ, anṛtaṃ**) or an adverbial falsity form (**mithyā, mṛṣā**) with common speech verbs.

## 9. GENITIVE OF TRUTH / VALIDITY EVALUATION
### Pattern
**X-genitive + abstract noun of truth/validity**  
‘the truth/accuracy/validity of X’

### Examples
- **वाक्यस्य सत्यता** → *vākyasya satyatā* → “the truth of a statement”
- **ज्ञानस्य प्रामाण्यम्** → *jñānasya prāmāṇyam* → “the validity of cognition”

### Notes
Analytical evaluation is often expressed by a genitive possessor plus an abstract noun. This pattern is especially prominent in philosophy, grammar, and commentary.

## 10. INSTRUMENTAL OF MEANS / GROUNDS
### Pattern
**truth/validity noun in instrumental**  
‘by truth, by proof, on valid grounds’

### Examples
- **प्रमाणेन सिद्धम्** → *pramāṇena siddham* → “established by valid proof”
- **सत्येन जयते** → *satyena jayate* → “One triumphs by truth.”

### Notes
The instrumental marks means, basis, or grounds. In the truth domain it is especially important with **pramāṇa** for evidential support, and more broadly with **satya** for moral or rhetorical means.

## 11. ADVERBIAL ESSENTIAL/FACTUAL STANCE
### Pattern
**stem + -taḥ / instrumental adverbial**  
‘truly, in reality, essentially, on factual grounds’

### Examples
- **यथार्थतः** → *yathārthataḥ* → “in reality / as a matter of fact”
- **तत्त्वतः** → *tattvataḥ* → “truly / in principle / in reality”

### Notes
Sanskrit frequently uses adverbial case forms and suffixal adverbs to mark the standpoint of reality, essence, or valid determination. These are common in philosophical and analytical prose.
