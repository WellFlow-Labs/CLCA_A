## 1. ATTRIBUTION
### Pattern
**X doğru / gerçek / haklı / geçerli / güvenilir (olmak)**  
[Noun/Clause] + truth-domain adjective, often with zero copula in present tense; **olmak** appears in infinitival or non-present forms.

### Examples
- Bu bilgi **doğru**. → *Bu bilgi doğru.* → “This information is correct/true.”
- Bu belge **geçerli** değil. → *Bu belge geçerli değil.* → “This document is not valid.”

### Notes
Turkish commonly predicates truth-related adjectives directly, with no overt copula in simple present. The same pattern covers factual truth (*doğru, gerçek*), validity (*geçerli*), credibility (*güvenilir*), and justification (*haklı*).

## 2. NEGATIVE ATTRIBUTION
### Pattern
**X doğru / gerçek / geçerli değil**; **X sahte / asılsız / geçersiz**  
Negation is expressed either analytically with **değil** or lexically with dedicated negative adjectives.

### Examples
- Bu iddia **doğru değil**. → *Bu iddia doğru değil.* → “This claim is not true.”
- Bu haber **asılsız**. → *Bu haber asılsız.* → “This report is baseless.”

### Notes
Turkish uses both compositional negation (**A değil**) and lexical opposites (**geçersiz, sahte, asılsız, haksız**). The lexical strategy is especially common for institutional validity and falsity.

## 3. ADNOMINAL MODIFICATION
### Pattern
**[Adj + N]** with truth-domain adjective before noun  
Common modifiers: **doğru, gerçek, hakiki, sahici, özgün, geçerli, güvenilir, sahte, uydurma**

### Examples
- **güvenilir kaynak** → *güvenilir kaynak* → “reliable source”
- **sahte belge** → *sahte belge* → “fake/forged document”

### Notes
Truth-domain meanings are very often expressed attributively inside noun phrases. This is the default structure for source evaluation, authenticity, validity, and falsity.

## 4. BECOME / INCHOATIVE
### Pattern
**Adj/N + ol-**; limited lexical **-leş-** forms  
Typical pattern: “become X” with **olmak**; some items also allow inchoative derivation like **sahteleşmek**, **özgünleşmek**.

### Examples
- Hikâye daha **inandırıcı oldu**. → *Hikâye daha inandırıcı oldu.* → “The story became more convincing.”
- İlişkileri zamanla **sahteleşti**. → *İlişkileri zamanla sahteleşti.* → “Their relationship became artificial/fake over time.”

### Notes
The productive inchoative strategy is **X olmak**. Morphological inchoatives in **-leş-** exist, but are selective and much less general across this semantic field.

## 5. CAUSATIVE (OR ABSENCE)
### Pattern
**X-i doğrulamak**; limited **Adj + -leş-tir-** causatives  
Most natural causative meaning is “make/establish as true/verified” via verbs like **doğrulamak**; some adjectives form causatives such as **sahteleştirmek**.

### Examples
- Haberi henüz **doğrulamadılar**. → *Haberi henüz doğrulamadılar.* → “They have not verified the news yet.”
- Bu söylem olayı **sahteleştiriyor**. → *Bu söylem olayı sahteleştiriyor.* → “This discourse makes the event seem artificial/fake.”

### Notes
There is no single general causative “make true” construction for all items. Instead Turkish uses lexical verbs, especially **doğrulamak** ‘verify/confirm’, plus a few derived causatives in **-leştir-**.

## 6. ABSTRACT NOMINALIZATION
### Pattern
**Adj + -lık/-lik/-luk/-lük**; some lexical nouns  
Common forms: **doğruluk, gerçeklik, güvenilirlik, geçerlilik, meşruiyet, dürüstlük, sahicilik**

### Examples
- Raporun **doğruluğu** tartışılıyor. → *Raporun doğruluğu tartışılıyor.* → “The accuracy/truth of the report is being discussed.”
- Ölçümün **güvenilirliği** düşük. → *Ölçümün güvenilirliği düşük.* → “The reliability of the measurement is low.”

### Notes
Abstract truth-domain nouns are highly productive, especially with **-lIk**. Some high-frequency abstractions are lexical or borrowed rather than transparently derived, e.g. **hakikat, meşruiyet**.

## 7. AGENTIVE NOMINALIZATION (LIAR, TRUTH-TELLER)
### Pattern
**(no common expression identified)**

### Examples
- **yalancı** gerçeği sakladı. → *yalancı gerçeği sakladı.* → “The liar hid the truth.”
- Herkes ona **dürüst biri** der. → *Herkes ona dürüst biri der.* → “Everyone calls him an honest person.”

### Notes
Turkish has agent nouns like **yalancı** ‘liar’, but within this dataset there is no strongly lexicalized, central agentive pair built directly from the core truth adjectives comparable to English *truth-teller*. The language often prefers descriptive phrases such as **dürüst biri**, **doğruyu söyleyen kişi**.

## 8. VERIDICAL SPEECH / REPORTING
### Pattern
**[Truth noun/accusative] + söylemek / yansıtmak / çarpıtmak / gizlemek**  
Typical objects: **doğruyu, gerçeği, hakikati**

### Examples
- Bana **gerçeği söyle**. → *Bana gerçeği söyle.* → “Tell me the truth.”
- Bu açıklama **gerçeği çarpıtıyor**. → *Bu açıklama gerçeği çarpıtıyor.* → “This statement distorts the truth.”

### Notes
A major Turkish construction type in this domain is verbal rather than purely adjectival: truth is encoded as an object of speech/report verbs. This pattern is especially central for honesty, distortion, and disclosure.

## 9. PARTIAL-TRUTH CONSTRUCTION
### Pattern
**X payı olmak** with **gerçek / doğruluk / hakikat**  
Noun phrase + **payı** ‘share/portion’ expresses partial truth.

### Examples
- Bu söylentinin **gerçek payı var**. → *Bu söylentinin gerçek payı var.* → “There is some truth in this rumor.”
- Eleştiride **doğruluk payı** yok değil. → *Eleştiride doğruluk payı yok değil.* → “The criticism is not entirely without some truth.”

### Notes
This is a compact, productive way to mark incomplete or partial truth. Structurally it is a possessed noun phrase with existential/predicative use.

## 10. CONFORMITY-TO-REALITY
### Pattern
**X-(y)e uygun** / **X-(d)en uzak**  
Usually with **gerçek / hakikat / asıl** in dative or ablative-marked complements.

### Examples
- Film tarihsel olarak **gerçeğe uygun** değil. → *Film tarihsel olarak gerçeğe uygun değil.* → “The film is not true to historical reality.”
- Bu anlatı **hakikatten uzak**. → *Bu anlatı hakikatten uzak.* → “This narrative is far from the truth.”

### Notes
Turkish often expresses truth as conformity via post-adjectival relational constructions rather than simple predication. These are especially common for representation, testimony, and criticism.
