## 1. BECOMING TRUE / VERIFIED / CREDIBLE

### Pattern
X + 变得/变 + 真实/可信/可靠/准确  
X + 由 + 不实/失实 + 变为 + 属实/真实/准确

### Examples
- 这段描述后来变得更真实了。  
  → zhè duàn miáoshù hòulái biàn de gèng zhēnshí le.  
  → This description later became more true-to-reality.

- 这一说法后来变得可信了。  
  → zhè yī shuōfǎ hòulái biàn de kěxìn le.  
  → This claim later became believable.

- 数据核对后变得更准确。  
  → shùjù héduì hòu biàn de gèng zhǔnquè.  
  → The data became more accurate after checking.

### Notes
Chinese commonly uses **变 / 变得** to express movement into a more truth-related state such as **真实, 可信, 可靠, 准确**.  
For **属实**, dynamic use is more restricted: it is usually not framed as a gradual quality, but as a verification result in official language.

---

## 2. BECOMING FALSE / INACCURATE / DISTORTED / NOT CREDIBLE

### Pattern
X + 变得/变 + 不实/失实/不可信/不可靠/不准确/失真  
X + 越来越 + 不可信/不准确  
X + 在……中 + 失真

### Examples
- 报道后来变得失实。  
  → bàodào hòulái biàn de shīshí.  
  → The report later became inaccurate.

- 这一说法越来越不可信了。  
  → zhè yī shuōfǎ yuèláiyuè bù kěxìn le.  
  → This claim became less and less believable.

- 图像在传递中失真。  
  → túxiàng zài chuándì zhōng shīzhēn.  
  → The image becomes distorted in transmission.

- 内容由真实变为虚假。  
  → nèiróng yóu zhēnshí biàn wéi xūjiǎ.  
  → The content changed from true to false.

### Notes
For movement into a negative state, Chinese again uses **变 / 变得 / 变为 / 越来越**.  
With **失真**, the dynamic reading is especially natural because the word itself often implies loss of fidelity.  
With **失实**, the subject is usually a **报道、内容、说法** type of expression rather than a person or object in general.

---

## 3. BECOMING OFFICIALLY VERIFIED AS TRUE

### Pattern
X + 属实  
X + 经查属实 / 查证属实  
尚未证实 + X + 是否属实

### Examples
- 举报内容属实。  
  → jǔbào nèiróng shǔshí.  
  → The reported content has been verified as true.

- 经查属实。  
  → jīng chá shǔshí.  
  → It was verified as true upon investigation.

- 尚未证实是否属实。  
  → shàngwèi zhèngshí shìfǒu shǔshí.  
  → It has not yet been confirmed whether it is true.

### Notes
For **属实**, Chinese usually does **not** use a common everyday “become true” pattern like *变得属实*.  
Instead, the language prefers **verification constructions** such as **属实 / 经查属实 / 查证属实 / 尚未证实是否属实**.  
So here the dynamic meaning is encoded as a **change in verification status**, not as an ordinary adjectival change-of-state.

## 4. CAUSING SOMETHING TO BECOME UNCLEAR, DISTORTED, OR LESS CREDIBLE

### Pattern
Y + 使/让 + X + 变得 + 不可信/不准确  
Y + 使/让 + X + 失真  
Y + 使/让 + 事实/情况 + 不清楚

### Examples
- 压缩过度会让图像失真。  
  → yāsuō guòdù huì ràng túxiàng shīzhēn.  
  → Excessive compression can make the image distorted.

- 这则谣言使事实变得不清楚。  
  → zhè zé yáoyán shǐ shìshí biàn de bù qīngchu.  
  → This rumor made the facts unclear.

- 这段话让这一说法变得不太可信。  
  → zhè duàn huà ràng zhè yī shuōfǎ biàn de bù tài kěxìn.  
  → These words made this claim less believable.

### Notes
Chinese commonly uses **使 / 让** for causation.  
This is especially natural with **失真, 不可信, 不准确** and similar evaluative states.  
The result can also be expressed analytically with **变得** after the causative verb.

## 5. CAUSING FALSEHOOD OR FABRICATION AS AN EVENT

### Pattern
Y + 发布 + 虚假信息  
Y + 伪造 + 事实/证件/签名  
Y + 弄虚作假

### Examples
- 发布虚假信息。  
  → fābù xūjiǎ xìnxī.  
  → Disseminate false information.

- 伪造事实。  
  → wěizào shìshí.  
  → Fabricate facts.

- 伪造证件。  
  → wěizào zhèngjiàn.  
  → Forge documents.

- 弄虚作假。  
  → nòng xū zuò jiǎ.  
  → Engage in falsification or fraud.

### Notes
Chinese often expresses caused falsity not by “make X false” but by an **eventive lexical verb**:
- **发布虚假信息**
- **伪造事实**
- **伪造证件**
- **弄虚作假**

These are more natural than a purely adjectival causative paraphrase in many contexts.

## 6. CAUSING CORRECTION OR MOVEMENT TOWARD A CORRECT STATE

### Pattern
Y + 纠正 + 错误  
X + 由 + 错误 + 变为 + 正确  
X + 变得 + 正确/准确

### Examples
- 纠正错误。  
  → jiūzhèng cuòwù.  
  → Correct an error.

- 这个答案后来变得正确了。  
  → zhège dá’àn hòulái biàn de zhèngquè le.  
  → This answer later became correct.

- 表达修改后变得更准确。  
  → biǎodá xiūgǎi hòu biàn de gèng zhǔnquè.  
  → The expression became more accurate after revision.

### Notes
For **正确 / 错误**, Chinese has a strong lexical dynamic pair:
- **犯错误**
- **承认错误**
- **纠正错误**

Among these, **纠正错误** is the clearest causative movement toward a correct state.  
A plain causative like “make X correct” is less idiomatic than using **纠正**.

---

## 7. ENTERING OR LEAVING A STATE OF ERROR

### Pattern
X + 犯错误  
X + 承认错误  
Y + 纠正错误  
X + 由 + 正确 + 变为 + 错误

### Examples
- 他犯错误了。  
  → tā fàn cuòwù le.  
  → He made a mistake.

- 他承认错误。  
  → tā chéngrèn cuòwù.  
  → He admitted his mistake.

- 老师纠正错误。  
  → lǎoshī jiūzhèng cuòwù.  
  → The teacher corrected the error.

### Notes
Here Chinese often uses **lexical event expressions** rather than simple state-change adjectives.  
**犯错误** encodes entry into an error event/state.  
**承认错误** encodes recognition of that state.  
**纠正错误** encodes removal of that state.

## 8. TRUTHFUL REPORTING AS CONTROLLED ACTION

### Pattern
如实 + 回答/报告/说明情况/陈述/反映

### Examples
- 请如实回答。  
  → qǐng rúshí huídá.  
  → Please answer truthfully.

- 如实报告。  
  → rúshí bàogào.  
  → Report truthfully.

- 如实说明情况。  
  → rúshí shuōmíng qíngkuàng.  
  → Explain the situation truthfully.

- 如实陈述。  
  → rúshí chénshù.  
  → State the facts truthfully.

### Notes
This is not a change-of-state pattern, but it is a key **dynamic action pattern** in the truth domain.  
Chinese often encodes truth not as “be true” but as **act in accordance with facts**.  
**如实** strongly prefers reporting verbs and is especially common in legal, administrative, and investigative contexts.

## 9. STABILITY OF TRUTH OR FALSITY

### Pattern
X + 是真的 / 很真实 / 很可靠 / 很可信  
假的真不了，真的假不了  
千真万确

### Examples
- 这是真的。  
  → zhè shì zhēn de.  
  → This is true.

- 这个消息很可靠。  
  → zhège xiāoxi hěn kěkào.  
  → This information is reliable.

- 千真万确。  
  → qiān zhēn wàn què.  
  → Absolutely true.

- 假的真不了，真的假不了。  
  → jiǎ de zhēn bù liǎo, zhēn de jiǎ bù liǎo.  
  → What is fake cannot become real, and what is real cannot become fake.

### Notes
Chinese also encodes stability through emphatic or proverbial expressions.  
Especially notable is:

- **千真万确**: strong assertion of stable truth
- **假的真不了，真的假不了**: explicit statement that truth and falsity do not ultimately reverse

This last expression directly comments on resistance to change between opposed truth states.

## 10. RESEMBLANCE APPROACHING TRUTH WITHOUT BECOMING TRUE

### Pattern
X + 很/更 + 逼真  
X + 高仿真  
X + 以假乱真

### Examples
- 效果很逼真。  
  → xiàoguǒ hěn bīzhēn.  
  → The effect is very realistic.

- 这个模型高仿真。  
  → zhège móxíng gāo fǎngzhēn.  
  → This model is highly realistic.

- 这种东西可以以假乱真。  
  → zhè zhǒng dōngxi kěyǐ yǐ jiǎ luàn zhēn.  
  → This kind of thing can pass off the fake as real.

### Notes
With **仿真 / 逼真**, the dynamic is often not “become true” but “approach the appearance of truth.”  
The idiom **以假乱真** is especially important: it encodes a situation where falsity becomes hard to distinguish from genuineness, without actually becoming genuine.

**No strongly established general causative pattern identified** such as:
- *让X名副其实*
- *让X货真价实*

### Notes
These expressions are mainly used as **evaluative result states** or fixed descriptions:

Among them, **保留原汁原味** is dynamic in the sense of preservation, but not a general “become/cause to become” truth-state pattern.

## 12. OVERALL TENDENCY

### Summary
Chinese encodes truth-related dynamics in several different ways rather than with one uniform pattern:

1. **Ordinary change-of-state**
   - **变 / 变得 / 变为 / 越来越**
   - especially with **真实, 可信, 可靠, 准确, 不可信, 不准确, 失实, 失真**

2. **Verification-result constructions**
   - **属实 / 经查属实 / 查证属实 / 尚未证实是否属实**
   - especially for officially confirmed truth

3. **Lexical event verbs**
   - **伪造, 发布虚假信息, 弄虚作假, 纠正错误, 犯错误**
   - especially for falsification, correction, and error events

4. **Action-manner constructions**
   - **如实回答 / 如实报告 / 如实陈述**
   - truth encoded as reporting according to facts

5. **Resemblance without genuineness**
   - **逼真 / 仿真 / 以假乱真**
   - approach to truth in appearance, not actual truth
