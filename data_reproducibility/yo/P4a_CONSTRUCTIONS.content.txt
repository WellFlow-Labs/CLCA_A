# CLCA Protocol v3.4 — P4a_CONSTRUCTIONS
# Language: Yoruba (yo)

## 1. ATTRIBUTION

### Pattern
**Subject + tọ́** (for correctness/truth)
**Subject + jẹ́ + òtítọ́** (for truth as nominal predicate)
**Subject + purọ́** (for falsehood)

### Examples
- Ọ̀rọ̀ náà tọ́
  - ọ̀rọ̀ náà tọ́
  - "That statement is true/correct"

- Ìròyìn yìí jẹ́ irọ́
  - ìròyìn yìí jẹ́ irọ́
  - "This news is a lie"

### Notes
Basic predication uses the stative verb **tọ́** directly for truth/correctness. For nominal predicates (òtítọ́, irọ́), the copula **jẹ́** is required. The verb **purọ́** functions as intransitive predicate for falsehood.

---

## 2. NEGATIVE ATTRIBUTION

### Pattern
**Subject + kò + tọ́** (negation of correctness)
**Subject + kò + jẹ́ + òtítọ́** (negation of nominal truth predicate)

### Examples
- Ọ̀rọ̀ náà kò tọ́
  - ọ̀rọ̀ náà kò tọ́
  - "That statement is not true/correct"

- Èyí kò jẹ́ òtítọ́
  - èyí kò jẹ́ òtítọ́
  - "This is not the truth"

### Notes
Standard preverbal negator **kò** precedes both stative verbs and copular constructions. Emphatic negation adds **rárá** ("at all") sentence-finally: **kò tọ́ rárá**.

---

## 3. ADNOMINAL MODIFICATION

### Pattern
**Noun + tọ́** (postnominal stative verb as relative)
**Noun + òtítọ́** (noun-noun compound/juxtaposition)
**Noun + gidi** (postnominal adjective)

### Examples
- ọ̀rọ̀ tọ́
  - ọ̀rọ̀ tọ́
  - "true word, correct statement"

- ẹ̀rí òtítọ́
  - ẹ̀rí òtítọ́
  - "truthful evidence, true testimony"

### Notes
Yoruba uses postnominal modification. Stative verbs like **tọ́** function as relative clauses without overt relativizer. Nouns like **òtítọ́** and adjectives like **gidi** follow the head noun directly.

---

## 4. BECOME / INCHOATIVE

### Pattern
**Subject + di + òtítọ́** (become truth)
**(no common expression for "become true" as state change)**

### Examples
- Ọ̀rọ̀ náà di òtítọ́
  - ọ̀rọ̀ náà di òtítọ́
  - "That matter became the truth / turned out to be true"

### Notes
The verb **di** (become, turn into) combines with nominal **òtítọ́** for inchoative meaning. However, there is no common construction for statements "becoming true" as a change of truth-value—truth is typically treated as static. The **di** construction expresses discovery or revelation rather than change in truth-value.

---

## 5. CAUSATIVE

### Pattern
**(no productive morphological causative)**
**Periphrastic: Subject + mú + kí + Clause** (make it that...)
**Periphrastic: Subject + jẹ́ + kí + Clause** (cause/allow it that...)

### Examples
- Ó mú kí ọ̀rọ̀ náà tọ́
  - ó mú kí ọ̀rọ̀ náà tọ́
  - "He/she made that statement true / verified it"

- Ó jẹ́ kí n sọ òtítọ́
  - ó jẹ́ kí n sọ òtítọ́
  - "He/she allowed me to tell the truth"

### Notes
Yoruba lacks morphological causative derivation for truth predicates. Causation is expressed periphrastically using **mú kí** (make/cause) or **jẹ́ kí** (allow/let) with subjunctive complement. These constructions are pragmatically marked and less common than simple assertion.

---

## 6. ABSTRACT NOMINALIZATION

### Pattern
**ò- + tí + Verb** (primary pattern: òtítọ́)
**ì- + Verb** (productive pattern: ìgbàgbọ́, ìdájú, ìbámu)
**àì- + Verb** (negative nominalization: àìtọ́, àìmọ̀)

### Examples
- òtítọ́
  - òtítọ́
  - "truth, truthfulness" (from tọ́ "be correct")

- ìgbàgbọ́
  - ìgbàgbọ́
  - "belief, faith" (from gbàgbọ́ "believe")

### Notes
The **ò-tí-** pattern is lexicalized for **òtítọ́**. The **ì-** prefix is highly productive for creating abstract nouns from verbs (ìbámu, ìdájú, ìjọ). The **àì-** prefix creates negative abstract nouns (incorrectness, ignorance).

---

## 7. AGENTIVE NOMINALIZATION

### Pattern
**a- + Verb** (agentive prefix)
**ọmọ + Noun** (child of X = person characterized by X)
**ẹni + Noun** (person of X, formal)

### Examples
- apurọ́
  - apurọ́
  - "liar" (from purọ́ "to lie")

- ọmọ òtítọ́
  - ọmọ òtítọ́
  - "truthful person, child of truth"

### Notes
The **a-** prefix creates agent nouns but is not productive with **tọ́** (*atọ́ "truth-teller" is not attested). Instead, **ọmọ + òtítọ́** or **ẹni + òtítọ́** express "truthful person." The pattern **apurọ́** (liar) is lexicalized.

---

## 8. COMPLEMENTATION (PROPOSITIONAL EMBEDDING)

### Pattern
**Verb + pé + Clause** (that-clause with complementizer pé)
**Verb + bí + Clause** (how/whether-clause)

### Examples
- Mo gbàgbọ́ pé ó tọ́
  - mo gbàgbọ́ pé ó tọ́
  - "I believe that it is true"

- Mo mọ̀ bí ó ṣe tọ́
  - mo mọ̀ bí ó ṣe tọ́
  - "I know how it is true / whether it is true"

### Notes
The complementizer **pé** introduces declarative complements after verbs like **gbàgbọ́** (believe), **mọ̀** (know), **sọ** (say). The complementizer **bí** introduces interrogative or manner complements. This is the standard pattern for propositional attitude reports.

---

## 9. EMPHATIC/FOCUS CONSTRUCTIONS

### Pattern
**Noun/Predicate + ni + (Subject) + Verb** (focus with ni)
**Nitootọ́ + Clause** (adverbial emphasis: truly)
**Predicate + gan-an** (emphatic particle: indeed, really)

### Examples
- Òtítọ́ ni mo sọ
  - òtítọ́ ni mo sọ
  - "It is the truth that I spoke" (emphatic)

- Ó tọ́ gan-an
  - ó tọ́ gan-an
  - "It is really true / absolutely correct"

### Notes
The focus particle **ni** (or **l-** assimilated form) marks focused constituents, typically fronted. The adverb **nitootọ́** (< ní tòótọ́ "in truth") provides sentence-level emphasis. The particle **gan-an** adds emphatic force to predicates.

---

## 10. SERIAL VERB CONSTRUCTIONS

### Pattern
**V₁ + Object + V₂** (verb serialization without conjunction)
**fi + Object + hàn** (use X show = reveal X)
**bá + Object + mu** (meet X hold = correspond to X)

### Examples
- Mo fi òtítọ́ hàn
  - mo fi òtítọ́ hàn
  - "I revealed the truth" (lit: I used truth showed)

- Ó bá ọ̀rọ̀ náà mu
  - ó bá ọ̀rọ̀ náà mu
  - "It corresponds to that statement" (lit: it met that-matter held)

### Notes
Yoruba extensively uses verb serialization where multiple verbs share a subject without overt coordination. The **fi...hàn** pattern (instrumental + show) is productive for "reveal/demonstrate." The **bá...mu** pattern (meet + hold) is lexicalized for "correspond."

---

## 11. LIGHT VERB CONSTRUCTIONS

### Pattern
**ṣe + Noun/Adjective** (do/be + predicate)
**ní + Noun** (have + noun)

### Examples
- Ó ṣe pàtàkì
  - ó ṣe pàtàkì
  - "It is important" (lit: it does importance)

- Ó ní ìwà rere
  - ó ní ìwà rere
  - "He/she has good character"

### Notes
The verb **ṣe** functions as highly productive light verb/copula combining with nouns and adjectives to form complex predicates. The verb **ní** (have) creates possessive constructions used for character attribution. These patterns are central to truth-domain expressions.

---

## 12. DEGREE MODIFICATION

### Pattern
**Predicate + púpọ̀** (much, greatly)
**Predicate + díẹ̀** (a little)
**Predicate + jù** (exceed, more than)

### Examples
- Ó jọ ọ́ púpọ̀
  - ó jọ ọ́ púpọ̀
  - "It resembles it greatly / is very similar"

- Ó tọ́ jù ú lọ
  - ó tọ́ jù ú lọ
  - "It is more correct than it"

### Notes
Degree modification uses postverbal adverbs. **Púpọ̀** intensifies, **díẹ̀** diminishes. Comparative uses **jù** (exceed) with optional **lọ** (go). However, truth predicates like **tọ́** rarely take degree modification—truth is typically binary rather than scalar.

---

## 13. INTERROGATIVE CONSTRUCTIONS

### Pattern
**Ṣé + Clause** (yes/no question particle)
**Question-word + Clause** (wh-questions)

### Examples
- Ṣé ó tọ́?
  - ṣé ó tọ́
  - "Is it true? / Is it correct?"

- Kí ni òtítọ́?
  - kí ni òtítọ́
  - "What is truth?"

### Notes
The particle **ṣé** marks polar questions without changing word order. Wh-questions use question words (**kí** "what," **ta** "who," **níbo** "where," etc.) with focus marker **ni**. These patterns apply regularly to truth predicates.

---

## 14. CONDITIONAL CONSTRUCTIONS

### Pattern
**Bí + Clause₁ + Clause₂** (if...then)
**Tí + Clause₁ + Clause₂** (if/when...then)

### Examples
- Bí ó bá tọ́, a ó gbà á
  - bí ó bá tọ́, a ó gbà á
  - "If it is true, we will accept it"

- Tí ó bá jẹ́ òtítọ́, sọ ọ́
  - tí ó bá jẹ́ òtítọ́, sọ ọ́
  - "If it is the truth, say it"

### Notes
Conditional clauses use **bí** or **tí** with subjunctive marker **bá** in the protasis. The apodosis may contain future marker **ó** or imperative. These constructions apply regularly to truth evaluations in hypothetical contexts.

---

## 15. PROVERBIAL/IDIOMATIC PATTERNS

### Pattern
**Noun₁ + á + Verb + Noun₂** (proverbial future)
**Noun + Verb (stative)** (proverbial assertion)

### Examples
- Òtítọ́ á kọjá irọ́
  - òtítọ́ á kọjá irọ́
  - "Truth will surpass lies" (proverb)

- Òtítọ́ korò
  - òtítọ́ korò
  - "Truth is bitter" (proverb)

### Notes
Proverbs use future marker **á** for gnomic assertions or simple stative predicates. These are conventionalized expressions with cultural significance. They function as complete utterances in moral discourse and instruction.
