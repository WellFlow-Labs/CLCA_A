# CLCA Protocol v3.4 — P4a_CONSTRUCTIONS
# Language: Finnish (fi)

## 1. ATTRIBUTION

### Pattern
**X on tosi/totuus/oikea/väärä** — Predicative adjective or noun construction using copula *olla* "to be" + nominative (subject) or partitive (negation/mass). Truth-domain adjectives function as predicates; abstract nouns require partitive case.

### Examples
- **Se on totta.** / se on totta / "That is true."
- **Väite on väärä.** / väite on väärä / "The claim is false."

### Notes
Finnish uses partitive case (*totta*) with abstract noun *totuus* in predicative position. Adjectives (*tosi*, *oikea*, *väärä*) remain nominative. Negation triggers partitive: *ei ole totta* "is not true."

---

## 2. NEGATIVE ATTRIBUTION

### Pattern
**X ei ole totta/tosi/oikea** — Negation particle *ei* + copula *ole* + partitive case. Standard negation pattern for predicative constructions.

### Examples
- **Se ei ole totta.** / se ei ole totta / "That is not true."
- **Väite ei pidä paikkaansa.** / väite ei pidä paikkaansa / "The claim does not hold / is not true."

### Notes
Partitive case obligatory in negated predicative constructions. Fixed expression *ei pidä paikkaansa* (literally "doesn't hold its place") serves as formal negation of truth claims.

---

## 3. ADNOMINAL MODIFICATION

### Pattern
**[ADJ] + [NOUN]** — Direct adjectival modification with agreement in case and number. Truth-domain adjectives freely modify nouns denoting statements, information, accounts, etc.

### Examples
- **tosi asia** / tosi asia / "true matter/fact"
- **väärä käsitys** / väärä käsitys / "wrong impression/misconception"

### Notes
Adjectives precede nouns and agree in case/number. Compound *tosiasia* "fact" is lexicalized. Common collocations: *oikea vastaus* "correct answer," *luotettava lähde* "reliable source," *uskottava selitys* "credible explanation."

---

## 4. BECOME / INCHOATIVE

### Pattern
**[VERB-stem] + -u-/-y- + infinitive suffix** — Reflexive/inchoative derivation creates intransitive "become X" verbs from causative bases. Productive pattern for truth-domain state changes.

### Examples
- **Totuus paljastuu.** / totuus paljastuu / "The truth is revealed / comes to light."
- **Suunnitelma toteutui.** / suunnitelma toteutui / "The plan was realized / came true."

### Notes
Inchoative suffix *-u-/-y-* derives from causatives: *todellistaa* → *todellistua* "become real," *vääristää* → *vääristyä* "become distorted." Also: *todentua* "be verified," *toteutua* "be realized."

---

## 5. CAUSATIVE

### Pattern
**[ADJ/NOUN-stem] + -tta-/-ttä- or -sta-/-stä- + infinitive** — Causative derivation creates transitive "make X" verbs from adjectives/nouns. Highly productive in truth domain.

### Examples
- **todistaa syyttömyytensä** / todistaa syyttömyytensä / "prove one's innocence"
- **vääristää totuutta** / vääristää totuutta / "distort the truth"

### Notes
Multiple causative patterns: *todellinen* → *todellistaa* "realize," *väärä* → *vääristää* "distort," *väärä* → *väärentää* "forge." Root *tosi* → *todistaa* "prove" shows irregular causative formation.

---

## 6. ABSTRACT NOMINALIZATION

### Pattern
**[ADJ-stem] + -uus/-yys/-suus** — Productive abstract noun formation from adjectives. Creates quality/state nouns central to truth-domain discourse.

### Examples
- **totuus** / totuus / "truth" (< *tosi* "true")
- **rehellisyys** / rehellisyys / "honesty" (< *rehellinen* "honest")

### Notes
Highly productive: *oikeellisuus* "correctness," *aitous* "genuineness," *luotettavuus* "reliability," *uskottavuus* "credibility," *todennäköisyys* "probability." Suffix variant depends on stem phonology.

---

## 7. AGENTIVE NOMINALIZATION

### Pattern
**[VERB-stem] + -ja/-jä** — Agent noun formation from verbs. Creates person nouns for those who perform truth-related actions.

### Examples
- **todistaja** / todistaja / "witness" (< *todistaa* "testify/prove")
- **valehtelija** / valehtelija / "liar" (< *valehdella* "to lie")

### Notes
Productive pattern: *väittelijä* "debater" (< *väitellä* "debate"). Note: no simple agent noun from *puhua totuutta* "speak truth" — Finnish uses descriptive *totuudenpuhuja* (compound) or *rehellinen ihminen* "honest person."

---

## 8. FIXED INESSIVE CONSTRUCTIONS

### Pattern
**olla + [NOUN-INESS]** — Grammaticalized spatial metaphor using inessive case ("being in X") for epistemic states. Highly conventionalized for correctness evaluation.

### Examples
- **Sinä olit oikeassa.** / sinä olit oikeassa / "You were right."
- **Minä olin väärässä.** / minä olin väärässä / "I was wrong."

### Notes
Fixed expressions: *olla oikeassa* "be right," *olla väärässä* "be wrong." Spatial metaphor fully grammaticalized. Also: *tosiasiassa* "in fact" (< *tosiasia* + inessive), *tosissaan* "seriously" (< *tosi* + inessive + possessive).

---

## 9. COMPLEMENT CLAUSE CONSTRUCTIONS

### Pattern
**[PREDICATE] + että + [CLAUSE]** — Epistemic predicates take *että* "that" complement clauses. Common with truth-evaluation and claim-making verbs.

### Examples
- **On todennäköistä, että hän tulee.** / on todennäköistä että hän tulee / "It is probable that he/she will come."
- **Hän väittää, että näki kaiken.** / hän väittää että näki kaiken / "He/she claims that he/she saw everything."

### Notes
Common predicates: *on tosiasia että* "it is a fact that," *on todettava että* "it must be noted that," *väittää että* "claim that." Impersonal constructions frequent in formal discourse.

---

## 10. TRANSLATIVE CONSTRUCTIONS

### Pattern
**[VERB] + [ADJ-TRANSLATIVE]** — Translative case marks result state in proving/showing constructions. Productive pattern for truth-evaluation outcomes.

### Examples
- **Väite todistettiin vääräksi.** / väite todistettiin vääräksi / "The claim was proven false."
- **Teoria todistettiin oikeaksi.** / teoria todistettiin oikeaksi / "The theory was proven correct."

### Notes
Translative case (*-ksi*) marks transformation to new state. Common with *todistaa* "prove," *osoittaa* "show," *paljastua* "be revealed." Pattern: X todistetaan Y:ksi "X is proven to be Y."

---

## 11. ADVERBIAL EXPRESSIONS

### Pattern
**[ADJ/NOUN] + -sti** or **[CASE-FORM]** — Adverb formation via suffix *-sti* or grammaticalized case forms. Creates manner and epistemic adverbs.

### Examples
- **Rehellisesti sanottuna, en tiedä.** / rehellisesti sanottuna en tiedä / "Honestly speaking, I don't know."
- **Todennäköisesti hän tulee huomenna.** / todennäköisesti hän tulee huomenna / "Probably he/she will come tomorrow."

### Notes
Productive *-sti* pattern: *oikeasti* "really," *aidosti* "genuinely," *vilpittömästi* "sincerely." Grammaticalized forms: *tosiasiassa* "in fact," *tosissaan* "seriously." Fixed expressions: *totta puhuen* "truthfully speaking."

---

## 12. EMPHATIC CONSTRUCTIONS

### Pattern
**[INTENSIFIER] + [TRUTH-TERM]** or **[FIXED EXPRESSION]** — Intensification through adverbs or fixed emphatic expressions. Common in conversational and assertive contexts.

### Examples
- **Se on ihan tosi.** / se on ihan tosi / "It's completely true / totally real."
- **Totta kai tulen.** / totta kai tulen / "Of course I'll come."

### Notes
Intensifiers: *ihan* "completely," *aivan* "quite," *täysin* "totally." Fixed expressions: *totta kai* "of course," *totta tosiaan* "indeed," *tosiaankin* "really indeed." Collocations: *puhdas totuus* "pure truth," *koko totuus* "whole truth."

---

## 13. VERB + OBJECT COLLOCATIONS

### Pattern
**[VERB] + [TRUTH-NOUN-PARTITIVE/GENITIVE]** — Conventionalized verb-object pairings with truth-domain nouns. Partitive case for objects; genitive in compounds.

### Examples
- **puhua totuutta** / puhua totuutta / "speak the truth"
- **paljastaa valhe** / paljastaa valhe / "expose the lie"

### Notes
Common patterns: *puhua valhetta* "tell a lie," *vääristää totuutta* "distort truth," *esittää todisteita* "present evidence," *todistaa syyttömyytensä* "prove one's innocence." Partitive case standard for objects.

---

## 14. PASSIVE PARTICIPLE CONSTRUCTIONS

### Pattern
**[VERB-stem] + -tta-/-ttä- + -va/-vä** — Passive participle formation creates adjectives expressing possibility/necessity. Productive in truth domain for "can be X-ed" meanings.

### Examples
- **uskottava selitys** / uskottava selitys / "credible explanation" (lit. "believable")
- **todistettavasti väärä** / todistettavasti väärä / "demonstrably false"

### Notes
Pattern: *uskoa* "believe" → *uskottava* "believable," *luottaa* "trust" → *luotettava* "reliable," *todistaa* "prove" → *todistettava* "provable." Often lexicalized as adjectives. Adverb: *todistettavasti* "demonstrably."

---

## 15. RESULT NOMINALIZATION

### Pattern
**[VERB-stem] + -us/-ys, -e, -ma/-mä, -os/-ös** — Multiple patterns create result/product nouns from verbs. Productive across truth-domain verbs.

### Examples
- **todiste** / todiste / "proof, evidence" (< *todistaa* "prove")
- **väärennös** / väärennös / "forgery, counterfeit" (< *väärentää* "forge")

### Notes
Multiple suffixes: *todistus* "certificate," *toteamus* "statement," *vääristymä* "distortion," *väitös* "dissertation defense." Choice of suffix often lexically determined. Creates concrete or abstract result nouns.

---

## 16. GERUND CONSTRUCTIONS

### Pattern
**[VERB-stem] + -minen** — Gerund formation creates action/process nouns. Highly productive; functions as verbal noun in all cases.

### Examples
- **suunnitelman toteuttaminen** / suunnitelman toteuttaminen / "implementation of the plan"
- **henkilöllisyyden todentaminen** / henkilöllisyyden todentaminen / "verification of identity"

### Notes
Fully productive: *lukeminen* "reading," *toteuttaminen* "implementing," *todentaminen* "verifying." Takes genitive objects. Functions as head noun in formal/technical discourse. Neutral regarding aspect/completion.

---

## 17. COMPOUND FORMATION

### Pattern
**[TRUTH-TERM] + [NOUN]** — Productive compounding with truth-domain terms as first element. Creates specialized vocabulary.

### Examples
- **tosielämä** / tosielämä / "real life" (< *tosi* + *elämä* "life")
- **väärennösrikos** / väärennösrikos / "forgery crime" (< *väärennös* + *rikos* "crime")

### Notes
Highly productive with *tosi-*: *tositarina* "true story," *tosi-tv* "reality TV," *tosiystävä* "true friend." Also: *todistusaineisto* "evidentiary material," *todistustaakka* "burden of proof." First element often in genitive: *totuuden hetki* "moment of truth."

---

## 18. POSTPOSITIONAL CONSTRUCTIONS

### Pattern
**[NOUN-GENITIVE] + [POSTPOSITION]** — Truth-domain nouns with postpositions create adverbial or prepositional phrases. Common in formal discourse.

### Examples
- **todisteiden perusteella** / todisteiden perusteella / "based on the evidence"
- **tosiasioihin perustuva** / tosiasioihin perustuva / "based on facts"

### Notes
Common postpositions: *perusteella* "based on," *mukaan* "according to." Pattern: NOUN-GEN + postposition. Participial form: *tosiasioihin perustuva päätös* "fact-based decision" (illative case + *perustua* "be based on").

---

## 19. FREQUENTATIVE/ITERATIVE DERIVATION

### Pattern
**[NOUN-stem] + -lla/-llä** — Frequentative verb formation from nouns, indicating repeated or characteristic action. Less productive than other patterns.

### Examples
- **valehdella** / valehdella / "to lie (repeatedly)" (< *valhe* "lie")
- (no common expression identified for other truth-domain terms)

### Notes
Pattern creates verbs from nouns: *valhe* → *valehdella* "to lie." Not productive across truth domain — no *\*totuudella* or *\*todistella* in standard usage. *Valehdella* is the primary example; implies habitual or repeated lying.

---

## 20. PRIVATIVE DERIVATION

### Pattern
**[NOUN-stem] + -tön/-ttömyys** — Privative suffix creates adjectives/nouns meaning "without X." Limited productivity in truth domain.

### Examples
- **vilpitön** / vilpitön / "sincere, genuine" (< *vilppi* "deceit" + *-tön* "without")
- **vilpittömyys** / vilpittömyys / "sincerity" (< *vilpitön* + *-yys*)

### Notes
*Vilpitön* (literally "without deceit") is main truth-domain example. Pattern productive elsewhere (*työtön* "unemployed") but limited here. Note: *vilppi* "deceit" itself not in P1 core vocabulary; *vilpitön* is the established form.

---

## 21. NEGATIVE PREFIX DERIVATION

### Pattern
**epä- + [ADJ/NOUN]** — Negative prefix creates antonyms. Moderately productive in truth domain.

### Examples
- **epätosi** / epätosi / "untrue, false" (< *epä-* + *tosi*)
- **epärehellinen** / epärehellinen / "dishonest" (< *epä-* + *rehellinen*)

### Notes
Productive pattern: *epätosi* "untrue," *epärehellinen* "dishonest," *epäluotettava* "unreliable." Less productive than simple antonyms (*väärä* preferred over *epäoikea*). Creates formal/technical variants.

---

## 23. MANNER ADVERBIAL CONSTRUCTIONS

### Pattern
**[ADJ-ADESSIVE] + tavalla/tavoin** — Manner construction using adessive case + *tapa* "way/manner." Productive pattern for expressing "in X manner."

### Examples
- **oikealla tavalla** / oikealla tavalla / "in the right way / correctly"
- **väärällä tavalla** / väärällä tavalla / "in the wrong way / incorrectly"

### Notes
Productive pattern: ADJ-ADESSIVE (*oikealla*, *väärällä*) + *tavalla/tavoin* "way/manner." Alternative to simple adverbs. More explicit than *oikein*/*väärin*. Common in instructions and evaluations.

---

## SUMMARY

Finnish truth-domain constructions show:

1. **Rich derivational morphology**: Productive suffixes create adjectives (*-llinen*), abstract nouns (*-uus/-yys*), causatives (*-tta-/-sta-*), inchoatives (*-u-/-y-*), agents (*-ja*), results (*-us/-e/-ma*), gerunds (*-minen*)

2. **Case-based patterns**: Inessive (*oikeassa/väärässä*), partitive (negation, objects), translative (result states), adessive (manner), genitive (compounds)

3. **Grammaticalized expressions**: Fixed phrases (*totta kai*, *olla oikeassa*), adverbials (*tosiasiassa*, *tosissaan*)

4. **Productive compounding**: Especially with *tosi-* prefix (*tosielämä*, *tositarina*)

5. **Complement structures**: *että*-clauses with epistemic predicates

6. **Selective productivity**: Not all patterns apply to all roots (e.g., causative gaps)

The system balances productive morphological patterns with lexicalized expressions, showing both systematic derivation and conventionalized constructions.
