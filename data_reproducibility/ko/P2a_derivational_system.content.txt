# CLCA Protocol v3.4 — P2a Derivational System
# Language: Korean (ko)

---

## DERIVATIONAL ANALYSIS

### Methodological Note

Korean derivational morphology operates through several mechanisms:
1. **Suffixation** (e.g., -성 for abstract nouns, -스럽다 for adjectival derivation)
2. **Compounding** (highly productive in Korean)
3. **Verb/adjective stem derivation** (e.g., -하다 verbalization)
4. **Nominalization** (various patterns)

The analysis below documents only attested forms with clear derivational relationships to P1 base items.

## DERIVATIONS BY BASE FORM

### 1. Base: 진실 (jinsil) "truth"

**Derived Form 1:**
- **Base Form:** 진실 (jinsil)
- **Derived Form:** 진실하다 (jinsilhada)
- **Transliteration:** jinsilhada
- **Literal Breakdown:** 진실 + 하다 (truth + do/be)
- **Translation:** to be truthful, to be true
- **Usage:** Adjectival verb describing truthful character or statements. Common in both written and spoken contexts, e.g., "진실한 사람" (truthful person).
- **Status:** [CORE]

**Derived Form 2:**
- **Base Form:** 진실 (jinsil)
- **Derived Form:** 진실되다 (jinsildoeda)
- **Transliteration:** jinsildoeda
- **Literal Breakdown:** 진실 + 되다 (truth + become)
- **Translation:** to be truthful, to be sincere
- **Usage:** Adjectival verb emphasizing inherent truthful quality. Slightly more formal/literary than 진실하다. Used in "진실된 마음" (sincere heart).
- **Status:** [CORE]

**Derived Form 3:**
- **Base Form:** 진실 (jinsil)
- **Derived Form:** 진실로 (jinsilro)
- **Transliteration:** jinsilro
- **Literal Breakdown:** 진실 + 로 (truth + instrumental/manner suffix)
- **Translation:** truly, truthfully, sincerely
- **Usage:** Adverbial form used to modify verbs or entire clauses. Common in formal speech and writing, e.g., "진실로 감사합니다" (I truly thank you).
- **Status:** [CORE]

**Derived Form 4:**
- **Base Form:** 진실 (jinsil)
- **Derived Form:** 진실히 (jinsilhi)
- **Transliteration:** jinsilhi
- **Literal Breakdown:** 진실 + 히 (truth + adverbial suffix)
- **Translation:** truthfully, sincerely
- **Usage:** Adverbial form, somewhat more formal than 진실로. Used in written and formal spoken contexts.
- **Status:** [CORE]

## SUMMARY OBSERVATIONS

### Productive Derivational Patterns Observed:

1. **-하다 verbalization:** Highly productive for Sino-Korean nouns (e.g., 진실하다, 정직하다, 솔직하다)

2. **-성 (-seong) nominalization:** Productive for creating abstract quality nouns (e.g., 정확성, 정직성, 타당성, 확실성)

3. **-히/-게 adverbialization:** Regular patterns for creating adverbs from adjectives (e.g., 정확히, 솔직히, 명백히)

4. **-로/-으로 instrumental adverbs:** Common for manner adverbs (e.g., 진실로, 사실로, 실제로)

5. **-적 (-jeok) adjectivalization:** Productive for Sino-Korean bases (e.g., 사실적, 본질적, 실제적)

6. **부-/불- negation:** Productive Sino-Korean negative prefix (e.g., 부정확하다, 불확실하다, 부정직하다)

7. **-되다 (-doeda) "become" construction:** Creates adjectival verbs emphasizing inherent quality (e.g., 진실되다, 거짓되다, 참되다)

### Asymmetries and Gaps:

- Native Korean roots (참, 맞다, 옳다) show different derivational patterns than Sino-Korean roots
- Some high-frequency items (거짓말, 진위, 진본) show limited derivational productivity
- Already-derived forms (진실성, 신빙성) do not undergo further derivation
- Compound nouns (거짓말, 모조품) represent endpoints rather than bases for further derivation

### Register and Usage Notes:

- Sino-Korean derivations tend toward formal registers
- Native Korean derivations (참되다, 맞게) span broader register ranges
- Adverbial forms show high frequency across all registers
- Abstract -성 nominalizations cluster in formal, analytical, and academic discourse
