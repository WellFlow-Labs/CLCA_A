# Language: Chinese (zh)

| **1. ATTRIBUTION** | 这是真的 | zhè shì zhēn de | "This is true/real" | [CORE] | Extremely common in everyday speech and writing. The nominalizer 的 (de) is obligatory with monosyllabic adjectives (真, 假) but may be omitted with disyllabic forms in formal registers (e.g., 这是事实 vs. ?这是事实的). |
| | 他的话是假的 | tā de huà shì jiǎ de | "His words are false" | [CORE] | |
| **2. NEGATIVE ATTRIBUTION** | 这不是真的 | zhè bù shì zhēn de | "This is not true/real" | [CORE] | Both patterns (不是 + Adj+的 and 不 + bare Adj) are fully productive. Choice depends on emphasis: copular negation (不是) emphasizes categorical denial, while direct negation (不) focuses on the property itself. |
| | 答案不对 | dá'àn bù duì | "The answer is not correct" | [CORE] | |
| **3. ADNOMINAL MODIFICATION** | 真实的情况 | zhēnshí de qíngkuàng | "the true/actual situation" | [CORE] | Highly productive across all registers. The particle 的 is typically required for disyllabic modifiers but may be omitted in lexicalized compounds (真相, 实话) or when modifier and noun form tight semantic units. |
| | 正确的答案 | zhèngquè de dá'àn | "the correct answer" | [CORE] | |
| **4. BECOME / INCHOATIVE** | 弄假成真 | nòng jiǎ chéng zhēn | "what starts as pretense becomes real" | [MARGINAL] | The bare 变 + Adj pattern is productive but less common with truth-domain terms than with other semantic domains. Most attestations involve lexicalized idioms (弄假成真) or resultative compounds. The pattern 变得 + Adj is more natural in contemporary usage. |
| | 变得不正常 | biàn de bù zhèngcháng | "become abnormal" | [CORE] | |
| **5. CAUSATIVE** | 让事实说话 | ràng shìshí shuōhuà | "let the facts speak" | [CORE] | Periphrastic causatives (使/让 X V) are common but typically involve action verbs rather than direct state change. Resultative verb compounds (改正, 纠正, 证实) are strongly preferred for expressing causation of truth-domain states. |
| | 把错误改正 | bǎ cuòwù gǎizhèng | "correct the mistakes" | [CORE] | |
| **6. ABSTRACT NOMINALIZATION** | 真实性 | zhēnshíxìng | "authenticity, truthfulness" | [CORE] | Highly productive in formal and academic registers. The suffix -性 creates abstract quality nouns; -度 creates measurable degree nouns. Both patterns are restricted to disyllabic bases (*真性, *假度 are unattested). |
| | 准确度 | zhǔnquèdù | "degree of accuracy" | [CORE] | |
| **7. AGENTIVE NOMINALIZATION** | N/A | N/A | N/A | [UNCERTAIN] | No productive morphological pattern identified. Agentive meanings require periphrastic expression (说真话的人 "truth-teller"). The general suffix -者 exists but does not productively combine with truth-domain roots to create specialized agent nouns. |
| **8. VERIFICATION / CONFIRMATION** | 是不是真的? | shì bu shì zhēn de? | "Is it true or not?" | [CORE] | Extremely common in spoken interaction. The A-not-A pattern is the unmarked yes/no question form in Mandarin. Both variants (是不是 Y and Y不Y) are fully productive, with the latter being more colloquial and direct. |
| | 对不对? | duì bu duì? | "Right or not? / Is that correct?" | [CORE] | |
| **9. DEGREE MODIFICATION** | 很真实 | hěn zhēnshí | "very authentic/realistic" | [CORE] | Standard degree modification applies without restriction. Note that 很 (hěn) functions as default intensifier in predicative position and may carry minimal intensifying force. Stronger intensifiers (非常, 十分, 极其) provide clearer emphasis. |
| | 最正确 | zuì zhèngquè | "most correct" | [CORE] | |
| **10. COMPARATIVE CONSTRUCTIONS** | 这个比那个更真实 | zhège bǐ nàge gèng zhēnshí | "This is more authentic than that" | [CORE] | Standard comparative syntax applies productively. The intensifier 更 (gèng) is optional but common in comparative constructions. No specialized comparative forms exist for truth-domain terms. |
| | 他和我一样诚实 | tā hé wǒ yīyàng chéngshí | "He is as honest as I am" | [CORE] | |
| **11. EVIDENTIAL / REPORTATIVE** | 据说是真的 | jùshuō shì zhēn de | "It is said to be true" | [CORE] | These are general reportative markers, not specialized for truth-domain. They indicate information source (hearsay) rather than epistemic stance toward truth value. Common in both spoken and written discourse. |
| | 听说不是事实 | tīngshuō bù shì shìshí | "I heard it's not factual" | [CORE] | |
| **12. MODAL CONSTRUCTIONS (OBLIGATION)** | 应该说实话 | yīnggāi shuō shíhuà | "should tell the truth" | [CORE] | Standard deontic modals combine freely with truth-domain predicates. No specialized modal constructions exist. The choice between 应该 (weaker obligation) and 必须 (stronger obligation) follows general modal semantics, not domain-specific patterns. |
| | 必须面对事实 | bìxū miànduì shìshí | "must face the facts" | [CORE] | |
| **13. INTENSIFICATION / EMPHASIS** | 实实在在 | shíshízàizài | "really and truly, genuinely" | [CORE] | AABB reduplication is productive with disyllabic truth-domain adjectives and creates emphatic, colloquial effect. The intensifying adverb 真 is extremely common in spoken registers. Both patterns are characteristic of informal discourse. |
| | 真诚实 | zhēn chéngshí | "really honest" | [CORE] | |
| **14. RESULTATIVE VERB COMPOUNDS** | 改正 | gǎizhèng | "correct, amend" (change + correct) | [CORE] | Highly productive pattern where truth-domain roots (正, 实, 真) function as resultative complements indicating achieved state. This is a characteristic feature of Chinese verb morphology and creates numerous lexicalized compounds (纠正, 证实, 落实, 坐实). |
| | 落实 | luòshí | "implement, actualize" (fall/settle + solid) | [CORE] | |
| **15. DISCOURSE MARKERS** | 说真的，我不知道 | shuō zhēn de, wǒ bù zhīdào | "Honestly speaking, I don't know" | [CORE] | Common in spoken interaction for managing speaker stance and sincerity. These forms are pragmatically grammaticalized and function as discourse particles rather than compositional phrases. 真的吗 is a fixed interrogative expression for expressing surprise or seeking confirmation. |
| | 真的吗? | zhēn de ma? | "Really? Is that so?" | [CORE] | |

## ALTERNATE CONSTRUCTIONS ATTESTED

### Attribution (Construction 1)
- **Alternate**: Bare adjective predication without copula (e.g., 很真实 "very authentic" in predicative position)
- **Context**: Common in predicative contexts with degree modification, where 是 is typically omitted

### Negative Attribution (Construction 2)
- **Alternate**: 没有 + Noun pattern (e.g., 没有真实性 "lacks authenticity")
- **Context**: Expresses absence rather than negation of property

### Become/Inchoative (Construction 4)
- **Alternate**: 成为 + Noun (e.g., 成为事实 "become fact")
- **Context**: Used with nominalized forms rather than bare adjectives

### Causative (Construction 5)
- **Alternate**: Resultative verb compounds without periphrastic causative (e.g., 证实 "verify/confirm" rather than 使...真实)
- **Context**: Strongly preferred in actual usage; periphrastic causatives are marginal with truth-domain state changes

### Intensification (Construction 13)
- **Alternate**: 确实/的确 + Adj (e.g., 确实真实 "indeed authentic")
- **Context**: More formal register than 真 + Adj; emphasizes speaker certainty
