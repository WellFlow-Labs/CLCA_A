## 1. BECOMING TRUE / REAL

### Pattern
**magkatotoo / nagkatotoo + ang NP**

### Examples
- **Sana magkatotoo ang hiling mo.** → *Sana magkatotoo ang hiling mo.* → “I hope your wish comes true.”
- **Nagkatotoo ang kanyang hinala.** → *Nagkatotoo ang kanyang hinala.* → “His suspicion turned out to be true.”

### Notes
This is the clearest attested dynamic pattern in the material for movement into a truth-related state. It is specifically supported for the **totoo** family, especially with wishes, predictions, fears, suspicions, and expectations.

---

## 2. BECOMING SERIOUS / “FOR REAL”

### Pattern
**totohanan na / totohanin + object**

### Examples
- **Totohanan na ito.** → *Totohanan na ito.* → “This is serious now. / This is for real now.”
- **Totohanin mo na ito.** → *Totohanin mo na ito.* → “Take this seriously now. / Do this for real now.”

### Notes
This is a dynamic extension within the **totoo** family, but it shifts away from factual truth toward seriousness or earnestness. It is colloquial and more restricted than **magkatotoo / nagkatotoo**.

---

## 3. BECOMING ESTABLISHED AS TRUE IN DISCOURSE

### Pattern
**ang katotohanan ay lumabas / lumabas din sa huli**

### Examples
- **Ang katotohanan ay lumabas din sa huli.** → *Ang katotohanan ay lumabas din sa huli.* → “The truth came out in the end.”
- **Ang katotohanan ay mahalaga sa usaping ito.** → *Ang katotohanan ay mahalaga sa usaping ito.* → “The truth is important in this matter.”

### Notes
The first example shows a discourse-dynamic sense in which truth becomes revealed or established. This is not the same as **magkatotoo**: here the focus is on truth emerging in public or in discussion, not on a wish or suspicion becoming real.

## 6. CAUSING SOMETHING TO BE CORRECT / PROPER

### Pattern
**wastuhin + object**

### Examples
- **Wastuhin ang pagkakasulat nito.** → *Wastuhin ang pagkakasulat nito.* → “Correct how this is written.”
- **Wastuhin ang gamit ng terminong iyon.** → *Wastuhin ang gamit ng terminong iyon.* → “Correct the use of that term.”

### Notes
This is the nearest attested causative-like pattern in the material for moving something into a correctness state. It belongs to the **wasto** family and is less common than paraphrases with **tama**, but it is supported.

---

## 7. CAUSING OR ACHIEVING VERIFIED STATUS

### Pattern
**beripikahin + object**

### Examples
- **Beripikahin ang impormasyon bago ito ibahagi.** → *Beripikahin ang impormasyon bago ito ibahagi.* → “Verify the information before sharing it.”
- **Beripikahin muna ang pagkakakilanlan ng aplikante.** → *Beripikahin muna ang pagkakakilanlan ng aplikante.* → “Verify the applicant’s identity first.”

### Notes
This is a procedural dynamic pattern: an agent checks information, identity, or records so that they count as **beripikado**. The material supports the verb **beripikahin** and the resulting modifier **beripikadong**.

---

## 8. RESULTING VERIFIED STATE

### Pattern
**beripikadong + noun**

### Examples
- **Beripikadong impormasyon lamang ang ilalathala.** → *Beripikadong impormasyon lamang ang ilalathala.* → “Only verified information will be published.”
- **Beripikadong account ang pahihintulutan sa plataporma.** → *Beripikadong account ang pahihintulutan sa plataporma.* → “Verified accounts will be allowed on the platform.”

### Notes
This is not itself a change verb, but it encodes the stable result of prior checking. In dynamic terms, it is the state that typically follows **beripikahin**.

---

## 9. SHIFTING A CLAIM INTO A SUPPORTED STATE

### Pattern
**salig sa / nakasalig sa + NP**

### Examples
- **Salig sa ebidensiya ang ulat.** → *Salig sa ebidensiya ang ulat.* → “The report is based on evidence.”
- **Nakasalig sa datos ang kanilang pasya.** → *Nakasalig sa datos ang kanilang pasya.* → “Their decision is based on data.”

### Notes
These expressions do not directly mean “become supported,” but they encode a state in which a report, decision, or judgment rests on evidence or data. They are dynamic in a weaker sense: they describe grounding rather than simple truth.

---

## 10. SHIFTING A CLAIM INTO AN UNSUPPORTED STATE

### Pattern
**walang saligan / walang saligang + noun**

### Examples
- **Walang saligan ang paratang.** → *Walang saligan ang paratang.* → “The accusation is baseless.”
- **Walang saligang haka-haka ang mga iyon.** → *Walang saligang haka-haka ang mga iyon.* → “Those are baseless speculations.”

### Notes
These forms encode the opposed stable state of lacking basis. However, the material does **not** provide a common dynamic expression meaning “become baseless”; it provides only the resulting evaluative state.

## 11. STABILITY OF CERTAINTY

### Pattern
**tiyak na + clause / hindi pa tiyak + NP**  
**sigurado + clause / sigurado ka ba**

### Examples
- **Tiyak na darating siya.** → *Tiyak na darating siya.* → “He will definitely come.”
- **Hindi pa tiyak ang resulta.** → *Hindi pa tiyak ang resulta.* → “The result is not certain yet.”
- **Sigurado akong tama siya.** → *Sigurado akong tama siya.* → “I’m sure he is right.”
- **Sigurado ka ba?** → *Sigurado ka ba?* → “Are you sure?”

### Notes
These forms encode stable or unstable certainty, but the material does not support a dedicated dynamic verb meaning “become certain” or “make certain” within this vocabulary set. The contrast is mainly between settled certainty and not-yet-settled certainty.

---

## 12. STABILITY OF CORRECTNESS

### Pattern
**tama / wasto / tumpak / eksakto + ang NP**

### Examples
- **Tama ang sagot mo.** → *Tama ang sagot mo.* → “Your answer is correct.”
- **Wasto ang paggamit ng terminong iyon.** → *Wasto ang paggamit ng terminong iyon.* → “The use of that term is correct.”
- **Tumpak ang sinabi mo.** → *Tumpak ang sinabi mo.* → “What you said is accurate.”
- **Eksakto ang sukat.** → *Eksakto ang sukat.* → “The measurement is exact.”

### Notes
These are stable evaluative states. Among them, only **wasto** has an attested corrective verb in the material (**wastuhin**). For **tama, tumpak, eksakto**, no common dynamic or causative expression is directly supported here.

---

## 13. STABILITY OF AUTHENTICITY VS FALSENESS

### Pattern
**tunay / totoo / peke / huwad + ang NP**  
**tunay na / totoong / pekeng / huwad na + noun**

### Examples
- **Tunay na ginto ito.** → *Tunay na ginto ito.* → “This is real gold.”
- **Peke iyan.** → *Peke iyan.* → “That is fake.”
- **Peke ang pirma.** → *Peke ang pirma.* → “The signature is fake.”
- **Huwad na pagkakakilanlan ang ginamit niya.** → *Huwad na pagkakakilanlan ang ginamit niya.* → “He used a false identity.”

### Notes
The material strongly supports stable contrasts of authenticity and falseness. But it does **not** provide a common dynamic expression meaning “become genuine,” “become fake,” or “make genuine/fake.”

---

## 14. STABILITY OF RELIABILITY / TRUSTWORTHINESS

### Pattern
**mapagkakatiwalaan / maaasahan + noun**  
**Maaasahan mo siya...**

### Examples
- **Mapagkakatiwalaang saksi ang hinahanap ng hukuman.** → *Mapagkakatiwalaang saksi ang hinahanap ng hukuman.* → “The court is looking for a trustworthy witness.”
- **Maaasahang datos ang kailangan sa ulat.** → *Maaasahang datos ang kailangan sa ulat.* → “Reliable data are needed in the report.”
- **Maaasahan mo siya sa oras ng pangangailangan.** → *Maaasahan mo siya sa oras ng pangangailangan.* → “You can rely on him in times of need.”

### Notes
These forms encode stable reliability. No common dynamic expression meaning “become trustworthy” or “make reliable” is directly supported by the material.

---

## 15. SUMMARY OF WHAT IS CLEARLY DYNAMIC

### Clearly supported dynamic patterns
- **magkatotoo / nagkatotoo** → becoming true / coming true
- **totohanin / totohanan na** → becoming serious / taking seriously
- **beripikahin** → causing something to acquire verified status
- **wastuhin** → causing something to become correct/proper

### Dynamic meanings not clearly supported
- “become fake / false / huwad / peke”
- “make true”
- “become certain” with **tiyak / sigurado**
- “become trustworthy” with **mapagkakatiwalaan / maaasahan**
- “become genuine” with **tunay**

### Notes
The strongest dynamic encoding in the supplied Tagalog material is concentrated in:
1. the **totoo** family, especially **magkatotoo / nagkatotoo**, and  
2. procedural or corrective verbs like **beripikahin** and **wastuhin**.

Most other truth-related items in the context are primarily **stative** or **evaluative**, not dynamic.
