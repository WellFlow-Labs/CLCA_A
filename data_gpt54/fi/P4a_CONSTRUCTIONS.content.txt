## 1. ATTRIBUTION
### Pattern
**X on totta / tosi / epätosi / laillinen / oikea / uskottava / luotettava**  
‘X is true / real / false / legal / correct / credible / reliable’

### Examples
- **Se on totta.** → — → “That is true.”
- **Väite on epätosi.** → — → “The claim is false.”

### Notes
Finnish commonly uses a copular clause with **olla** + predicate adjective/noun-like predicate form for truth-domain evaluation. For “true,” both **totta** and **tosi** occur, while more formal evaluation often uses **epätosi**, **laillinen**, **uskottava**, etc.

## 2. NEGATIVE ATTRIBUTION
### Pattern
**X ei ole totta / tosi / laillinen / uskottava**; also **X ei pidä paikkaansa**  
‘X is not true / legal / credible’; ‘X does not hold true’

### Examples
- **Se ei ole tosi.** → — → “That is not true.”
- **Väite ei pidä paikkaansa.** → — → “The claim is not true.”

### Notes
Negation is normally formed with finite **ei** plus **olla** or with the fixed truth-evaluation expression **pitää paikkansa**. The latter is especially common for rejecting factual correctness of claims, reports, and rumors.

## 3. ADNOMINAL MODIFICATION
### Pattern
**[Adjective + Noun]** with truth/authenticity/correctness adjective:  
**aito / autenttinen / alkuperäinen / väärä / virheellinen / oikea / paikkansapitävä + N**

### Examples
- **aito nahka** → — → “genuine leather”
- **virheellinen tieto** → — → “erroneous information”

### Notes
Truth-domain meanings are very often expressed attributively inside noun phrases. Different adjectives specialize by domain: **aito** for genuineness, **virheellinen/väärä** for error, **paikkansapitävä** for factual accuracy, **alkuperäinen** for originality.

## 4. BECOME / INCHOATIVE
### Pattern
**tulla todeksi / osoittautua epätodeksi / paljastua väärennökseksi**  
‘become true / turn out false / be revealed as a forgery’

### Examples
- **Uni tuli todeksi.** → — → “The dream came true.”
- **Väite osoittautui epätodeksi.** → — → “The claim turned out to be false.”

### Notes
Change-of-state is commonly expressed with **tulla** or **osoittautua** plus translative **-ksi**. This pattern is productive for outcomes of verification, discovery, or realization.

## 5. CAUSATIVE (OR ABSENCE)
### Pattern
**tehdä jokin uskottavaksi / oikeuttaa jokin / todistaa jokin**  
‘make something believable / justify something / prove something’

### Examples
- **Hän teki tarinan uskottavaksi.** → — → “He/she made the story believable.”
- **Todisteet todistavat väitteen oikeaksi.** → — → “The evidence proves the claim correct.”

### Notes
There is no single general causative verb meaning “make true/authentic” across the whole domain. Finnish instead uses lexical verbs such as **todistaa** ‘prove’, **oikeuttaa** ‘justify’, or a translative result construction with **tehdä**.

## 6. ABSTRACT NOMINALIZATION
### Pattern
**Adjective/verb stem + nominal suffix**: **-uus/-yys, -us**  
e.g. **totuus, todellisuus, aitous, oikeudenmukaisuus, luotettavuus, uskottavuus**

### Examples
- **Totuus tulee ilmi.** → — → “The truth comes out.”
- **Lähteen luotettavuus on tärkeä.** → — → “The reliability of the source is important.”

### Notes
Abstract truth-domain nouns are very commonly formed by derivation, especially with **-uus/-yys** and **-us**. These nouns denote truth, reality, authenticity, fairness, reliability, and credibility as abstract properties.

## 7. AGENTIVE NOMINALIZATION (LIAR, TRUTH-TELLER)
### Pattern
**totuudenetsijä / todistaja**; also periphrastic **puhua totta** for ‘tell the truth’  
(no common expression identified for a basic single-word ‘truth-teller’ in the provided material)

### Examples
- **Hän on totuudenetsijä.** → — → “He/she is a seeker of truth.”
- **Todistaja saapui oikeuteen.** → — → “The witness arrived at court.”

### Notes
Agentive **-ja/-jä** is attested in this semantic area, but mainly in specialized nouns like **todistaja** ‘witness’ and **totuudenetsijä** ‘seeker of truth’. A simple core lexicalized agent noun meaning ‘truth-teller’ is not supported by the provided data; Finnish often uses verbal phrases instead.

## 8. TRUTH-AS-COMPLEMENT CONSTRUCTION
### Pattern
**pitää jokin totena / pitää jotakuta luotettavana**  
‘consider something true / consider someone reliable’

### Examples
- **Monet pitävät väitettä totena.** → — → “Many consider the claim true.”
- **Pidän häntä luotettavana.** → — → “I consider him/her reliable.”

### Notes
Finnish commonly encodes evaluative judgment with **pitää** + object + essive complement (**-na/-nä**). This construction is important for belief, acceptance, and assessment rather than direct assertion.

## 9. CLAUSAL TRUTH-EVALUATION
### Pattern
**On totta, että ... / pitää paikkansa, että ...**  
‘It is true that ... / It holds true that ...’

### Examples
- **On totta, että asia on vaikea.** → — → “It is true that the matter is difficult.”
- **Pitää paikkansa, että päätös viivästyi.** → — → “It is true that the decision was delayed.”

### Notes
Finnish has impersonal clause-taking patterns for evaluating whole propositions. **On totta, että ...** is straightforward and neutral; **pitää paikkansa** is common for factual verification, especially in reporting and argumentation.
