## 1. ATTRIBUTION
### Pattern
**X (adalah) benar / betul / tepat / sesuai / sah / valid / akurat / asli / palsu**
### Examples
- *Informasi itu benar.* → — → “That information is true.”
- *Dokumen ini sah.* → — → “This document is valid.”
### Notes
Indonesian uses bare predicate adjectives/nouns without a copula in ordinary present-tense attribution; *adalah* may appear in formal style. Different predicates specialize by domain: truth (*benar*), validity (*sah, valid*), accuracy (*akurat*), authenticity (*asli/palsu*).

## 2. NEGATIVE ATTRIBUTION
### Pattern
**X tidak + ADJ** / **X kurang + ADJ** / **X belum + ADJ**
### Examples
- *Kabar itu tidak benar.* → — → “That news is not true.”
- *Data ini kurang akurat.* → — → “These data are not very accurate.”
### Notes
Negation is typically with *tidak* before the predicate. Softened negative evaluation often uses *kurang*; procedural or pending validity commonly uses *belum* (e.g. *belum valid*).

## 3. ADNOMINAL MODIFICATION
### Pattern
**N yang + ADJ** / **N + ADJ**
### Examples
- *jawaban yang tepat* → — → “the correct answer”
- *bukti yang sah* → — → “valid/legal evidence”
### Notes
The most productive attributive pattern is **N yang ADJ**. Bare **N + ADJ** also occurs with some lexicalized or formal combinations, especially in validity/authenticity language (e.g. *data valid, dokumen sah*).

## 4. BECOME / INCHOATIVE
### Pattern
**menjadi + ADJ/N** / **terbukti + ADJ**
### Examples
- *Data itu menjadi tidak valid setelah diubah.* → — → “The data became invalid after being changed.”
- *Dokumen itu terbukti palsu.* → — → “The document turned out/proved to be fake.”
### Notes
There is no dedicated inchoative morphology for this domain; change-of-state is usually expressed periphrastically with *menjadi*. Result-discovery is often expressed with *terbukti* for authenticity/truth evaluation.

## 5. CAUSATIVE (OR ABSENCE)
### Pattern
**meN- + root + -kan** causative/confirmative/validative
### Examples
- *Pejabat itu membenarkan kabar tersebut.* → — → “The official confirmed that news.”
- *Pemerintah mengesahkan undang-undang itu.* → — → “The government ratified that law.”
### Notes
Causative-like derivation is well attested, but meanings vary by root: *membenarkan* ‘confirm/justify’, *membetulkan* ‘correct’, *mengesahkan/mengabsahkan* ‘validate/ratify’, *memalsukan* ‘falsify’. Indonesian does not have a single uniform truth-domain causative construction beyond these lexicalized derivatives.

## 6. ABSTRACT NOMINALIZATION
### Pattern
**ke- + ADJ + -an** / borrowed noun formation
### Examples
- *kebenaran* → — → “truth”
- *keaslian dokumen* → — → “the authenticity of the document”
### Notes
Abstract nouns are commonly formed with **ke- -an**: *kebenaran, ketepatan, kesesuaian, keaslian, keabsahan, keakuratan, keandalan, kemiripan, kepatutan*. Borrowed formal nouns also occur, especially *validitas* and *validasi*.

## 8. CONFORMITY / COMPARISON FRAME
### Pattern
**sesuai dengan + N** / **cocok dengan + N** / **mirip dengan + N**
### Examples
- *Pernyataannya sesuai dengan fakta.* → — → “His statement is in accordance with the facts.”
- *Foto itu mirip dengan aslinya.* → — → “The photo resembles the original.”
### Notes
A major structural type in this domain evaluates truth-related fit by explicit comparison to a standard, fact, or model. *Sesuai* is more formal/standard-based, *cocok* more everyday/compatibility-based, and *mirip* marks resemblance rather than full correctness.

## 9. PROPOSITIONAL COMPLEMENT
### Pattern
**benar bahwa ...** / **tidak benar bahwa ...**
### Examples
- *Benar bahwa laporan itu sudah diterima.* → — → “It is true that the report has been received.”
- *Tidak benar bahwa dia memalsukan data.* → — → “It is not true that he falsified the data.”
### Notes
Truth of a full proposition is commonly expressed with **benar bahwa ...** and its negated counterpart. This is especially natural in formal clarification, rebuttal, and reporting.

## 10. EVIDENTIAL / EVALUATIVE PASSIVE
### Pattern
**dianggap / dinyatakan / dipastikan / diduga / terbukti + ADJ**
### Examples
- *Data itu dianggap valid.* → — → “The data is considered valid.”
- *Tanda tangan itu diduga palsu.* → — → “The signature is suspected to be fake.”
### Notes
Indonesian frequently uses passive evaluative verbs before truth-domain predicates to mark institutional judgment, suspicion, confirmation, or proof. This construction is especially common with *valid, sah, asli,* and *palsu*.
