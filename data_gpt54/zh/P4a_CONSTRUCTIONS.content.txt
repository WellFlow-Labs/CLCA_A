## 1. ATTRIBUTION
### Pattern
X + 是 / 很 + 真/假/真实/虚假/正确/错误/准确/可信/可靠/属实/不实
### Examples
- 这是真的。 → zhè shì zhēn de. → This is true.
- 这个消息很可靠。 → zhège xiāoxi hěn kěkào. → This information is reliable.
### Notes
Chinese commonly predicates truth-domain adjectives directly, often with 是 for identificational framing or 很 for ordinary adjectival predication. Formal items like 属实 and 不实 also occur predicatively, especially with reports, content, or situations.

## 2. NEGATIVE ATTRIBUTION
### Pattern
X + 不 + Adj / X + 不属实 / X + 不实 / X + 非 + N/Adj(formal)
### Examples
- 这一说法不太可信。 → zhè yī shuōfǎ bù tài kěxìn. → This claim is not very believable.
- 报道不实。 → bàodào bùshí. → The report is untrue/inaccurate.
### Notes
Negation is usually formed with 不 before the adjective, while lexical negatives such as 不实 and 失实 are especially common in formal rebuttal language. 非- exists in formal registers but is less central in the provided data.

## 3. ADNOMINAL MODIFICATION
### Pattern
Adj + 的 + N / bare compound modifier + N
### Examples
- 虚假的信息 → xūjiǎ de xìnxī → false information
- 名副其实的专家 → míng fù qí shí de zhuānjiā → an expert worthy of the name
### Notes
Adjectival truth terms commonly modify nouns with 的. Some tightly bound compounds appear without 的, especially lexicalized forms such as 真话, 假货, 正品, 虚假信息.

## 4. BECOME / INCHOATIVE
### Pattern
变得 + Adj / 变 + Adj / Adj + 起来
### Examples
- 信息在传递中变得失真。 → xìnxī zài chuándì zhōng biàn de shīzhēn. → The information becomes distorted in transmission.
- 他的说法越来越不可信了。 → tā de shuōfǎ yuèláiyuè bù kěxìn le. → His claim has become less and less believable.
### Notes
Chinese does not rely on a special copular “become” verb for this domain; change-of-state is usually expressed with 变(得), 越来越, or similar aspectual means. These are productive syntactic patterns rather than specialized truth-domain morphology.

## 5. CAUSATIVE (OR ABSENCE)
### Pattern
使 / 让 / 把 + X + 变得 + Adj; also V + 出/成 + result
### Examples
- 这则谣言使事实变得不清楚。 → zhè zé yáoyán shǐ shìshí biàn de bù qīngchu. → This rumor made the facts unclear.
- 压缩过度会让图像失真。 → yāsuō guòdù huì ràng túxiàng shīzhēn. → Excessive compression can make the image distorted.
### Notes
There is no dedicated causative morphology for “make true/false/correct” in Chinese; causation is expressed analytically with 使, 让, or resultative syntax. Some meanings instead prefer lexical verbs such as 伪造 “forge/falsify” or 纠正 “correct.”

## 6. ABSTRACT NOMINALIZATION
### Pattern
Adj + 性 / Adj + 度; lexical abstract nouns also occur
### Examples
- 这份报告的真实性很重要。 → zhè fèn bàogào de zhēnshíxìng hěn zhòngyào. → The authenticity/truthfulness of this report is important.
- 证词的可信度不高。 → zhèngcí de kěxìndù bù gāo. → The testimony’s credibility is not high.
### Notes
Abstract property nouns are very commonly formed with -性 and -度, especially in formal, academic, legal, and technical registers. Chinese also uses lexical nouns like 真相, 事实, 本质, 实质, but the productive structural pattern is suffixal nominalization.

## 7. AGENTIVE NOMINALIZATION (LIAR, TRUTH-TELLER)
### Pattern
(no common expression identified)
### Examples
- 伪造者 → wěizàozhě → forger; falsifier
- 说真话的人 → shuō zhēnhuà de rén → a person who tells the truth
### Notes
Chinese has no single productive everyday agentive pair exactly matching “liar / truth-teller” from the truth-domain adjectives listed here. Agent reference is usually lexical (e.g. 骗子, not in the dataset), with 者 for formal agent nouns, or relative-clause expressions like 说真话的人.

## 8. VERIDICAL REPORTING / SPEECH-ACT MANNER
### Pattern
如实 + V / 说实话 / 说真的
### Examples
- 请如实回答。 → qǐng rúshí huídá. → Please answer truthfully.
- 说实话，我不太相信。 → shuō shíhuà, wǒ bù tài xiāngxìn. → To tell the truth, I don’t quite believe it.
### Notes
Chinese strongly uses adverbial and discourse-marker constructions for truthful speaking rather than only adjectival predication. 如实 is formal and modifies reporting verbs; 说实话 / 说真的 are common discourse-framing expressions.

## 9. VERIFICATION / OFFICIAL FINDING
### Pattern
X + 属实 / 经查属实 / 查证属实 / 是否属实
### Examples
- 举报内容属实。 → jǔbào nèiróng shǔshí. → The reported content has been verified as true.
- 尚未证实是否属实。 → shàngwèi zhèngshí shìfǒu shǔshí. → It has not yet been confirmed whether it is true.
### Notes
This is a highly conventional formal construction set in administrative, legal, and journalistic language. 属实 functions as a specialized predicate of verified factuality, often with investigation verbs.

## 10. FALSEHOOD / FABRICATION EVENT
### Pattern
V + 虚假信息/事实/证件; 伪造 + N; 弄虚作假
### Examples
- 发布虚假信息。 → fābù xūjiǎ xìnxī. → Disseminate false information.
- 伪造证件。 → wěizào zhèngjiàn. → Forge documents.
### Notes
Chinese often expresses falsity as an event or act through lexical verbs rather than by causativizing adjectives. 伪造 and fixed expressions like 弄虚作假 are central for deliberate fabrication or fraud.

## 11. ESSENTIAL / SUBSTANTIVE FRAMING
### Pattern
从本质上看 / 从实质上看 / X + 的本质 / 没有实质区别
### Examples
- 从本质上看，这是同一个问题。 → cóng běnzhì shàng kàn, zhè shì tóng yí gè wèntí. → Essentially, this is the same problem.
- 两者没有实质区别。 → liǎngzhě méiyǒu shízhì qūbié. → There is no substantive difference between the two.
### Notes
Chinese frequently encodes “truth about what something really is” through essence/substance constructions rather than simple true/false predication. 本质 and 实质 are especially common in analytical and formal discourse.
