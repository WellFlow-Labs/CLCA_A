# Language: Korean (ko)

## CONSTRUCTION NATURALNESS & USAGE ANALYSIS

| Construction Type | Example | Transliteration | Translation | Epistemic Status | Usage Notes |
|------------------|---------|-----------------|-------------|------------------|-------------|
| **1. ATTRIBUTION** | 이것은 사실이다 | igeoseun sasirida | This is a fact | [CORE] | Standard copular predication used across all registers. Freely applies to all truth-domain nouns (사실, 진실, 거짓). Adjectival forms (정확하다, 정직하다) are equally common and do not require copula. |
| | 그의 말은 진실이다 | geuui mareun jinsilida | His words are truth | [CORE] | |
| **2. NEGATIVE ATTRIBUTION** | 이것은 사실이 아니다 | igeoseun sasiri anida | This is not a fact | [CORE] | Universal negation pattern for nominal predicates. The -지 않다 pattern for adjectival predicates is equally productive. Both forms used in all contexts without restriction. |
| | 그 말은 정확하지 않다 | geu mareun jeonghwakhaji anta | That statement is not accurate | [CORE] | |
| **3. ADNOMINAL MODIFICATION** | 진실한 사람 | jinsilhan saram | truthful person | [CORE] | Highly productive across all truth-domain terms. Requires -하다 verbalization for Sino-Korean bases before adnominal marking. Used freely in descriptive and evaluative contexts. |
| | 정확한 정보 | jeonghwakhan jeongbo | accurate information | [CORE] | |
| **4. BECOME / INCHOATIVE** | 진실이 되다 | jinsiri doeda | to become truth | [MARGINAL] | 되다 construction exists but is less common than specialized verbs (드러나다, 밝혀지다) for truth emergence. More natural for abstract state changes than propositional truth-value changes. |
| | 거짓말이 들통나다 | geojinmari deultongada | a lie becomes exposed | [CORE] | |
| **5. CAUSATIVE** | (no common expression) | N/A | N/A | [UNCERTAIN] | No productive morphological causatives attested. Periphrastic expressions (진실을 밝히다, -게 하다 constructions) are used instead. Gap in paradigm compared to other semantic domains. |
| **6. ABSTRACT NOMINALIZATION** | 진실성 | jinsilseong | truthfulness | [CORE] | Highly productive with Sino-Korean bases using -성 suffix. Used extensively in formal, academic, and evaluative discourse. Native Korean bases use different nominalizers (-음). |
| | 정확성 | jeonghwakseong | accuracy | [CORE] | |
| **7. AGENTIVE NOMINALIZATION** | 거짓말쟁이 | geojinmaljjaengi | liar | [CORE] | Productive only for negative agent (liar). No parallel positive term (*진실쟁이) exists. Asymmetric pattern—positive agents require periphrastic expression. -쟁이 suffix carries colloquial/pejorative connotation. |
| **8. EVIDENTIAL/EPISTEMIC MARKING** | 사실인 것 같다 | sasirin geot gatda | seems to be a fact | [CORE] | Extremely productive pattern used across all registers. Korean obligatorily marks epistemic stance in many contexts. Multiple alternative constructions (듯하다, 나 보다) with subtle differences in evidential source. |
| | 거짓말인 것 같다 | geojinmarin geot gatda | seems to be a lie | [CORE] | |
| **9. DISCOURSE MARKERS** | 사실은 | sasireun | actually, in fact | [CORE] | Fully grammaticalized as discourse markers beyond compositional meaning. Used in all spoken and written registers for topic shift, correction, or revelation. High frequency in conversational discourse. |
| | 솔직히 말하면 | soljiki malhamyeon | frankly speaking | [CORE] | |
| **10. VERIFICATION CONSTRUCTIONS** | 진실을 밝히다 | jinsireul balkhida | to reveal the truth | [CORE] | Rich and productive pattern with multiple specialized verbs. Used across investigative, journalistic, legal, and everyday contexts. Both transitive (밝히다, 확인하다) and intransitive (드러나다) forms common. |
| | 사실을 확인하다 | sasireul hwaginhada | to verify the facts | [CORE] | |
| **11. AUTHENTICATION CONSTRUCTIONS** | 진짜인지 가짜인지 | jinjjainji gajjainji | whether real or fake | [CORE] | Standard construction for authenticity questions about objects, documents, products. Less commonly applied to propositional truth (which uses different constructions). Domain-specific to material authenticity. |
| | 진본인지 모조품인지 | jinboninji mojopuminji | whether authentic or counterfeit | [CORE] | |
| **12. CORRECTNESS EVALUATION** | 맞는 답 | manneun dap | correct answer | [CORE] | Domain-specific to educational, testing, and evaluative contexts. Binary opposition (맞다/틀리다) is fundamental to Korean correctness assessment. Distinct from moral evaluation (옳다/그르다). |
| | 틀린 답 | teullin dap | wrong answer | [CORE] | |
| **13. INTENSIFICATION PATTERNS** | 새빨간 거짓말 | saeppalgan geojinmal | blatant lie | [MARGINAL] | Limited and asymmetric pattern. Color intensifiers apply primarily to 거짓말 (lies). 새빨간 is idiomatic for obviousness/brazenness. 하얀 거짓말 is calque from English. No parallel intensification for truth terms. |
| | 하얀 거짓말 | hayan geojinmal | white lie | [MARGINAL] | |
| **14. LEGITIMACY ASSESSMENT** | 정당한 이유 | jeongdanghan iyu | legitimate reason | [CORE] | Specialized to formal registers: legal, political, argumentative discourse. Strong collocational preferences (정당한 권리, 타당한 근거). Abstract nominalizations (정당성, 타당성) frequently appear in academic/formal writing. |
| | 타당한 근거 | tadanghan geungeo | valid grounds | [CORE] | |
| **15. CREDIBILITY CONSTRUCTIONS** | 신빙성이 있다 | sinbingseongi itda | to be credible | [CORE] | Fixed construction with limited verb paradigm (있다/없다, 높다/낮다, 떨어지다/높이다). Used in evaluative contexts before verification. Common in news media, academic, and investigative discourse. |
| | 신빙성이 떨어지다 | sinbingseongi tteoreojida | to lose credibility | [CORE] | |

## ATTESTED ALTERNATE CONSTRUCTIONS

### Construction 2 (Negative Attribution)
- **Alternate**: 틀리다 (teullida) "to be wrong" / 거짓이다 (geojisida) "to be false"
- **Usage**: Direct negative predicates without 아니다 negation; 틀리다 more common in correctness contexts

### Construction 4 (Become/Inchoative)
- **Alternate**: 드러나다 (deureonada) "to be revealed" / 밝혀지다 (balkhyeojida) "to be brought to light"
- **Usage**: Preferred over 되다 for truth emergence; implies discovery or revelation process

### Construction 5 (Causative)
- **Alternate**: 진실을 밝히다 (jinsireul balkhida) "to reveal truth" / -게 하다 auxiliary construction
- **Usage**: Periphrastic causation only; no morphological causatives attested

### Construction 7 (Agentive Nominalization)
- **Alternate**: 진실을 말하는 사람 (jinsireul malhaneun saram) "person who speaks truth"
- **Usage**: Periphrastic expression required for positive agent; no productive suffix available

### Construction 8 (Evidential/Epistemic)
- **Alternate**: -(으)ㄴ/는 듯하다 (deuthada) "seems" / -나 보다 (na boda) "appears" / 틀림없다 (teullimeopda) "without doubt"
- **Usage**: Multiple evidential markers with subtle differences in certainty level and information source

### Construction 13 (Intensification)
- **Alternate**: 진짜배기 (jinjjabaegi) "the real deal"
- **Usage**: Intensifier suffix -배기 for authenticity; colloquial register

## SUMMARY OBSERVATIONS

**CORE constructions (11/15)**: Attribution, Negative Attribution, Adnominal Modification, Abstract Nominalization, Agentive Nominalization (negative only), Evidential/Epistemic Marking, Discourse Markers, Verification Constructions, Authentication Constructions, Correctness Evaluation, Legitimacy Assessment, Credibility Constructions

**MARGINAL constructions (2/15)**: Become/Inchoative (specialized verbs preferred), Intensification Patterns (limited scope, asymmetric)

**UNCERTAIN constructions (1/15)**: Causative (no productive morphological pattern attested)

**Notable asymmetries**: 
- Agentive nominalization productive only for negative agents (거짓말쟁이)
- Intensification patterns apply primarily to negative terms (거짓말)
- Causative constructions require periphrasis

**Register variation**: Legitimacy Assessment and Credibility Constructions show strong preference for formal registers; Intensification Patterns skew colloquial
