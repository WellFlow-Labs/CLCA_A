# CLCA Protocol v3.4 — P2a Derivational System
# Language: Hebrew (he)

## DERIVATIONAL PATTERNS IDENTIFIED

### Pattern Analysis Note
Hebrew derivational morphology operates primarily through:
1. **Root-and-pattern system** (binyanim) - consonantal roots combined with vocalic patterns
2. **Affixation** - prefixes, suffixes, and circumfixes
3. **Compounding** - combination of existing lexemes

The following documentation reports only attested forms from P1 and P1b data.

## DERIVATIONS BY BASE FORM

### Base: אמת (emet) "truth"

#### Derived Form 1
- **Base Form:** אמת (emet)
- **Derived Form:** אמיתי (amiti)
- **Transliteration:** amiti
- **Literal Breakdown:** emet + adjectival suffix -i
- **Translation:** true, genuine, real, authentic
- **Usage:** Adjectival derivation converting the noun "truth" into an adjective describing genuineness or authenticity. Highly productive pattern for creating adjectives from abstract nouns.
- **Status:** [CORE]

#### Derived Form 2
- **Base Form:** אמת (emet)
- **Derived Form:** אמיתות (amitiyut)
- **Transliteration:** amitiyut
- **Literal Breakdown:** amiti + abstract noun suffix -ut
- **Translation:** authenticity, genuineness, truthfulness
- **Usage:** Abstract noun derived from the adjective amiti, denoting the quality or state of being genuine. Standard pattern for creating abstract nouns from adjectives.
- **Status:** [CORE]

#### Derived Form 3
- **Base Form:** אמת (emet)
- **Derived Form:** באמת (be'emet)
- **Transliteration:** be'emet
- **Literal Breakdown:** preposition be- "in/with" + emet
- **Translation:** truly, really, indeed, in truth
- **Usage:** Prepositional phrase functioning as adverb or discourse marker. Highly frequent in spoken and written Hebrew.
- **Status:** [CORE]

#### Derived Form 4
- **Base Form:** אמת (emet)
- **Derived Form:** אמת מידה (amat mida)
- **Transliteration:** amat mida
- **Literal Breakdown:** emet (in construct state) + mida "measure"
- **Translation:** criterion, standard, yardstick
- **Usage:** Fixed compound using construct state (smixut) to create a metaphorical expression for evaluative standards. The construct form "amat" is the bound form of "emet."
- **Status:** [CORE]

#### Derived Form 5
- **Base Form:** אמת (emet)
- **Derived Form:** אמת לאמיתה (emet la'amita)
- **Transliteration:** emet la'amita
- **Literal Breakdown:** emet + preposition le- "to" + amita (emet with possessive suffix -a "its")
- **Translation:** the absolute truth, the real truth
- **Usage:** Emphatic construction using prepositional phrase with possessive suffix to intensify meaning. Common in colloquial Hebrew.
- **Status:** [CORE]

#### Derived Form 6
- **Base Form:** אמת (emet)
- **Derived Form:** אמת מוחלטת (emet muḥletet)
- **Transliteration:** emet muḥletet
- **Literal Breakdown:** emet + muḥletet "absolute" (adjective)
- **Translation:** absolute truth
- **Usage:** Adjectival modification creating a philosophical/technical term. Standard pattern for creating compound concepts.
- **Status:** [CORE]

#### Derived Form 7
- **Base Form:** אמת (emet)
- **Derived Form:** אמת היסטורית (emet historit)
- **Transliteration:** emet historit
- **Literal Breakdown:** emet + historit "historical" (adjective)
- **Translation:** historical truth
- **Usage:** Adjectival modification creating domain-specific term. Pattern used for various types of truth (scientific, subjective, etc.).
- **Status:** [CORE]

**Base noun:** אמונה (emuna) "faith, belief, trust"
- → מאמין (ma'amin) "believer" [active participle from causative verb]

## CROSS-ROOT DERIVATIONAL OBSERVATIONS

### Productive Affixal Patterns Identified

1. **Adjectival suffix -i (-י):**
   - אמת → אמיתי (emet → amiti)
   - שקר → שקרי (sheker → shikri)
   - Pattern: Noun → Adjective
   - Productivity: High across Hebrew lexicon

2. **Abstract noun suffix -ut (-ות):**
   - אמיתי → אמיתות (amiti → amitiyut)
   - אמין → אמינות (amin → aminut)
   - נאמן → נאמנות (ne'eman → ne'emanut)
   - מהימן → מהימנות (meheyman → meheymanut)
   - שקרן → שקרנות (shakran → shakranut)
   - Pattern: Adjective → Abstract Noun
   - Productivity: Very high, standard pattern

3. **Agent noun suffix -an (-ן):**
   - שקר → שקרן (sheker → shakran)
   - Pattern: Noun/Verb → Agent Noun (habitual/professional)
   - Productivity: Moderate, typically indicates habitual characteristic

4. **Prepositional phrase formation with be- (ב-):**
   - אמת → באמת (emet → be'emet)
   - אמונה → באמונה (emuna → be'emuna)
   - צדק → בצדק (tsedek → betsedek)
   - Pattern: Noun → Adverbial Expression
   - Productivity: High, productive syntactic pattern

### Binyan-Based Derivational Patterns

The data shows systematic use of Hebrew verbal binyanim (conjugation patterns) for derivation:

1. **Hif'il (causative) pattern:**
   - Root א-מ-נ → להאמין (leha'amin) "to cause to be firm → to believe"
   - Root צ-ד-ק → להצדיק (lehatsдik) "to cause to be right → to justify"

2. **Nif'al (passive/reflexive) pattern:**
   - Root כ-ו-נ → נכון (nakhon) "established, correct"
   - Root א-מ-נ → נאמן (ne'eman) "made faithful → faithful, reliable"

3. **Pi'el (intensive) pattern:**
   - Root ש-ק-ר → לשקר (leshaker) "to lie intensively → to lie"

4. **Pu'al/Huf'al (passive) patterns:**
   - Root ד-י-ק → מדויק (meduyak) "made precise → precise"
   - Root צ-ד-ק → מוצדק (mutsдak) "made just → justified"
   - Root ז-י-ף → מזויף (mezuyaf) "made false → forged"

### Compound Formation Patterns

1. **Construct state (smixut) compounds:**
   - אמת מידה (amat mida) "measuring rod of truth → criterion"
   - צדקת הדין (tsidkat hadin) "righteousness of judgment"
   - אמונת חכמים (emunat ḥakhamim) "faith of sages"

2. **Attributive adjective compounds:**
   - Domain specification: אמת מדעית (emet mada'it) "scientific truth"
   - Type specification: שקר לבן (sheker lavan) "white lie"
   - Intensification: שקר גמור (sheker gamur) "complete lie"

### Asymmetries and Gaps Noted

1. **Uneven derivational productivity:**
   - Root א-מ-נ shows extensive derivation across multiple semantic domains
   - Root ש-ק-ר shows moderate derivation, primarily within falsity domain
   - Root צ-ד-ק shows derivation split between justice and correctness senses

2. **Participial forms with limited further derivation:**
   - Forms like נכון (nakhon), מדויק (meduyak), ברור (barur) function primarily as adjectives without productive further derivation in attested data

3. **Loanwords with limited morphological integration:**
   - אותנטי (otenti) "authentic" shows minimal derivational productivity compared to native forms

4. **Biblical/literary forms with reduced modern productivity:**
   - כזב (kazav), שווא (shav) marked as [MARGINAL] with no attested modern derivations
