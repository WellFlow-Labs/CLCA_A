## 1. ATTRIBUTION
### Pattern
**[Clause/NP] + ni / jẹ́ òtítọ́**; also **ó tọ́ / ó dájú** for “it is right/certain”
### Examples
- **Òtítọ́ ni.** → *òtítọ́ ni* → “It is true.”
- **Ó jẹ́ òtítọ́.** → *ó jẹ́ òtítọ́* → “It is true.”
### Notes
Yoruba commonly attributes truth with a nominal predicate (*òtítọ́ ni*) or a verbal predicate (*jẹ́ òtítọ́*). Related evaluative attribution also uses *tọ́* “be right/correct” and *dájú* “be certain.”

## 2. NEGATIVE ATTRIBUTION
### Pattern
**kì í ṣe òtítọ́** / **irọ́ ni** / **kò tọ́**
### Examples
- **Kì í ṣe òtítọ́.** → *kì í ṣe òtítọ́* → “It is not true.”
- **Irọ́ ni.** → *irọ́ ni* → “It is a lie / It is false.”
### Notes
Negative truth evaluation is commonly expressed either by denying truth (*kì í ṣe òtítọ́*) or by directly labeling something false (*irọ́ ni*). *Kò tọ́* is broader and can mean “it is wrong / not correct.”

## 3. ADNOMINAL MODIFICATION
### Pattern
**N + títọ́ / òdodo / ojúlówó / ẹlẹ́rìí + modifier**
### Examples
- **Ọ̀nà títọ́** → *ọ̀nà títọ́* → “straight path / right way”
- **Ẹlẹ́rìí ojú** → *ẹlẹ́rìí ojú* → “eyewitness”
### Notes
Truth-domain meanings appear adnominally through noun–modifier combinations. These often extend from truth to correctness, moral rightness, authenticity, or evidential status.

## 5. CAUSATIVE (OR ABSENCE)
### Pattern
**fi òtítọ́ hàn / fi ẹ̀rí hàn / rí i dájú**
### Examples
- **Fi òtítọ́ hàn.** → *fi òtítọ́ hàn* → “Show / reveal the truth.”
- **Fi ẹ̀rí hàn.** → *fi ẹ̀rí hàn* → “Present evidence / show proof.”
### Notes
No dedicated morphological causative is established here, but Yoruba uses analytic verb constructions to cause truth or evidence to become manifest. *Rí i dájú* similarly means “make sure / ascertain.”

## 6. ABSTRACT NOMINALIZATION
### Pattern
**Nominalized lexical forms:** **òtítọ́, òtọ́, títọ́, ẹ̀rí, òdodo**
### Examples
- **Òtítọ́ ṣe pàtàkì.** → *òtítọ́ ṣe pàtàkì* → “Truth is important.”
- **Òdodo ṣe pàtàkì.** → *òdodo ṣe pàtàkì* → “Justice/righteousness is important.”
### Notes
Abstract truth-domain meanings are commonly expressed by lexical nominalizations rather than productive on-the-fly morphology in the supplied data. These nouns cover truth, correctness, evidence, and righteousness.

## 8. TRUTH AS OBJECT OF SPEECH/KNOWLEDGE
### Pattern
**V + òtítọ́** (e.g. say/know/love truth)
### Examples
- **Sọ òtítọ́.** → *sọ òtítọ́* → “Tell the truth.”
- **Mọ̀ òtítọ́.** → *mọ̀ òtítọ́* → “Know the truth.”
### Notes
A strong constructional pattern treats *òtítọ́* as the object of verbs of speech, knowledge, and valuation. This is one of the clearest productive truth-domain frames in the data.

## 9. EVIDENTIAL POSSESSION / ABSENCE
### Pattern
**ní ẹ̀rí / kò sí ẹ̀rí**
### Examples
- **Mo ní ẹ̀rí.** → *mo ní ẹ̀rí* → “I have evidence.”
- **Kò sí ẹ̀rí.** → *kò sí ẹ̀rí* → “There is no evidence.”
### Notes
Evidence is structurally framed through possession and existential negation. This pattern is central for evaluating whether a claim is supported.

## 10. ADVERBIAL TRUTH MARKING
### Pattern
**ní òtítọ́ / l’òtítọ́**
### Examples
- **Ní òtítọ́, mo mọ̀ ọ.** → *ní òtítọ́, mo mọ̀ ọ* → “In truth / actually, I know him/her.”
- **L’òtítọ́, ó tọ́.** → *l’òtítọ́, ó tọ́* → “Truly / in fact, it is right.”
### Notes
These are adverbial discourse-marking constructions meaning “truly, in fact.” They do not attribute truth to a noun directly, but frame the whole proposition as candid or factual.
