# CLCA Protocol v3.4 — P4b Construction Usage & Constraints
# Language: Tamil (ta)

---

| Construction Type | Example | Transliteration | Translation | Epistemic Status | Usage Notes |
|------------------|---------|-----------------|-------------|------------------|-------------|
| **1. ATTRIBUTION** | இது உண்மை | itu uṇmai | "this is truth/true" | [CORE] | Extremely common in everyday speech and writing. Zero copula is unmarked default for present tense statements. Emphatic particle தான் (tāṉ) frequently added for assertion. |
| | அவன் பொய்யன் | avaṉ poyaṉ | "he is a liar" | [CORE] | Standard pattern for character attribution. Past/future require explicit copula forms (இருந்தது, இருக்கும்). |
| **2. NEGATIVE ATTRIBUTION** | இது உண்மையில்லை | itu uṇmaiillai | "this is not true" | [CORE] | Primary negation strategy. இல்லை (illai) dominates in colloquial speech; அல்ல (alla) in formal/written contexts. |
| | அது பொய்யல்ல | atu poyyalla | "that is not false" | [CORE] | அன்று (aṉṟu) variant restricted to literary/classical registers. Register choice is socially significant. |
| **3. ADNOMINAL MODIFICATION** | உண்மையான கதை | uṇmaiyāṉa katai | "true story" | [CORE] | Highly productive attributive pattern. The -ஆன (-āṉa) suffix is the standard adjectivizer for truth-terms modifying nouns. |
| | பொய்யான சாட்சி | poyyāṉa cāṭci | "false testimony" | [CORE] | Equally productive with negative truth-terms. Genitive alternative (உண்மையின்) used for possessive/partitive relations, not simple attribution. |
| **4. BECOME / INCHOATIVE** | உண்மை ஆகிவிட்டது | uṇmai ākiviṭṭatu | "it became true / turned out to be true" | [CORE] | Common in narrative contexts describing revelation or status change. Completive auxiliaries விடு/போ typically required for natural expression. |
| | பொய் ஆகிப்போனது | poy ākipōṉatu | "it became false / turned out to be a lie" | [CORE] | Used when prior belief is overturned or deception revealed. போ (pō) emphasizes unexpected change. |
| **5. CAUSATIVE** | உண்மைப்படுத்து | uṉmaippaṭuttu | "verify, authenticate, make true" | [CORE] | Standard term for verification/authentication in formal and technical contexts. Highly frequent in administrative and legal registers. |
| | மெய்ப்படுத்து | meyppaṭuttu | "prove, verify" | [CORE] | Slightly more formal/literary than உண்மைப்படுத்து. Common in academic and philosophical discourse. |
| | பொய்யாக்கு | poyyākku | "make false" | [MARGINAL] | Less common than positive causatives. Uses different causative morphology (-ஆக்கு rather than -படுத்து). No standard *பொய்ப்படுத்து form attested. |
| **6. ABSTRACT NOMINALIZATION** | உண்மைத்தன்மை | uṇmaittaṉmai | "truthfulness, the quality of being true" | [CORE] | Common in formal/philosophical discourse. தன்மை (taṉmai) "quality" compounds with already-abstract உண்மை for meta-level abstraction. |
| | மெய்ம்மை | meymai | "truth, reality, genuineness" | [CORE] | Literary/philosophical register. More abstract and philosophical than உண்மை. |
| | பொய்ம்மை | poymai | (abstract falsehood) | [MARGINAL] | Rare and archaic. பொய் itself functions as abstract noun without further derivation in modern usage. |
| **7. AGENTIVE NOMINALIZATION** | உண்மையாளர் | uṇmaiyāḷar | "truthful person" (honorific) | [CORE] | Honorific/plural form common in formal contexts. Suffix choice (-ஆன்/-ஆளி/-ஆளர்) marks gender and social register. |
| | பொய்யன் | poyaṉ | "liar" (masculine) | [CORE] | Very common pejorative. Masculine -அன் suffix standard. Negative agent terms more elaborated than positive equivalents. |
| **8. VERBAL COLLOCATIONS — SPEAKING/TELLING** | உண்மை சொல்லு | uṇmai collu | "tell the truth" | [CORE] | Extremely frequent collocation, primary expression for truth-telling. சொல்லு (collu) is unmarked default speech verb. |
| | பொய் பேசு | poy pēcu | "speak lies" | [CORE] | Standard expression for lying. பேசு (pēcu) slightly more formal than சொல்லு. Object case-marking optional in colloquial speech. |
| **9. VERBAL COLLOCATIONS — REVELATION/EMERGENCE** | உண்மை வெளிப்படு | uṇmai veḷippaṭu | "truth comes out, is revealed" | [CORE] | Very common in narrative contexts. Implies prior concealment or hiddenness. வெளிப்படு is core emergence verb. |
| | பொய் வெளிப்படு | poy veḷippaṭu | "lie is exposed" | [CORE] | Equally common with negative truth-terms. Emphasizes unmasking of deception. |
| | தெரிய வரு | teriya varu | "come to be known" | [CORE] | Alternative emphasizing gradual discovery process rather than sudden revelation. |
| **10. VERBAL COLLOCATIONS — CONCEALMENT** | உண்மையை மறை | uṇmaiyai maṟai | "hide the truth" | [CORE] | Common in contexts of deliberate deception. Accusative marking (-ஐ) obligatory in standard usage. |
| | உண்மையை மூடி மறை | uṇmaiyai mūṭi maṟai | "cover up and hide the truth" | [CORE] | Emphatic form adding மூடி "covering" for intensification. Used for serious cover-ups or conspiracies. |
| **11. VERBAL COLLOCATIONS — ACCEPTANCE/ACKNOWLEDGMENT** | உண்மையை ஒப்புக்கொள் | uṇmaiyai oppukkoḷ | "admit the truth" | [CORE] | Very common, especially in contexts of confession or acknowledgment. Reflexive -கொள் marks self-benefactive. |
| | தப்பை ஒப்புக்கொள் | tappai oppukkoḷ | "admit the mistake" | [CORE] | Equally frequent with error terms. Standard expression for taking responsibility. |
| | ஏற்று | ēṟṟu | "accept" | [CORE] | Alternative verb for accepting difficult or painful truths. Less emphasis on verbal admission. |
| **12. VERBAL COLLOCATIONS — REALIZATION/PERCEPTION** | உண்மையை உணர் | uṇmaiyai uṇar | "realize the truth" | [CORE] | Common in narrative and philosophical contexts. உணர் emphasizes perceptual/intuitive realization. |
| | மெய்யை அறி | meyyai aṟi | "know the truth/reality" | [CORE] | More common in philosophical/spiritual registers. அறி emphasizes cognitive knowledge. மெய்-based forms preferred in classical contexts. |
| **13. VERBAL COLLOCATIONS — VERIFICATION/PROOF** | உண்மையை காட்டு | uṇmaiyai kāṭṭu | "show the truth" | [CORE] | General demonstration verb. Common in argumentative and evidential contexts. |
| | உண்மையை நிரூபி | uṇmaiyai nirūpi | "prove the truth" | [CORE] | Formal/academic register. நிரூபி (< Sanskrit) used in scientific and legal proof contexts. |
| | மெய்ப்பிக்க | meypikka | "to verify" | [CORE] | Dedicated verification verb. Common in administrative and technical contexts requiring authentication. |
| **14. VERBAL COLLOCATIONS — CORRECTION/FIXING** | சரி செய் | cari cey | "fix, correct, repair" | [CORE] | Extremely productive and frequent. Used for both physical repairs and error correction. செய் is light verb. |
| | தப்பை சரி செய் | tappai cari cey | "correct the mistake" | [CORE] | Standard expression for error correction. Completive விடு often added for emphasis on completion. |
| **15. PREDICATIVE INTERROGATIVES** | இது உண்மையா | itu uṇmaiyā | "is this true?" | [CORE] | Standard yes/no question formation. -ஆ (-ā) is unmarked question particle in colloquial speech. |
| | அது சரியா | atu cariyā | "is that correct?" | [CORE] | Equally common. Intonation alone can mark questions in very colloquial contexts. |
| | உண்மையோ | uṇmaiyō | "is it really true?" | [CORE] | -ஓ (-ō) variant for rhetorical or skeptical questions. Implies doubt or surprise. |
| **16. EMPHATIC CONSTRUCTIONS** | இது உண்மைதான் | itu uṇmaitāṉ | "this really is true" | [CORE] | Extremely frequent in spoken Tamil. தான் (tāṉ) adds emphasis and certainty to assertions. |
| | அது பொய்தான் | atu poytāṉ | "that really is false" | [CORE] | Equally productive with negative terms. Can combine with other particles for nuanced emphasis. |
| | உண்மைதானே | uṉmaitāṉē | "it's true, isn't it?" | [CORE] | Confirmation-seeking variant. -ஏ (-ē) adds tag-question force. |
| **17. COMPARATIVE CONSTRUCTIONS** | உண்மையை விட | uṇmaiyai viṭa | "more than the truth, beyond the truth" | [MARGINAL] | Not highly productive with truth-terms. Used in hyperbolic or emphatic comparisons. |
| | பொய்யை விட | poyyai viṭa | "worse than a lie" | [MARGINAL] | Attested in moral evaluations but not frequent. விட comparative more common with gradable adjectives. |
| **18. COMPOUND FORMATIONS — STATE/CONDITION** | உண்மை நிலை | uṇmai nilai | "true state of affairs, actual situation" | [CORE] | Common in formal and journalistic registers. நிலை "state" is productive compounding element. |
| | பொய் நிலை | poy nilai | "false state, deceptive condition" | [CORE] | Equally productive. நிலவரம் (nilavaram) "situation" is formal alternative. |
| **19. COMPOUND FORMATIONS — KNOWLEDGE/AWARENESS** | மெய் அறிவு | mey aṟivu | "true knowledge" | [CORE] | Common in philosophical and educational contexts. மெய்-based forms preferred over உண்மை-based in this domain. |
| | மெய் ஞானம் | mey ñāṉam | "true wisdom, spiritual knowledge" | [CORE] | Spiritual/religious register. ஞானம் (< Sanskrit) marks elevated philosophical discourse. |
| **20. COMPOUND FORMATIONS — INFORMATION/NARRATIVE** | உண்மைத் தகவல் | uṇmait takaval | "true information" | [CORE] | Very common in media and information contexts. Highly productive pattern for distinguishing true/false information. |
| | பொய்க் கதை | poyk katai | "false story, lie" | [CORE] | Frequent in everyday speech. கதை "story" compounds productively with truth-terms. |
| **21. COMPOUND FORMATIONS — LEGAL/DOCUMENTARY** | பொய் சாட்சி | poy cāṭci | "false testimony, perjury" | [CORE] | Standard legal term. Highly productive pattern for fraud/forgery terminology in legal register. |
| | பொய் சான்று | poy cāṉṟu | "false certificate, forged document" | [CORE] | Common in administrative and legal contexts. Includes extensive fraud terminology (பொய் ஆவணம், பொய் கையெழுத்து, etc.). |
| **22. COMPOUND FORMATIONS — COMMERCIAL FRAUD** | பொய் சாமான் | poy cāmāṉ | "fake goods, counterfeit merchandise" | [CORE] | Common in commercial and consumer contexts. Productive pattern for counterfeit terminology. |
| | பொய் நாணயம் | poy nāṇayam | "counterfeit currency" | [CORE] | Standard term. Contrasts with அசல் "genuine" and நகல் "copy/imitation" in commercial discourse. |
| **23. IDIOMATIC/PROVERBIAL EXPRESSIONS** | பொய்க்கு கால் இல்லை | poykku kāl illai | "lies have no legs" (lies don't last) | [CORE] | Well-known proverb. Cultural wisdom about impermanence of falsehood. |
| | உண்மை கசக்கும் | uṇmai kaṟakkum | "truth is bitter" | [CORE] | Common proverb about unpleasant truths. கசக்கும் "is bitter/harsh" is fixed collocation. |
| | பொய் சொன்னால் கொம்பு முளைக்கும் | poy coṉṉāl kompu muḷaikkum | "if you lie, horns will sprout" | [CORE] | Traditional warning to children. Part of moral instruction repertoire. |
| **24. DISCOURSE MARKERS — TRUTH-FRAMING** | உண்மையில் சொல்லப்போனால் | uṇmaiyil collapōṉāl | "to tell the truth, actually" | [CORE] | Very common discourse marker introducing candid or corrective statements. Frequent in conversational Tamil. |
| | உண்மையைச் சொல்ல வேண்டும் என்றால் | uṇmaiyaic colla vēṇṭum eṉṟāl | "if I must speak truthfully" | [CORE] | Formal variant for hedging or introducing difficult truths. More elaborate than simple உண்மையில். |
| | உண்மையில் | uṇmaiyil | "actually, in truth" | [CORE] | Functions independently as adverb. Extremely frequent for corrections or clarifications. |
| **25. ADVERBIAL MANNER CONSTRUCTIONS** | உண்மையாக | uṇmaiyāka | "truly, truthfully" | [CORE] | Productive manner adverb formation. -ஆக (-āka) is standard adverbializer. |
| | பொய்யாக | poyyāka | "falsely, untruthfully" | [CORE] | Equally productive. Emphatic -வே (-vē) variant (உண்மையாகவே) common for intensification. |
| | மெய்யாக | meyyāka | "truly, genuinely" | [CORE] | More literary/formal than உண்மையாக. Preferred in classical and philosophical registers. |
| **26. QUOTATIVE CONSTRUCTIONS** | உண்மையென | uṇmaiyeṉa | "as truth, saying it is true" | [CORE] | Quotative என (eṉa) marks characterization. More formal than simple predication. |
| | பொய்யென | poyyeṉa | "as false, calling it a lie" | [CORE] | Used to introduce or characterize statements. மெய்யென variant common in literary register. |
| **27. POSSESSIVE/GENITIVE CONSTRUCTIONS** | உண்மையின் வலிமை | uṇmaiyiṉ valimai | "the power of truth" | [CORE] | Common in abstract philosophical and moral discourse. Genitive -இன் marks possessive relationship. |
| | பொய்யின் விளைவு | poyyiṉ viḷaivu | "the consequence of lies" | [CORE] | Productive with abstract nouns: வலிமை "strength," முக்கியத்துவம் "importance," இயல்பு "nature," விளைவு "consequence." |
| **28. LIGHT VERB CONSTRUCTIONS — CHECKING/INSPECTION** | சரி பார் | cari pār | "check, verify, inspect" | [CORE] | Extremely common construction for verification activities. பார் "see" is light verb. |
| | சரி பார்த்துக்கொள் | cari pārttukkoḷ | "check for oneself" | [CORE] | Reflexive -கொள் adds benefactive meaning. Very frequent in instructional and procedural contexts. |
| **29. COMPLETIVE CONSTRUCTIONS** | உண்மை வெளிப்பட்டுவிட்டது | uṇmai veḷippaṭṭuviṭṭatu | "the truth has come out (completely)" | [CORE] | Very common in past tense narratives. விடு emphasizes completion/finality of revelation. |
| | தப்பு செய்துவிட்டேன் | tappu ceytuviṭṭēṉ | "I made a mistake (and it's done)" | [CORE] | போ variant emphasizes change of state. Completive auxiliaries nearly obligatory in natural narrative past. |
| **30. NEGATIVE IMPERATIVE/PROHIBITIVE** | பொய் சொல்லாதே | poy collātē | "don't tell lies" (singular informal) | [CORE] | Very common in moral instruction, especially to children. -ஆதே is standard negative imperative. |
| | உண்மையை மறைக்காதீர்கள் | uṇmaiyai maṟaikkātīrkaḷ | "don't hide the truth" (plural/formal) | [CORE] | -ஆதீர்கள் marks plural/formal address. Positive imperative uses bare stem or -உ suffix. |

## SUMMARY OBSERVATIONS

### High-Frequency Core Patterns
1. **Attribution with zero copula** (constructions 1-2): Unmarked default for present tense
2. **Adnominal -ஆன modification** (construction 3): Primary attributive strategy
3. **Speech verb collocations** (construction 8): Primary expressions for truth-telling/lying
4. **Emphatic தான் particle** (construction 16): Extremely frequent in spoken Tamil
5. **Light verb constructions** (constructions 14, 28): Highly productive with செய் and பார்

### Register Variation
- **Colloquial**: இல்லை negation, சொல்லு speech verb, -ஆ question particle
- **Formal/Literary**: அல்ல negation, மெய்-based compounds, ஞானம் wisdom terms
- **Legal/Administrative**: பொய் compounds for fraud terminology, நிரூபி for proof

### Asymmetries
- **Negative elaboration**: பொய் compounds far more elaborated in legal/commercial fraud domains than positive உண்மை equivalents
- **Causative morphology**: உண்மை/மெய் use -படுத்து; பொய் uses -ஆக்கு
- **Abstract nominalization**: Less productive with பொய் than உண்மை/மெய்

### Marginal Patterns
- **Comparative constructions** (construction 17): Attested but not productive with truth-terms
- **பொய்ம்மை abstract** (construction 6): Rare and archaic
