## 1. BECOMING CREDIBLE / TRUSTWORTHY
### Pattern
**NP + kuaminika / -na-aminika**; negative **NP + kutoaminika / ha-aminiki**

### Examples
- **Taarifa hii inaaminika.** → *Taarifa hii inaaminika.* → “This report is credible / has become acceptable as credible.”
- **Chanzo hicho hakiaminiki.** → *Chanzo hicho hakiaminiki.* → “That source is not credible.”

### Notes
Within the supplied vocabulary, **kuaminika / aminika** is the clearest dynamic or state-change-compatible form for entering or holding a credibility state. It works naturally with reports, sources, evidence, institutions, and persons.  
A fully explicit “become credible” paraphrase can be expressed only loosely with available material; no separate common lexical item meaning specifically “become true/credible” beyond **kuaminika** is provided in the context.

---

## 2. BECOMING NON-CREDIBLE / LOSING CREDIBILITY
### Pattern
**NP + kutoaminika**; finite negative **NP + ha-aminiki**; relative **asiyeaminika**

### Examples
- **Kutoaminika kwa chanzo hicho ni dhahiri.** → *Kutoaminika kwa chanzo hicho ni dhahiri.* → “The lack of credibility of that source is evident.”
- **Mtu huyo haaminiki.** → *Mtu huyo haaminiki.* → “That person is not trustworthy / not credible.”

### Notes
The context supports **kutoaminika**, **asiyeaminika**, and negative finite forms like **hakiaminiki**. These encode the opposed state to credibility.  
However, a dedicated common expression meaning specifically “become untrustworthy” is **not explicitly provided** in the context; what is clearly supported is the resulting non-credible state.

---

## 3. CAUSING CONFIDENCE / MAKING SOMETHING SEEM TRUSTWORTHY
### Pattern
**Y + kutia imani**; finite **Y + -na-tia imani**

### Examples
- **Hotuba yake ilitia imani.** → *Hotuba yake ilitia imani.* → “His speech inspired confidence.”
- **Kiongozi huyo anatia imani.** → *Kiongozi huyo anatia imani.* → “That leader inspires confidence.”

### Notes
This is the clearest causative-like expression in the supplied material. It does **not** literally mean “make true” or “make correct”; rather, it means causing confidence or trust.  
So for causation in the truth-related domain, Swahili here is best represented by a **periphrastic confidence-causing construction**, not by a dedicated causative verb for truth or correctness.

---

## 4. TELLING THE TRUTH AS A DYNAMIC ACT
### Pattern
**kusema / sema + ukweli**

### Examples
- **Sema ukweli.** → *Sema ukweli.* → “Tell the truth.”
- **Ninaamini kwamba atasema ukweli.** → *Ninaamini kwamba atasema ukweli.* → “I believe that he will tell the truth.”

### Notes
This is the ordinary dynamic verbal expression for producing truthful speech. Instead of a simple lexical verb “to truth,” Swahili uses a **light-verb construction** with **sema + ukweli**.  
This encodes an event or action, not just a static property.

---

## 5. LYING / ENTERING THE OPPOSITE SPEECH ACT
### Pattern
**kusema / sema + uongo**

### Examples
- **Alisema uongo.** → *Alisema uongo.* → “He/she told a lie.”
- **Sema uongo.** → *Sema uongo.* → “Tell a lie.”

### Notes
This is the direct dynamic opposite of **kusema ukweli** in the supplied data. It encodes the act of producing false speech.  
Again, the language here uses a **light-verb construction**, not a separate simple verb listed in the context.

## 6. STABLE CHARACTER STATES: TRUTHFUL, LYING, TRUSTWORTHY
### Pattern
**NP + ni + mkweli / mwongo / mwaminifu**; also descriptive **mtu aminifu**

### Examples
- **Yeye ni mkweli.** → *Yeye ni mkweli.* → “He/she is a truthful person.”
- **Yeye ni mwongo.** → *Yeye ni mwongo.* → “He/she is a liar.”
- **Yeye ni mwaminifu.** → *Yeye ni mwaminifu.* → “He/she is a faithful / trustworthy person.”

### Notes
These forms encode relatively stable personal character rather than momentary truth events:
- **mkweli** = truthful/honest person
- **mwongo** = liar
- **mwaminifu** = trustworthy/faithful person

The context supports these as person-denoting nouns.  
A common expression specifically meaning “become a liar” or “become truthful” is **not explicitly provided**.

## 7. STABLE ABSTRACT STATES
### Pattern
**ukweli / usahihi / uaminifu / uhalisia + wa / kwa ...**

### Examples
- **Usahihi wa taarifa** → *Usahihi wa taarifa* → “accuracy of information”
- **Uaminifu kwa Mungu** → *Uaminifu kwa Mungu* → “faithfulness to God”
- **Ukweli wa mambo** → *Ukweli wa mambo* → “the truth of the matter”

### Notes
These nouns encode stable qualities or states:
- **ukweli** = truth
- **usahihi** = correctness/accuracy
- **uaminifu** = trustworthiness/faithfulness
- **uhalisia** = reality/authenticity

They are useful for naming a state, but the context does **not** provide a common dedicated expression for “become truth,” “become accurate,” or “become authentic” built from these nouns.

## 8. CORRECTNESS AS STATE, BUT NO CLEAR ‘BECOME CORRECT’ FORM
### Pattern
**NP + ni / si + sahihi**; adnominal **jibu sahihi, taarifa sahihi**

### Examples
- **Hii ni sahihi.** → *Hii ni sahihi.* → “This is correct.”
- **Jibu hili si sahihi.** → *Jibu hili si sahihi.* → “This answer is not correct.”

### Notes
The context strongly supports **static evaluation** with **sahihi** and **si sahihi**.  
However, **no common expression is explicitly provided** for:
- “X becomes correct”
- “Y makes X correct”

So for **sahihi**, the available material mainly shows **state attribution**, not dynamic change or causation.

## 9. TRUTH / FALSEHOOD AS RESULT STATES IN ATTRIBUTION
### Pattern
**NP + ni + kweli / uongo**; negative **NP + si kweli**

### Examples
- **Ni kweli.** → *Ni kweli.* → “It is true.”
- **Ni uongo.** → *Ni uongo.* → “It is a lie / It is false.”
- **Si kweli.** → *Si kweli.* → “It is not true.”

### Notes
These are result-like evaluative states: a claim is classified as true, false, or not true.  
But the context does **not** provide a common dedicated expression for:
- “X becomes true”
- “X becomes false”
- “Y makes X true/false”

So the language material here supports **state assignment**, but not a clearly attested change-of-state verb for **kweli/uongo**.

## 10. AUTHENTICITY VS FAKENESS AS STATES, BUT NO CLEAR CHANGE VERB
### Pattern
**N + halisi / bandia / feki / ya asili**

### Examples
- **jina halisi** → *jina halisi* → “real name”
- **dawa bandia** → *dawa bandia* → “counterfeit medicine”
- **akaunti feki** → *akaunti feki* → “fake account”
- **bidhaa ya asili** → *bidhaa ya asili* → “authentic / natural product”

### Notes
These forms clearly encode authenticity or non-authenticity as descriptive states.  
However, **no common expression is explicitly provided** for:
- “X becomes fake”
- “X becomes genuine”
- “Y makes X fake/genuine”

So in the supplied material, this domain is mainly **stative/descriptive**, not dynamic.

## 11. VALIDITY / LAWFULNESS / PROHIBITION AS STATES
### Pattern
**NP + ni + batili / halali / haramu**

### Examples
- **Ni batili.** → *Ni batili.* → “It is invalid / null and void.”
- **Ni halali.** → *Ni halali.* → “It is lawful / legitimate.”
- **Ni haramu.** → *Ni haramu.* → “It is forbidden / illicit.”

### Notes
These are strong evaluative state predicates in formal, legal, and religious language.  
But again, **no common expression is explicitly provided** for:
- “become invalid”
- “become lawful”
- “become forbidden”
- “make valid / invalidate” using only the supplied vocabulary

So the context supports **classification into a state**, not a dedicated dynamic transition verb.

---

## 12. EVIDENTNESS AS A STABLE ASSESSMENT
### Pattern
**NP + ni dhahiri**; **ni dhahiri kwamba + clause**

### Examples
- **Ni dhahiri.** → *Ni dhahiri.* → “It is evident.”
- **Ni dhahiri kwamba ni uongo.** → *Ni dhahiri kwamba ni uongo.* → “It is evident that it is a lie.”

### Notes
**dhahiri** encodes manifestness or obviousness. It is an assessment of how plainly something is the case.  
The context does **not** provide a common expression for “become evident” or “make evident” using only the listed vocabulary.

---

## 13. OVERALL PATTERN
### Summary
Across the supplied Swahili material, truth-related dynamics are encoded mainly in three ways:

1. **Light-verb event expressions**
   - **kusema ukweli**
   - **kusema uongo**

2. **Credibility state / quasi-change forms**
   - **kuaminika**
   - **haaminiki / hakiaminiki**
   - **kutoaminika**
   - **asiyeaminika**

3. **Periphrastic causation of confidence**
   - **kutia imani**

### Notes
For many other truth-related items in the context—especially **kweli, uongo, sahihi, halisi, bandia, batili, halali, haramu, dhahiri**—the evidence provided is mainly for **static attribution** or **nominal/adnominal description**, not for productive change-of-state or causative expressions.

So the safest conclusion from the supplied data is:

- **Clearly dynamic:** **kusema ukweli**, **kusema uongo**, **kuaminika**, **kutia imani**
- **Mostly static in the provided material:** **kweli, uongo, sahihi, halisi, bandia, feki, batili, halali, haramu, dhahiri**
