## 1. BECOMING TRUE / BECOMING ESTABLISHED AS TRUE

### Pattern
**სიმართლე / ჭეშმარიტება + eventive verb** such as **გაირკვა, დადგინდა**

### Examples
- **სიმართლე გაირკვა.** → *simartle gairkva* → “The truth came out / became clear.”
- **სიმართლე დადგინდა.** → *simartle dadginda* → “The truth was established.”
- **ჭეშმარიტება დადგინდა.** → *č’ešmarit’eba dadginda* → “The truth was established.”  
  **Epistemic note:** less directly supported than **ჭეშმარიტების დადგენა**; the noun-phrase construction is better supported.

### Notes
Georgian does not show, in the supplied material, a simple common pattern equivalent to English “become true” with the core truth nouns. Instead, truth is typically presented as **becoming clear**, **coming out**, or **being established**.  
For **სიმართლე**, this is clearly supported. For **ჭეშმარიტება**, the best-supported dynamic expression is the nominal construction **ჭეშმარიტების დადგენა** rather than a simple finite clause.

## 2. BECOMING KNOWN AS AUTHENTIC / GENUINE

### Pattern
**ნამდვილობა + დადგენა / შემოწმება**; also resultative institutional phrasing with **დადგინდა**

### Examples
- **ნამდვილობის დადგენა** → *namdvilobis dadgena* → “establishing authenticity”
- **ნამდვილობის შემოწმება** → *namdvilobis shemots’meba* → “checking authenticity”
- **დოკუმენტის ნამდვილობა დადგინდა.** → *dok’ument’is namdviloba dadginda* → “The document’s authenticity was established.”

### Notes
For **ნამდვილი / ნამდვილობა**, the dynamic meaning is not usually “becomes real,” but rather **is verified as genuine**. The supplied material strongly supports procedural expressions of authentication.  
This is especially natural for documents, signatures, and similar objects.

## 3. BECOMING CORRECT / BECOMING ACCURATE

### Pattern
NO COMMON EXPRESSION EXISTS in the supplied material for a simple general pattern “X becomes correct/accurate.”

### Examples
- **სისწორის შემოწმება** → *sists’oris shemots’meba* → “checking correctness”
- **სიზუსტის შემოწმება** → *sizust’is shemots’meba* → “checking accuracy”

### Notes
The context supports **verification** of correctness or accuracy, but not a clear common inchoative pattern like “it became correct” built from **სწორი, სისწორე, ზუსტი, სიზუსტე**.  
So for these items, Georgian is represented here mainly through **checking** rather than **becoming**.

## 4. BECOMING FALSE / BECOMING NON-TRUE

### Pattern
NO COMMON EXPRESSION EXISTS in the supplied material.

### Examples
- **ეს სიმართლეს არ შეესაბამება.** → *es simartles ar sheesabameba* → “This does not correspond to the truth.”
- **ეს დოკუმენტი ყალბია.** → *es dok’ument’i q’albia* → “This document is fake.”

### Notes
The material supports **negative attribution** and **opposition**, but not a clear dynamic pattern like “became false” or “turned fake” using the listed truth-related vocabulary.  
So Georgian here is better represented by **state description** or **truth-denial**, not by a productive “become false” construction.

## 5. CAUSING TRUTH TO BE ESTABLISHED

### Pattern
**სიმართლის / ჭეშმარიტების / ნამდვილობის + დადგენა**

### Examples
- **სიმართლის დადგენა** → *simartlis dadgena* → “establishing the truth”
- **ჭეშმარიტების დადგენა** → *č’ešmarit’ebis dadgena* → “determination / establishment of truth”
- **ნამდვილობის დადგენა** → *namdvilobis dadgena* → “establishing authenticity”

### Notes
This is the clearest causative-like dynamic pattern in the material. Georgian often encodes “causing X to be known as true/genuine” not with a simple causative adjective pattern, but with a **procedural nominal construction** meaning “establish the truth/authenticity.”  
This is especially common in legal, investigative, scholarly, and administrative contexts.

## 6. CAUSING SOMETHING TO COUNT AS JUSTIFIED / PROVED RIGHT

### Pattern
**გაამართლოს / გაამართლა + object**; also **გამართლება**

### Examples
- **გაამართლა მოლოდინი.** → *gaamartla molodini* → “It justified / lived up to expectations.”
- **გამართლება** → *gamartleba* → “justification; acquittal; vindication”
- **გამართლება აქვს.** → *gamartleba akvs* → “It has justification / is justified.”
- **გამართლება არ აქვს.** → *gamartleba ar akvs* → “There is no justification / it is inexcusable.”

### Notes
Within the **მართ-** family, the most clearly dynamic causative item is **გაამართლა**. It can mean that something **vindicated**, **justified**, or **proved right** an expectation, trust, claim, or person.  
This is not exactly “make true” in a broad factual sense, but it is a strong dynamic pattern of **bringing about justified status**.

## 7. CAUSING BELIEF / MAKING SOMETHING SEEM TRUE

### Pattern
Built around **დამაჯერებელი** rather than a finite causative construction in the supplied material

### Examples
- **დამაჯერებელი არგუმენტი** → *damajerebeli argument’i* → “convincing argument”
- **დამაჯერებელი ახსნა** → *damajerebeli akhsna* → “convincing explanation”
- **დამაჯერებელი მტკიცებულება** → *damajerebeli mtkitsebuleba* → “convincing evidence”

### Notes
The dynamic component here is lexical: **დამაჯერებელი** means roughly “causing belief / convincing.”  
However, the supplied material does **not** provide a separate common finite construction like “Y made X believable” using this vocabulary. So the causative meaning is present mainly inside the adjective itself.

## 8. REVEALING OR DISCOVERING TRUTH

### Pattern
**სიმართლე + გაირკვა / დადგინდა**; **სიმართლის / ჭეშმარიტების / ნამდვილობის + ძიება / დადგენა / შემოწმება**

### Examples
- **სიმართლე გაირკვა.** → *simartle gairkva* → “The truth came out.”
- **სიმართლის ძიება** → *simartlis dzieba* → “search for truth”
- **ჭეშმარიტების ძიება** → *č’ešmarit’ebis dzieba* → “search for truth”
- **ნამდვილობის შემოწმება** → *namdvilobis shemots’meba* → “checking authenticity”
- **სისწორის შემოწმება** → *sists’oris shemots’meba* → “checking correctness”
- **სიზუსტის შემოწმება** → *sizust’is shemots’meba* → “checking accuracy”

### Notes
A major dynamic tendency in the material is that truth-related meanings are often encoded through **processes of discovery, verification, and establishment** rather than through simple change-of-state verbs.  
This is especially clear with:
- **სიმართლე** → revelation / establishment
- **ჭეშმარიტება** → elevated search / establishment
- **ნამდვილობა** → authentication
- **სისწორე / სიზუსტე** → checking and verification

## 9. STABILITY: REMAINING IN A TRUTH-RELATED STATUS

### Pattern
NO COMMON EXPRESSION EXISTS in the supplied material for a dedicated “remain true/correct/genuine” construction.

### Examples
No clearly supported common expression identified.

### Notes
The context is rich in expressions for:
- being true/correct/genuine,
- establishing truth,
- checking authenticity,
- justifying something,

but it does not provide a clear common pattern specifically for **remaining** true, correct, or genuine over time.

## 10. ITEM-BY-ITEM BEHAVIOR SUMMARY

### **სიმართლე**
Best supported dynamic expressions:
- **სიმართლე გაირკვა**
- **სიმართლე დადგინდა**
- **სიმართლის დადგენა**
- **სიმართლის ძიება**

Behavior:
Truth is encoded as something that can be **revealed**, **established**, or **sought**.

---

### **ჭეშმარიტება**
Best supported dynamic expressions:
- **ჭეშმარიტების დადგენა**
- **ჭეშმარიტების ძიება**
- **ჭეშმარიტების თქმა**

Behavior:
More elevated than **სიმართლე**; dynamic use is mainly through **searching for** or **establishing** truth.

---

### **ნამდვილი / ნამდვილობა**
Best supported dynamic expressions:
- **ნამდვილობის დადგენა**
- **ნამდვილობის შემოწმება**

Behavior:
Authenticity is encoded mainly as something that can be **verified** or **established**, especially institutionally.

---

### **სწორი / სისწორე**
Best supported dynamic expressions:
- **სისწორის შემოწმება**

Behavior:
Correctness is mainly treated as something to **check**, not as something that clearly “becomes” so in the supplied material.

---

### **ზუსტი / სიზუსტე**
Best supported dynamic expressions:
- **სიზუსტის შემოწმება**
- **სიზუსტის დაცვა**

Behavior:
Accuracy is treated procedurally: it can be **checked** and **maintained**.

---

### **მართებული / გამართლებული / გამართლება**
Best supported dynamic expressions:
- **გაამართლა**
- **გამართლება აქვს / არ აქვს**

Behavior:
This area strongly supports **justification**, **vindication**, and **proving right**, rather than simple factual truth.

---

### **ყალბი / სიყალბე**
Best supported dynamic expressions:
NO COMMON EXPRESSION EXISTS for a change-of-state pattern in the supplied material.

Behavior:
Falseness is mainly encoded as a **state** or **negative evaluation**, not through a supported “become fake/false” construction here.

---

## 11. OVERALL GENERALIZATION

### Pattern
Truth-related dynamics in the supplied Georgian material are encoded mainly through:
1. **revelation** — **სიმართლე გაირკვა**
2. **establishment** — **სიმართლის / ჭეშმარიტების / ნამდვილობის დადგენა**
3. **verification** — **ნამდვილობის / სისწორის / სიზუსტის შემოწმება**
4. **justification/vindication** — **გაამართლა, გამართლება**

### Notes
A simple productive pattern like English “become true / become false / make true” is **not strongly supported** by the supplied vocabulary.  
Instead, Georgian here prefers:
- **eventive discovery verbs**,
- **institutional nominal constructions**,
- and **justification/vindication expressions**.
