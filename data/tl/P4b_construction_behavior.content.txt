# CLCA Protocol v3.4 — P4b Construction Usage & Constraints
# Language: Tagalog (tl)

---

| Construction Type | Example | Transliteration | Translation | Epistemic Status | Usage Notes |
|------------------|---------|-----------------|-------------|------------------|-------------|
| **1. ATTRIBUTION** | Totoo ang sinabi niya. | totoo ang sinabi niya | "What he/she said is true." | [CORE] | This is the unmarked, most frequent construction for attributing truth-values. Used across all registers and contexts without restrictions. |
| | Mali ang sagot mo. | mali ang sagot mo | "Your answer is wrong." | [CORE] | |
| **2. NEGATIVE ATTRIBUTION** | Hindi totoo ang balita. | hindi totoo ang balita | "The news is not true." | [CORE] | Standard negation pattern used in all contexts. The alternative *di-* prefix form (e.g., *di-totoo*) is more colloquial and less emphatic. |
| | Hindi tama ang ginawa mo. | hindi tama ang ginawa mo | "What you did is not right/correct." | [CORE] | |
| **3. ADNOMINAL MODIFICATION** | tunay na kaibigan | tunay na kaibigan | "true friend" / "genuine friend" | [CORE] | Highly productive pattern for modifying nouns. Modifier-before-noun order is strongly preferred for truth-domain terms, though noun-modifier order is grammatically possible. |
| | maling impormasyon | maling impormasyon | "wrong information" / "false information" | [CORE] | |
| **4. BECOME / INCHOATIVE** | Nagtotoo ang panaginip ko. | nagtotoo ang panaginip ko | "My dream is coming true." | [CORE] | Common with *totoo* for realization/coming true. Different roots show different preferred verbal patterns; not all truth-domain terms have equally productive inchoative forms. |
| | Nagkamali ako. | nagkamali ako | "I made a mistake." | [CORE] | The *magkamali* form is highly lexicalized and extremely frequent in everyday speech. |
| **5. CAUSATIVE** | Patunayan mo ang sinabi mo. | patunayan mo ang sinabi mo | "Prove what you said." | [CORE] | *Patunayan* is highly lexicalized and common. Other truth-domain roots do not form causatives as productively; this construction is somewhat restricted to specific lexical items. |
| | Pinatotohanan niya ang kanyang salita. | pinatotohanan niya ang kanyang salita | "He/she is proving his/her word true." | [MARGINAL] | Less common than *patunayan*; appears in more formal or literary contexts. The progressive aspect form is particularly restricted. |
| **6. ABSTRACT NOMINALIZATION** | katotohanan | katotohanan | "truth" / "reality" | [CORE] | Highly productive *ka-...-an* pattern used across all registers. These abstract nouns are extremely common in both spoken and written Tagalog. |
| | katapatan | katapatan | "honesty" / "sincerity" | [CORE] | |
| **7. AGENTIVE NOMINALIZATION** | sinungaling | sinungaling | "liar" | [CORE] | This lexicalized form is extremely common in everyday speech. However, the pattern itself is not productive—there is no general derivational process for creating agent nouns in this domain. |
| | mandaraya | mandaraya | "cheater" | [CORE] | Common lexical item, but the *mang-* derivation is limited to certain roots. Most truth-domain terms lack productive agentive forms. |
| **8. EXISTENTIAL CONSTRUCTIONS** | May katotohanan ang sinabi niya. | may katotohanan ang sinabi niya | "What he/she said has truth." | [CORE] | Very productive and common pattern, especially in argumentative or evaluative discourse. Used to assert or deny the presence of truth/evidence/validity. |
| | Walang katunayan ang akusasyon. | walang katunayan ang akusasyon | "The accusation has no proof." | [CORE] | |
| **9. EVIDENTIAL/EPISTEMIC CONSTRUCTIONS** | Ayon sa katotohanan, wala siyang kasalanan. | ayon sa katotohanan, wala siyang kasalanan | "According to the truth, he/she is not guilty." | [CORE] | Common in formal discourse, news reporting, and argumentation. Functions as a discourse organizer establishing evidential basis for claims. |
| | Batay sa katunayan, tama ang desisyon. | batay sa katunayan, tama ang desisyon | "Based on the evidence, the decision is correct." | [CORE] | |
| **10. DISCOURSE MARKER CONSTRUCTIONS** | Sa totoo lang, ayaw ko na. | sa totoo lang, ayaw ko na | "To be honest, I don't want to anymore." | [CORE] | Extremely common in conversational Tagalog. These are fixed expressions with specific pragmatic functions (introducing frank statements, marking seriousness). |
| | Totóhanán, hindi ka ba galit? | totóhanán, hindi ka ba galit | "Seriously, aren't you angry?" | [CORE] | |
| **11. COMPARATIVE CONSTRUCTIONS** | Mas totoo ang kuwento niya kaysa sa iyo. | mas totoo ang kuwento niya kaysa sa iyo | "His/her story is more true than yours." | [CORE] | Fully productive pattern. However, pragmatically, comparatives of absolute terms like *totoo* may be less frequent than comparatives of gradable terms like *tama*. |
| | Ito ang pinakatamang sagot. | ito ang pinakatamang sagot | "This is the most correct answer." | [CORE] | |
| **12. INTENSIFICATION CONSTRUCTIONS** | Totoong-totoo ang nangyari. | totoong-totoo ang nangyari | "What happened is very true." | [CORE] | Reduplication pattern is very common in emphatic speech. Conveys strong emphasis and removal of doubt. |
| | Sobrang mali ang ginawa niya. | sobrang mali ang ginawa niya | "What he/she did is very wrong." | [CORE] | *Sobrang* intensification is frequent in colloquial speech across all truth-domain terms. |
| **13. CONCESSIVE CONSTRUCTIONS** | Totoo naman, pero hindi sapat. | totoo naman, pero hindi sapat | "It is true though, but it's not enough." | [CORE] | Very common in argumentative and conversational contexts. *Naman* is more colloquial; *man* appears in more formal or literary registers. |
| | Tama man, mali pa rin ang paraan. | tama man, mali pa rin ang paraan | "Even if correct, the method is still wrong." | [CORE] | |
| **14. CONDITIONAL CONSTRUCTIONS** | Kung totoo ang sinabi mo, patawarin kita. | kung totoo ang sinabi mo, patawarin kita | "If what you said is true, I'll forgive you." | [CORE] | Standard conditional pattern, fully productive with all truth-domain predicates. Extremely common in reasoning and hypothetical discourse. |
| | Kung mali ako, sabihin mo. | kung mali ako, sabihin mo | "If I'm wrong, tell me." | [CORE] | |
| **15. INTERROGATIVE CONSTRUCTIONS** | Totoo ba ang balita? | totoo ba ang balita | "Is the news true?" | [CORE] | Standard yes/no question formation, used constantly in everyday conversation. Fully productive with all truth-domain predicates. |
| | Tama ba ang sagot ko? | tama ba ang sagot ko | "Is my answer correct?" | [CORE] | |
| **16. EMPHATIC AFFIRMATION CONSTRUCTIONS** | Tama nga ako! | tama nga ako | "I am right indeed!" | [CORE] | Very common in conversational contexts, especially when confirming something previously doubted or expressing vindication. Carries strong pragmatic force. |
| | Totoo nga ang sabi nila. | totoo nga ang sabi nila | "What they said is indeed true." | [CORE] | |
| **17. CESSATION/SUFFICIENCY CONSTRUCTIONS** | Tama na yan! | tama na yan | "That's enough!" | [CORE] | Extremely common directive construction, but restricted to *tama*. Does not extend to other truth-domain terms (*totoo na*, *mali na* do not have this cessation meaning). |
| | Tama na, ayoko na. | tama na, ayoko na | "Enough, I don't want to anymore." | [CORE] | |
| **18. PRONOMINAL ATTRIBUTION CONSTRUCTIONS** | Mali ka. | mali ka | "You're wrong." | [CORE] | Extremely frequent in conversational disagreement/agreement. Most common with *tama* and *mali*; less common with *totoo* in this construction. |
| | Tama ako. | tama ako | "I'm right." | [CORE] | |

## ALTERNATE CONSTRUCTIONS ATTESTED

### Construction 2 (Negative Attribution)
- **Alternate form**: Contracted negator *di-* as prefix
  - Example: *Di-totoo ang balita* (less emphatic than *hindi totoo*)
  - Status: [CORE] in colloquial speech, more casual register

### Construction 6 (Abstract Nominalization)
- **Alternate pattern 1**: *pagka-* prefix
  - Example: *pagkatunay* "genuineness"
  - Status: [MARGINAL] - less productive than *ka-...-an*
  
- **Alternate pattern 2**: *pag-* prefix with verbal roots
  - Example: *pagtotoo* "realization" (process noun)
  - Status: [MARGINAL] - denotes process rather than abstract quality

### Construction 17 (Cessation/Sufficiency)
- **Polite variant**: Addition of *po*
  - Example: *Tama na po*
  - Status: [CORE] in polite/formal contexts

## GENERAL OBSERVATIONS

1. **Register variation**: Several constructions show clear register distinctions (e.g., *naman* vs. *man* in concessives, *di-* vs. *hindi* in negation).

2. **Lexical restrictions**: Some patterns are productive across all truth-domain terms (attribution, negation, modification), while others are restricted to specific lexical items (causatives, cessation constructions).

3. **Pragmatic specialization**: Several constructions have developed specialized pragmatic functions beyond their compositional semantics (discourse markers, emphatic affirmation).

4. **Productivity asymmetries**: Abstract nominalization with *ka-...-an* is highly productive, while agentive nominalization shows limited productivity with mostly lexicalized forms.
